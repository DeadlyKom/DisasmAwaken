# Материалы разбора Awaken

Disk хранит оригинальный TRD и его физическую разметку. Extracted содержит
44 непустые записи, включая удалённые, с логическими файлами, заголовками,
полными секторами и хвостами. Reports содержит текущие проверочные реестры.
Исследовательские сценарии и предыдущие варианты находятся в Research.

Все приведённые команды выполняются из корня проекта. Python нужен
для исследования и проверок, обычная сборка SjASMPlus его не вызывает.

## Текущие проверки без сборки

```text
python Tools/Disasm/VerifySources.py
python Tools/Disasm/Research/AuditConformance.py --output Tools/Disasm/Reports/ConformanceAudit.json
python Tools/Disasm/VerifyBuild.py
```

Первая команда сверяет текст инструкций и физические ресурсы с оригиналом.
Вторая проверяет действительный граф include, объявления глобальных ссылок,
оформление и остаточные пробелы разбора. Третья читает уже существующий TRD,
не создаёт новый образ и не доказывает сборку текущих исходников.

Изолированные модели в Research запускают оригинальные байты через
поставляемый SkoolKit. У каждого отчёта отдельно указано, что именно проверено.
Наличие результата passed не заменяет проверку всего игрового сценария.

## Исследовательские кандидаты

Полный экспорт не записывает файлы поверх Source. Для нового кандидата:

```text
python Tools/Disasm/Research/ExportSources.py --output Tools/Disasm/Research/Candidates/NextSource
python Tools/Disasm/Research/GenerateDocs.py --output Tools/Disasm/Research/Candidates/NextDocs
```

Указанная папка должна быть новой. Исходные материалы копируются внутрь
кандидата, текущие Source, Builder, Includes и Docs не заменяются.
Табличный реестр языка выпускается как ScriptTokens.md, ручной разбор
ScriptLanguage.md сохраняется. Получившиеся различия просматриваются отдельно.
Экспорт не входит в сборку и не запускает SjASMPlus.

PromoteFunction.py применяет конкретный ручной разбор из Knowledge,
Contracts и Notes. Перед записью он запускает статическую сверку и сохраняет
затронутые версии в History. Этот инструмент меняет рабочую копию,
поэтому его адрес и регион должны соответствовать конкретной разбираемой процедуре.
Сам по себе он не доказывает смысл контракта.
Замены учитывают регион, совпадающее адресное имя другого банка сохраняется.
Проверка CheckScopedPromotion.py выполняет тестовое переименование только
в отдельном кандидате, такой кандидат помечается как регрессионная фикстура,
его тестовые имена не являются результатом смыслового разбора.
ValidateNotes.py проверяет начала инструкций и тип условного перехода
или выхода перед записью комментариев.

## Сохранённая история

History содержит прежние исследовательские выпуски, исходные версии перед
исправлениями и не включённые в текущую сборку файлы. Перемещения отражены
в LayoutMigration.json, UnusedSourceArchive.json и UnusedResourceArchive.json
из Reports с сохранением контрольных сумм. Исторические манифесты относятся
к своему выпуску и не используются нынешним Builder/Main.asm.
