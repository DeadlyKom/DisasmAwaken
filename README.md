# Awaken v0.2 — воспроизводимый разбор TRD

Исходный образ сохранён в `Tools/Disasm/Disk/original.trd`.
Все пути проекта отсчитываются от его корня.

Дальнейшие изменения перечислены в [плане приведения проекта в соответствие](Docs/ConformancePlan.md).

## Текущее состояние

Предыдущая сборка SjASMPlus восстановила весь диск побайтово без ошибок
и предупреждений. После текущего изменения структуры каталогов и оформления
сборка не запускалась, действует пользовательский запрет. Статическая сверка
инструкций и данных выполнена отдельно, результаты находятся в
[SourceVerification.json](Tools/Disasm/Reports/SourceVerification.json) и
[аудите требований](Tools/Disasm/Reports/ConformanceAudit.json).
Полный семантический разбор ещё продолжается,
неустановленные назначения и контракты явно обозначены `Unknown`.
В реестре 1101 фрагментов, 254 с неизвестным назначением и 485 без доказанного контракта. У всех зарегистрированных входов Text контракты описаны, но игровые значения части полей и физические данные языка ещё требуют разбора. Управление сценарием описано в [ScriptControl](Docs/ScriptControl.md), выражения в [ExpressionControl](Docs/ExpressionControl.md).
Отсечение карты описывается в [ClipProducts](Docs/ClipProducts.md), [ClipIntersections](Docs/ClipIntersections.md), [ClipTail](Docs/ClipTail.md) и [ClipCases](Docs/ClipCases.md). Подготовки дуги и завершающие маски разобраны в [ArcPreparation](Docs/ArcPreparation.md) и [ArcClosing](Docs/ArcClosing.md), диспетчер геометрических случаев остаётся Unknown.
Запуск оригинала в Unreal подтверждён пользователем. Запуск пересобранного
образа предварительно подтверждён, подробный игровой прогон ещё не выполнен.

Извлечены 44 непустые записи каталога, включая три удалённые. Сохранены
логические файлы, полные выделенные сектора, заголовки записей, хвосты,
служебная область и свободные области диска. Проверено, что эти компоненты
покрывают исходный образ полностью и воспроизводят его побайтово.

## Сборка

Из корня проекта либо через задачу Build в VS Code:

```powershell
.\Tools\Sjasmplus\sjasmplus.exe --nologo --fullpath=rel --lst=Tmp/Awaken.lst --sym=Tmp/Awaken.sym --sld=Tmp/Awaken.sld Builder/Main.asm
```

Результат — `Awakenv02.trd` в корне. Python и SkoolKit в сборке не участвуют.
Отдельная проверка существующего результата — `python Tools/Disasm/VerifyBuild.py`.

У файлов `.bin`, `.sectors.bin`, `.header.bin` и `.tail.bin` разное назначение.
Для загрузчиков нельзя подменять полные выделенные сектора логической длиной.
Подробности приведены в `Docs/Extraction.md`.

SHA-256 оригинала:

```text
55a11de202a5334547e39a6db42c945242a2a53559dc1cf601522219e3463f32
```

поэтому сохранённая резервная копия `Tools/Disasm/Disk/original.trd` попадает
под существующее правило `*.trd`. Она присутствует на диске независимо от Git.
