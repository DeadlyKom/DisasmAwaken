# State06, малый эффект банка 3 и затухание родителя

[StartSmallRecordEffect](../Source/Action/StartSmallRecordEffect.asm)
занимает F6EC..F728 ACTION банка 0. ModelOffset передаётся
[ReadObjectHeaderWord](ActionObjectHeader.md). Старший байт прочитанного
заголовка становится режимом Mode малого эффекта. Младший байт заголовка
здесь не используется. Для передачи через
[DispatchBank3Callback](ActionBankedCallback.md) режим сохраняется
в альтернативном A, а значение **26** передаётся отдельно как State
записи эффекта. Три Components родителя передаются через EXX.

Настоящий [Voxel.CreateSmallEffect](../Source/Voxel/CreateSmallEffect.asm)
исполняется в банке 3. Поиск начинается с A795 и идёт по FVisualEffect
размером 18 до свободного State=0 либо отрицательного маркера.
Свободный слот заполняется всеми восемнадцатью байтами:

| Поля | Значение |
| --- | --- |
| SavedHL, SavedDE, SavedBC | три Components родителя |
| Mode | старший байт заголовка модели |
| State | 1A, десятичное 26 |
| FramePointer и FirstFrame | D800, адрес первого кадра малого эффекта |
| FrameCount | 1, первый обход загружает начальный кадр |
| FrameReload | 0D, тринадцать кадров в цикле |
| FrameStride | 00C0, шаг в байтах |
| FrameWidth и FrameHeight | 0C и 0C, размеры исходного кадра |

Отрицательный маркер прекращает поиск без заполнения записи. На обоих
путях выполняется настоящий возврат через RestoreRuntimePage в ACTION.
Затем Enabled кадрового обхода получает 1, Frames поднимается до 26,
если был меньше, родитель получает StateCode=07 и Unknown11=12.
**Отказ выделения не отменяет переход к затуханию и включение обхода.**
При обычных вызовах [State07](ActionTimedDecayState.md) счётчик 18
закончится освобождением родителя, если другие писатели не вмешаются.

Итоговые HL=D800, DE=00C0, BC=0012. A=max(старые Frames,26),
F соответствует CP старых Frames с 26. После загрузки нового 26
флаги не пересчитываются. Альтернативные HL, DE и BC содержат три
Components родителя. При выделении AF'=0054. При отрицательном маркере
A'=1A, F' сохраняет входной альтернативный F. IX, I, IM и IFF
сохраняются, IY указывает выбранный слот либо маркер.

Порт 7FFD получает последовательно 14, 10, 13, 10. Это чтение
OBJECT3D, возврат в ACTION, вызов VOXAL и окончательный возврат.
Итоговая конфигурация равна 10, исходная конфигурация не восстанавливается.
Требуется разблокированный 7FFD и исходно выбранный банк ACTION 0.
Максимальная дополнительная рамка CPU-стека равна шести байтам,
внешний возврат сохраняется, SP после RET увеличен на два.

При выделении после n занятых записей R добавляет 142+7*n M1,
при отрицательном маркере 100+7*n, ещё 2 M1 при старых Frames<26.
Бит 7 R сохраняется. Четыре операнда создателя малого эффекта
изменяются в банке 3. Два писателя Enabled и Frames по F711 и F71D
имеют физические цели **банка 5 после переноса ядра**, что явно
зарегистрировано в [самомодификации](ModifiedCode.md).

[Независимая композиционная модель](../Tools/Disasm/Research/CheckActionSmallEffectState.py)
проверила 32256 сценариев, все исходные чётные ModelOffset, все
Frames, восемь компонентных границ и все входные альтернативные F.
Дополнительные сценарии явно меняют старший байт заголовка в тестовой
RAM банка 4, чтобы проверить все 256 Mode, они не выдаются за разные
оригинальные модели. Неизвестный незагруженный хвост банка 4 заполнен A4.
Настоящие чтение, банковый создатель, поиск и возвратные хвосты исполняются
до полного внешнего RET. Сверены регистры, флаги, R, SP, восемь банков,
кратность всех записей и четыре настоящих OUT. Полное произведение
входов, аппаратные IRQ, точные T, сборка и нативный запуск не выполнялись.
