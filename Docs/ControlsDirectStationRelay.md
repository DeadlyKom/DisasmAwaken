# Прямая перенесённая загрузка станции

[LoadStationDirectRelay](../Source/Controls/LoadStationDirectRelay.asm) исполняется по 4000..4030, 49 байтов. Источник находится по DCA9..DCD9 банка 1, физические смещения CONTROL 01CB..01FB. Девятибайтовый ключ STATIONFC следует по 4031..4039. [RelocateStationReload](../Source/Controls/RelocateStationReload.asm) переносит весь 256-байтовый блок, поэтому код переживает смену верхнего банка. [Факты и договор](../Tools/Disasm/Research/ControlsDirectStationRelayFacts.py), [проверка двух стадий](../Tools/Disasm/Research/CheckControlsStationReloadRelays.py).

Стадия запрещает прерывания, устанавливает IM 1, I=3F и IY=5C3A. Два OUT 7FFD выдают 1F и 18. Старый стек заменяется на 5FFF. Ключ из копии переносится в 5CDD, байт диска 5CF9 обнуляется. Тип файла C является девятым байтом сразу после восьми символов STATIONF, пробела или терминатора между ними нет.

По 5FFD помещается слово 6300, после чего JP 3D13 передаёт управление TR-DOS с C=0E. На этой границе HL=403A, DE=6300, BC=000E, AF=0044, SP=5FFD, IX и альтернативные регистры сохранены. Локального CALL нет. Обычный RET файловой службы снимет непосредственно 6300, поэтому отдельной проверки Carry и кода ошибки здесь нет.

При условии успешной внешней загрузки STATIONF по 6000 адрес 6300 является [StationBoot.RelocateBootstrap](../Source/StationBoot/RelocateBootstrap.asm) свежей программы. Этот вход не смешивается с процедурами прежнего содержимого памяти по тому же числовому адресу. Старый адрес возврата не используется.

Общая серия двух стадий содержит 768 проверок. Для этого входа 256 профилей исполняются до границы TR-DOS. Сопоставлены восемь банков RAM и кратность записей, основные и сохраняемые регистры, I, IM, IFF и SP.

В сквозной модели [выхода через шум](ActionNoiseExit.md#сквозной-возврат-после-разрушения-корабля) оригинальное ПЗУ TR-DOS 5.04T загружает 160 секторов станции. При передаче на `#6300` все 512 байтов состояния станции совпадают с файлом, полётный контекст остаётся за пределами этой передачи. [LoadStationStateRelay](ControlsStateStationRelay.md) использует отдельный путь с переносом состояния.

В модели с переименованной записью STATIONF ПЗУ читает три сектора каталога, устанавливает `#5D0F=1` и всё равно возвращается на `#6300`. Там остаются байты [CountClass3LinksUpToTwo](../Source/Action/CountClass3LinksUpToTwo.asm) из ACTION. Модель останавливается до первой команды по этому адресу. [Трасса обоих исходов](../Tools/Disasm/Reports/ActionNoiseStationCycleVerification.json)

Ключ оформлен реальным [экземпляром FTrDosFileKey](../Source/Controls/Data/DirectStationKey.asm), все девять байтов и рабочий адрес проверены [физическим разбором](../Tools/Disasm/Research/ControlsStationRelayFileKeys.py).
