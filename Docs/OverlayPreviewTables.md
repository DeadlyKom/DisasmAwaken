# Исходная синусоида D3D и значки прицела

[SineTable.asm](../Source/D3D/Data/SineTable.asm) содержит 256 физических
FFixedSineValue по #C400..#C4FF. Все байты совпадают с таблицей ACTION
по #9900. Данные не объединялись, у них разные дисковые и банковые
контексты. Таблицу предпросмотра читает
[BuildPreviewModelMatrix](../Source/D3D/BuildPreviewModelMatrix.asm).
Угловая единица равна 1/256 оборота, байт трактуется как знаковый
коэффициент исходного масштаба. Формула построения и свойства таблицы
описаны в [ActionSineTable](ActionSineTable.md).

Следующие 256 байтов #C500..#C5FF не относятся к этой синусоиде.
Они сохранены отдельным неизвестным диапазоном, назначение по
повторяющимся числам не назначается.

[OverlayGlyphs.asm](../Source/Controls/Data/OverlayGlyphs.asm)
содержит 16 реальных FOverlayGlyphPhase по #EB0E..#EC0D банка 1.
Каждая запись имеет восемь строк по два байта, левую и правую колонку.
Первые восемь фаз являются рамкой 8 на 8, следующие восемь ромбом
7 на 7 с нулевой последней строкой. Каждая последующая фаза равна
16-битной строке нулевой фазы, сдвинутой вправо на индекс фазы.

[ToggleTargetOverlay](../Source/Controls/ToggleTargetOverlay.asm)
выбирает фазу как `(X−4) AND 7`. Обычная рамка начинается с #EB0E,
при совпадении одного из трёх индексов выделения добавляется #80
и выбирается ромб. Все восемь пар объединяются с линейным буфером
через XOR, это не маска очистки и не запись атрибутов.

128 байтов ромба также совпадают с MapMarkerSprites.ActiveAux.
В [маркерном потребителе карты](MapMarkerSprites.md) последняя пара
не выводится, а прицельная рамка читает все восемь. Поэтому здесь
используется собственная структура с двумя физическими полями каждой
из восьми строк, без переноса имени неиспользуемого хвоста из другого
договора. Полностью нулевая строка не меняет буфер при XOR.

[Проверка формата](../Tools/Disasm/Research/OverlayPreviewTables.py)
сверяет обе копии синусоиды, все 128 сдвигов строк и обе нулевые фазы.
[VerifySources](../Tools/Disasm/VerifySources.py) проверяет физические
инициализаторы и адреса всех 272 записей. Существующая
[модель прицельной рамки](../Tools/Disasm/Research/CheckControlsTargetOverlay.py)
проверяет реальный потребитель. Сборка и нативный запуск не выполнялись.
