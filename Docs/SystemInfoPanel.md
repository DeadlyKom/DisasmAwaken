# Информационная панель систем

[DrawSystemInfoPanel](../Source/Station/DrawSystemInfoPanel.asm) — реальный обработчик записи 19, его изменяемый ItemIndex хранится по 7690. [TryDrawSystemInfo](../Source/Station/TryDrawSystemInfo.asm) сначала ищет полный указатель обработчика в списке, при отсутствии возвращается, иначе последовательно входит в обработчик. Это два жёстко упорядоченных INCLUDE, условный RET не исключает продолжения.

После DrawCaptionItem устанавливается Style=0 и печатается исходный шаблон. Подписи шаблона и реальные русские строки устанавливают назначение полей, которых нельзя было вывести из одного алгоритма генерации ключа.

| Значение | X | Y | Получение |
| --- | --- | --- | --- |
| Дальности хватает топлива | 49 | 8 | H слова 988E, если H ненулевой, иначе L>>1 |
| Расстояние | 49 | 16 | MeasureCoordinateDistance между выбранной и текущей точками, FF показан дефисом |
| Политическая область выбранной системы | 0 | 40 | ClassifyKeyRegion по её FirstWord |
| Имя выбранной системы | 0 | 48 | BuildSystemName по двум словам |
| Выбранная планета | 34 | 56 | PrintVariantLabel с выбранным Variant |
| Строй выбранной системы | 25 | 64 | PrintSystemTraits, если число планет ненулевое |
| Перечень планет | 0,32,64 | 96,104 | От одной до шести PrintSelectedVariantLabel с A=0..N-1 |
| Политическая область текущей системы | 0 | 128 | ClassifyKeyRegion по текущему FirstWord |
| Имя текущей системы | 0 | 136 | Повторный BuildSystemName с тем же Buffer |
| Текущая планета | 34 | 144 | PrintVariantLabel с текущим Variant |
| Строй текущей системы | 25 | 152 | PrintSystemTraits, если число планет ненулевое |

Координаты даны относительно TextWindow. Помощник признаков добавляет ещё две строки на Y+8 и Y+16, см. [SystemTraits](SystemTraits.md). Строй и политическая область не тождественны. Названия областей по кодам 0..3 — Федерация Галактики, Конфедерация Первых, Содружество Миров, Свободные Земли. Имя системы не использует Variant, подпись планеты его использует.

Если количество выбранного ключа равно нулю, по X=0,Y=96 печатается Планет нет., признаки и перечень пропускаются. Если количество текущего ключа равно нулю, его признаки просто пропускаются без такой фразы. Поэтому две нулевые ветви не объединены. Количество равно max((XOR четырёх байтов AND 7)-1,0), два исходных кода дают ноль и различаются F=44 и F=42.

Для выбранных признаков PUSH AF снимается в BC, B становится количеством, C содержит флаги характеристики. Первые пять подписей сохраняют текущие AF и BC отдельными PUSH, после каждой INC A и DEC B решают, закончить ли перечень. Шестая подпись вызывается без этих сохранений. Ни новая петля, ни новое размещение данных не введены.

При ненулевом количестве текущего ключа его PUSH AF тоже снимается в BC. На обычном полном успешном рисунке конечные HL=A822, DE содержит область и экономику текущей системы, BC=(N<<8)|F_характеристики, AF=0045. При нулевом количестве возвращается результат DescribeCurrentKey. IX,IY сохраняются. Альтернативные общие пары после текущего BuildSystemName сохраняют его результат обмена наборами, AF' в конце относится к странице возврата DescribeCurrentKey. В Buffer осталось имя текущей системы, LastDistance хранит результат измерения.

Paging выполняется реальными SelectRamBank с сохранением старших управляющих битов. Возврат выбирает банк 0 и ROM 1, исходный произвольный номер банка не восстанавливается. Указатель не защищается самим обработчиком, это договор внешнего пути. HALT заголовка требует пробуждения. Отказы текста не прекращают последующие поля, Style остаётся нулём.

[CheckSystemInfoPanel](../Tools/Disasm/Research/CheckSystemInfoPanel.py) и [отчёт](../Tools/Disasm/Reports/SystemInfoPanelVerification.json) проверяют 192 полных вызова с исходными рамкой, текстом, расстоянием, именами, характеристиками и подписями. Проверены все количества 0..6, все пять кодов строя, расстояния 0,1,2,FF и два состояния экранного бита. Точная последовательность непосредственных вызовов и их аргументы сопоставляется с ожидаемым планом полей, имена сверяются с отдельной формулой. Независимая модель всего bitmap этой панели не заявлена, пиксельные договоры её помощников имеют отдельные проверки. HALT пробуждается моделью, IRQ, сборка и нативная игра не выполнялись.

96 полных вызовов выполнены через проверяющую обёртку, ещё 256 пустых списков проверили ранний выход для всех входных F, включая сохранение Carry.
