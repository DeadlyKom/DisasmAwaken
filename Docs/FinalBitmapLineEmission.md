# Выдача шаблона одной пиксельной строки

[EmitBitmapLine](../Source/Final/EmitBitmapLine.asm) копирует 52 байта
из `#6247..#627A` по входному DE, затем меняет четыре слова SP
в исходном шаблоне. Копия сохраняет прежние слова, включая возможное
несоответствие второй половины первой. Новые вторые половины
вычисляются только после копирования, прибавлением `#10`.

Первые адреса берутся из `#6248` и `#6255`, следующие строки вычисляет
[NextBitmapLine](../Source/Final/NextBitmapLine.asm). В штатном шаблоне
источник имеет столбец 0, а приёмник указывает за первой половиной
строки, столбец 16. Номера строк двух сторон могут различаться.
После строки 191 адрес источника становится `#D800`, первый адрес
приёмника `#5810`, второй адрес приёмника `#5820`.

На выходе BC=`#0010`, DE увеличен на 52, HL равен второму новому
адресу приёмника. RET снимает внешний возврат. Каждый из двух CALL
использует одно и то же слово под входным SP, сначала записывает
`#621C`, затем `#622C`. Других собственных стековых записей нет.
Альтернативные пары и индексные регистры сохраняются.

Последний ADD HL,BC задаёт H, N, C и биты 5/3 F, сохраняя S, Z и
P/V последнего вызова NextBitmapLine. Для указанного диапазона
строк S, Z, N и C равны нулю. Внутри знакоместа A содержит номер
следующей строки 1..7, P/V отражает чётность этого байта. На границе
знакомест P/V равен нулю, A содержит `#10` при переходе между третями
либо старший байт нового первого адреса приёмника.

[Модель](../Tools/Disasm/Research/CheckFinalEmitBitmapLine.py) исполняет
оригинальную процедуру для всех 192×192 пар строк. Ожидаемые адреса
получены из экранной геометрии, без вызова NextBitmapLine в эталоне.
Вторые половины перед копированием намеренно имеют другие значения,
проверяя порядок копирования и изменения. Сверены все регистры кроме
R/T, все 52 байта копии и кратность всех 64 записей в память.
[Отчёт](../Tools/Disasm/Reports/FinalEmitBitmapLineVerification.json).

Тест не исполняет полученную копию и не проверяет перекрытия областей,
прерывания или произвольные столбцы. Исполнение всей созданной цепочки
и её итоговый растр проверяет [модель финального построителя](../Tools/Disasm/Research/CheckFinal.py),
описанная в [разборе финала](Final.md).
