# Таблица приближений корня D3D

[Исходная страница C500](../Source/D3D/Data/PreviewRootSamples.asm)
содержит 256 байтов в банке 4, смещения 0500..05FF записи D3D. Она
начинается после синусоиды и заканчивается перед буфером проекции C600.

При индексе 0 исходное значение равно 0. Для индексов 1..63 значения
равны 16 × max(2, round(sqrt(индекс))). Для 64..255 значение совпадает
с round(sqrt(256 × индекс)), кроме двух сохранённых случаев.

| Индекс | Исходный байт | Значение формулы |
|---|---|---|
| AF | D3 | D4 |
| F4 | F0 | FA |

[Проверка](../Tools/Disasm/Research/PreviewRootSamples.py) сверяет все
256 значений и эти два отличия целочисленной арифметикой.
[Отчёт](../Tools/Disasm/Reports/PreviewRootSamplesClassification.json)
отделяет установленную числовую форму от неизвестного потребителя.
Таблица сохраняется литералами, исходные байты не пересчитываются.
