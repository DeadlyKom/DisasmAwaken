# Изменяемые пороги параметров ACTION

[ApplyParameterSet](../Source/Action/ApplyParameterSet.asm) изменяет
три подтверждённых операнда CP. Это байты исполняемых инструкций,
а не новые переменные в отдельной памяти. Исходные значения остаются
в собираемых инструкциях, во время работы их заменяет маршрутизатор
пятнадцатибайтового набора.

| Поле набора | Имя адреса операнда | Адрес | Запись из | Исходное значение | Сравниваемый байт |
|---|---|---|---|---|---|
| 07 | Class0RLimit | 6615, банк 5 | AC84 | 70 | аппаратный R класса 0 |
| 08 | RandomLowLimit | E6E7, банк 0 | AC89 | A0 | новый младший байт Stream10 |
| 0A | Class3RLimit | 65E5, банк 5 | AC93 | 06 | аппаратный R класса 3 |

Писатель находится в фиксированном банке 2. Для E6E7 требуется выбранный
банк 0, как и задаёт договор ApplyParameterSet. Поля и адреса не
приравниваются к одноимённым смещениям FActionRecord. Названия находятся
в существующем ActionApplyParametersState, каждое EQU обозначает адрес
байта операнда, а не текущее числовое значение порога.

## Условия исполнения

[ConfigureClass0Link](../Source/Action/ConfigureClass0Link.asm) сравнивает
прочитанный аппаратный R с текущим Class0RLimit. При R меньше порога
поиск связи пропускается. При равенстве или большем R выполняется
общий SelectLink. Исходное 70 является только начальным байтом CP.
Другие обработчики со своим неизменяемым CP 70 этим не затрагиваются.

[FindFilteredRecordOr26](../Source/Action/FindFilteredRecordOr26.asm)
обновляет Stream10. Если новый L не меньше текущего RandomLowLimit,
возвращает специальный код 1A, иначе начинает поиск разрешённых классов.
При пороге ноль код 1A выбирается для любого L. При пороге FF поиск
пропускается только для нового L=FF. Период и равномерность потока
не установлены, вероятность ветви из одного порога не выводится.

[ConfigureClass3Link](../Source/Action/ConfigureClass3Link.asm) сравнивает
аппаратный R с текущим Class3RLimit. При R не меньше порога использует
обычный фильтр классов 5/14. При меньшем R проверяет Gate и Stream8
перед специальным кодом 1A. Порог ноль исключает специальную ветвь,
исходное значение 06 не является неизменной характеристикой алгоритма.

Все разряды 7..0 каждого порога принадлежат одному беззнаковому числу,
независимые флаги не назначаются. Значение FF не является служебным
запретом, сравнение использует его как 255. Во время одного вызова
порог должен оставаться стабильным, вмешательство IRQ исключено
договором. Само изменение байта операнда не меняет число M1 CP.

## Проверка

[Модель изменённых порогов](../Tools/Disasm/Research/CheckActionParameterThresholds.py)
выполнила 196608 сценариев. Для каждого из трёх входов проверены
все 256 порогов и все 256 значений сравниваемого байта. У класса 0
и класса 3 это фактически прочитанный R, у общего фильтра новый L.
Значение A дополнительно наблюдается перед самой CP, поэтому охват
не подменяется набором исходных счётчиков либо семян.

Исполняются реальные подстановка, потоки, фильтры и преобразователи.
Сверены точные регистры, флаги, R, SP, все восемь банков RAM и значения
с кратностью записей. Пороги задаются непосредственно в RAM модели.
ApplyParameterSet этим тестом не вызывается, его маршрутизация уже
[проверена отдельно](ActionApplyParameters.md). Три непосредственных
писателя статически сопоставлены с реальными CP и внесены в
[реестр самомодификации](ModifiedCode.md).

Ранее опубликованные 402384 сценария классов проверяли исходные байты
70/A0/06. Они не объявляются доказательством всех изменённых режимов.
Новая проверка покрывает отдельные полные пары входа и порога,
не полное произведение трёх порогов, потоков и всех списков.
Сборка, IRQ и нативная игра не выполнялись.
