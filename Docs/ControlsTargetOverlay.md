# XOR рамки и значков объектов

[ToggleTargetOverlay](../Source/Controls/ToggleTargetOverlay.asm)
инвертирует поперечные и боковые маски двух коротких рамок. При входном
`A = 1` после этого возвращает управление. Иначе инвертирует верхнюю
полосу и 87 строк боковых битов полной рамки.

Список объектов читается с шагом `#40`. Для значка нужна доступная
проекция, неотрицательная глубина со старшим байтом от 6 и координаты
в диапазонах `80 ≤ X < 174`, `14 ≤ Y < 90`. Пропускаются класс
`#14`, записи с маркером в первой компоненте и записи с байтом
`#80` по смещению `#1B`. На пути проверки маркера младший байт
`#80` завершает обход.

В [ProjectOverlayCoordinates](../Source/Action/ProjectOverlayCoordinates.asm)
по `ADC5` координаты получаются из двух отношений с общим
знаменателем глубины. На допущенных входах к горизонтальному
отношению прибавляется 128, к вертикальному 48. Шаблон начинается
с `#EB0E + 16 × ((X − 4) AND 7)`. При совпадении индекса с одним
из трёх байтов выделения добавляется 128. Две колонки восьми строк
объединяются с буфером через XOR, первый байт находится по
`#8000 + 32 × (Y − 4) + floor((X − 4)/8)`.

[Модель](../Tools/Disasm/Research/CheckControlsTargetOverlay.py)
прошла 288 сценариев, включая 81 обычный и 81 выделенный значок.
Сверены 3072 байта буфера, стек и возврат. Полный регистровый
контракт и нативный запуск отдельно не проверялись.
