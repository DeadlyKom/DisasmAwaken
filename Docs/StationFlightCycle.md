# Сквозной переход между станцией и полётом

[Модель](../Tools/Disasm/Research/CheckStationFlightCycle.py) начинает исполнение
исходного STATIONF по 6300. Восьмой вход в цикл станции по 9A81 оставляет
SP=5FFF, страницу 10 и выбранный корабль 06. Далее модель вызывает штатный
вход BeginTransition по 7E5A. Выбор элемента в интерфейсе для этого шага
задаётся вызовом входа.

Перед вылетом оба профиля исполняют исходный LANG. Событие 5 получает
индекс строки оборудования 23. Начальное состояние корабля 06 даёт
сообщение 6 и оставляет код FF и исходные 2 000 кредитов. Для успешной
покупки задаются корабль 00 и 10 000 кредитов. Код FE записывает сам
LANG, он же списывает цену. Выбор строки задаётся на границе вызова
интерпретатора, интерфейс торговли отдельно описан в
[модели оборудования](../Tools/Disasm/Research/CheckOriginalEquipmentTrade.py).

[Переход в ACTION](StationExit.md) сохраняет 512 байтов состояния станции
в 4000..41FF, вызывает файловый сервис с ключом ACTION с типом C и получает
управление по 4236. Исходный код копирует все 512 байтов в 9BBD..9DBC, после
чего исполняются перенос, загрузочные процедуры ACTION и
[64 полных полётных кадра](ActionFlightCycle.md).

[Команда возврата](ActionStationReturnCommand.md) проверена в двух профилях.
В обоих случаях реальный сканер считывает замкнутый бит 3 порта FBFE и
через запись Index12, восемнадцатую при счёте с нуля, вызывает 7606.

- Исходный байт оснащения FF сохраняется. Команда возвращается в
  RestoreKeyScanFrame, сканирование завершается, следующий кадр начинается.
- Приобретённый код FE сохраняется до команды возврата. После 64 кадров
  команда списывает его до FF и запускает PrepareStationReload. Этот код
  сохраняет 512 байтов после перестановки двух младших полей счётчика.
  Копия LoadStationStateRelay вызывает файловый сервис с ключом STATIONF
  с типом C и продолжает по 421F. Сверены 481 байт, восстановленный из
  копии в 983B..9A1B, и 31 байт из свежего файла в 9A1C..9A3A. После
  перезапуска проверены восемь входов в цикл станции с SP=5FFF.

[Отчёт](../Tools/Disasm/Reports/StationFlightCycleVerification.json) привязан
к хешу исходного диска. Модель подставляет дисковые сервисы по каталогу и
содержимому этого образа. Нажатие моделируется ответом порта. В циклах TraceFlight действуют
модельные прерывания. Проверка охватывает ограниченные участки между ними,
сборка и нативный запуск в этой серии не выполнялись.
