# Отрицание внешних строк базиса

[NegateOuterBasisRows](../Source/Action/NegateOuterBasisRows.asm), исходные AFF5..B043 фиксированного ACTION банка 2, изменяет шесть слов [физического базиса](ActionRenderBasis.md). Порядок операций C20, C21, C22, C00, C01, C02 соответствует отрицанию строк 2 и 0 матрицы, хранящейся по столбцам. Средняя строка C10, C11, C12 не меняется. Слова не переставляются.

Для каждого слова вычисляется `new=(-old) AND FFFF`. Перед каждым SBC явно сбрасывается Carry через OR A, входной Carry не влияет на результат. A при этом не меняется. Переполнение сохраняется, в частности 8000 остаётся 8000 с PV=1 для соответствующего SBC. Нормализации, насыщения или исправления экстремального значения нет.

После RET HL содержит отрицание исходного C02, DE содержит исходный C02, BC и A сохранены. F определяется последним SBC, то есть отрицанием C02, а не входным A. Альтернативные регистры, IX/IY, I, IM, IFF и paging сохраняются. SP увеличен на два обычным RET, временных записей стека нет. Выполняются ровно 43 M1, бит 7 R сохраняется. Порты не используются.

В исходной клавиатурной ветви 762A присутствует CALL AFF5 до повторной инициализации банковых точек и смены опкодов координатного направления. [Полный переключатель вида](ActionViewDirectionCommand.md) теперь отдельно выделен, его 2568 сценариев проверяют настоящие дочерние тела. Направление осей и игровой вид не назначаются только по виду шести отрицаний.

[Модель](../Tools/Disasm/Research/CheckActionReverseViewBasis.py) проверила 66304 сценария. Все 65536 значений каждого из шести слов проверены одновременно, затем проверены 512 смешанных матриц и 256 профилей A/F. [Отчёт](../Tools/Disasm/Reports/ActionReverseViewBasisVerification.json) подтверждает точные архитектурные регистры, флаги, R и SP, всю RAM и упорядоченные двенадцать записей. Три слова средней строки варьируются и остаются неизменными. Полное произведение шести 16-битовых входов не перебиралось.

Это локальная проверка исходных инструкций, аппаратные IRQ не вмешиваются. Точные такты, полный переключатель вида и нативное изображение не проверялись. Ассемблер не запускался. [Факты и имена физических слов](../Tools/Disasm/Research/ActionReverseViewBasisFacts.py) используются [издателем подтверждённых фрагментов](../Tools/Disasm/Research/PublishActionTargetCommands.py), исследовательский Python для обычной сборки не требуется.
