# Поиск активных соседей

[HasActiveNeighbor](../Source/Text/HasActiveNeighbor.asm) выбирает пары границ по #964E и значения по #988E. [HasSecondActiveNeighbor](../Source/Text/HasSecondActiveNeighbor.asm) использует пары по #9690 и значения по #98F6. Общий ScanAtBases принимает BC базу пар, DE базу значений. Слово индекса лежит на CPU-стеке поверх возврата, старший байт игнорируется.

Выбранный адрес равен база_значений+индекс. Адрес пары равен база_границ+((2*индекс) AND FF). Удвоение выполняется в A, поэтому индексы 0 и 128 используют одну пару границ, но разные выбранные значения. Это исходный алгоритм, не расширенное шестнадцатибитное удвоение.

Первый байт пары является отрицательным левым пределом, число проверяемых предыдущих элементов равно (-байт) AND FF. Значение FF даёт один шаг назад, FE два, 01 даёт 255 шагов. Второй байт задаёт число последующих элементов напрямую. Выбранный элемент не проверяется.

Сначала сканируются левые соседи до первого активного. Перед возвратом восстанавливается HL выбранного элемента. Если слева ничего нет, HL восстанавливается и начинается правый поиск, после которого HL остаётся у найденного правого соседа либо после всех заданных шагов. Значения с установленным bit7 инвертируются, остальные используются напрямую, активен ненулевой результат. Таким образом, исходные 00 и FF неактивны, все остальные активны.

DE=1 при найденном соседе, иначе 0. A содержит декодированное ненулевое значение либо 0. При успехе F от OR A, при отсутствии у двух штатных входов F=42 от последнего DEC C. У общего ScanAtBases, если обе границы нулевые, ни одного OR A не выполняется, Carry остаётся от сложения адреса пары. При переносе этого сложения F=43, Z всё равно установлен. B сохраняет старший байт базы пар, C содержит остаток текущего счётчика, при полном исчерпании C=0. При найденном левом соседе на расстоянии d C=(левый_байт+d-1) AND FF, при правом C=правый_предел-d+1. Альтернативные и индексные регистры, I и IFF сохранены, SP увеличен на четыре.

Границы таблиц не проверяются. [Физические пары](EquipmentPhysicalTables.md)
задают непрерывные группы соседей. Для второго набора индекс 13 читает
клавиатурный якорь по #96AA. Игровые связи конкретных строк требуют
отдельного подтверждения по сценариям.

[CheckActiveNeighbors.py](../Tools/Disasm/Research/CheckActiveNeighbors.py) исполняет оба исходных входа и общий хвост в 12291 случае, включая три случая переноса адреса при нулевых границах. Охвачены все байты индекса и обеих границ, отсутствие активности, активные соседи, инвертированные байты и оборачивание удвоенного индекса. Сверены результат, полный F, A/HL/BC/DE, SP и сохранность регистров. Отчёт [ActiveNeighborsVerification](../Tools/Disasm/Reports/ActiveNeighborsVerification.json). Прерывания, сборка и нативный игровой запуск не выполнялись.

## Повторное использование индекса и точный R

ScanAtBases снимает индекс через POP HL, затем PUSH DE записывает адрес выбранного элемента в те же два байта. При выходе эта пара остаётся в RAM, исходное слово возврата под ней не меняется. Других собственных записей RAM нет. Оба Entry потребляют индекс и возврат, SP увеличен на четыре.

Для общего ScanAtBases при найденном левом соседе выполнено 20+8*N+C M1, где N число просмотренных соседей, C число CPL для байтов с установленным bit7. Если слева ничего не найдено, стоимость равна 25+8*N+C, включая проверенные справа значения до первого активного либо до конца границы. Первый Entry добавляет две M1, второй три из-за явного JP. R меняется с сохранением старшего бита.

Расширенная CheckActiveNeighbors прошла 12291 сценарий с точными R и двумя записями выбранного адреса. Подтверждены неизменность исходного возврата, физические байты LANG и положительный контроль наблюдателя CPU. Полное произведение индексов, границ, данных и R, произвольные перекрытия стека с таблицами и прерывания не проверяются. Игровая семантика зависимостей этим не устанавливается. Сборка и нативный запуск не выполнялись.


## Граница второго списка при индексе 13

Для младшего индекса 13 адрес пары равен #9690+((2*13) AND #FF)=#96AA. Здесь начинается [KeyboardCodes.Anchor](../Source/Station/Data/KeyboardCodes.asm), исходные два байта равны нулю. Таким образом этот индекс читает соседний клавиатурный якорь как пару пределов. Новая четырнадцатая запись границ не создаётся. Оба нулевых предела не дают обхода соседних значений, исходный выбранный элемент тоже не проверяется. Это физическая граница нынешнего образа, назначения отсутствующего списка или естественной игровой достижимости из неё не следует. Соответствующее примечание внесено в ActiveNeighborFacts без перестановки прочих пояснений.
