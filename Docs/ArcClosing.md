# Хвостовые маски растровой дуги в двух состояниях кода

[Ядро E2AB](../Source/Map/RasterizeArcEdges.asm) описано в [ArcKernel](ArcKernel.md). Здесь разобраны внутренние CloseLowTail по E41A, CloseHighTail по E430 и CloseBothTails по E445. Их продолжение RestoreFrame по E3D3 восстанавливает сохранённый SP. Подготовки адресов описаны в [ArcPreparation](ArcPreparation.md), фазы кода в [MapRuntimeProfiles](MapRuntimeProfiles.md).

## Выбор условия поиска

[DFC3](../Source/Map/DrawClippedMapArc.asm) читает байт своего изменяемого операнда по DFC4. Бит 0 выбирает четыре кода переходов по E426, E438, E44F, E460. При установленном бите 0 записывается 38, JR C, при сброшенном бите 0 записывается 30, JR NC. Старшие семь битов параметра на этот выбор не влияют. Эти записи выполняются до последующей проверки минимального радиуса.

JR C завершает сканирование на единице, JR NC на нуле. Поэтому формулы исходного образа с JR C не описывают второй режим. Обе ветви обрабатывают уже существующие пиксельные байты, результат зависит от прежнего рисунка.

## Младший хвост, CloseLowTail

H и E задают адрес, начальный L заменяется на E. Пусть v — исходный байт. При JR C результат равен `v OR ((v-1) AND 255)`, младшие нули ниже первой единицы становятся единицами. При JR NC для ненулевого v результат равен `v AND ((v+1) AND 255)`, младшие единицы перед первым нулём очищаются.

Нулевой байт обрабатывается отдельным переходом и в обоих режимах становится FF. Например, 28 при JR C превращается в 2F, а при JR NC остаётся 28. FF при JR C остаётся FF, при JR NC становится 00.

Итоговый B равен нулю для исходного v=0. Иначе B=v SHR(k+1), где k есть число пропущенных младших нулей для JR C либо единиц для JR NC. Если JR NC встречает FF, k=8 и B=0. C и DE сохраняются, HL указывает на изменённый байт.

## Старший хвост, CloseHighTail

Входной HL задаёт адрес. Нулевой v в обоих режимах превращается в FF. При ненулевом v режим JR C устанавливает старшие нули выше старшей единицы, результат `v OR ((255 SHL bit_length(v)) AND 255)`. JR NC очищает старшие единицы до первого нуля. Если k — число старших единиц, результат `v AND (255 SHR k)`.

Например, 28 даёт E8 при JR C и 28 при JR NC. FF даёт FF при JR C и 00 при JR NC. Итоговый B=FF SHR k, где k — число пропущенных старших нулей для JR C либо единиц для JR NC. Для v=0 итоговый B=0. HL, DE и C сохраняются.

## Два хвоста, CloseBothTails

E445 начинается с EXX, поэтому растровые адреса и маски поступают в альтернативном наборе. После обмена сначала изменяется правый байт по HL по правилу младшего хвоста, затем L=E выбирает левый байт и применяется правило старшего хвоста.

При совпадении адресов вторая операция читает уже изменённый байт. Например, для общего нулевого байта JR C последовательно даёт FF и FF, а JR NC даёт FF и 00. Для общего FF режим JR NC сначала получает 00, затем особая нулевая ветвь возвращает FF. Подменять второе чтение исходным снимком нельзя.

Итоговый HL — левый адрес, DE и C после EXX сохраняются, B определяется последним старшим хвостом от фактически прочитанного левого байта. Прежние основные HL, DE, BC после EXX находятся в альтернативном наборе и дальше не меняются. Альтернативный AF этот обмен не затрагивает.

## Внешний кадр

Все хвосты переходят в RestoreFrame. SP загружается из MapState.RasterStack, POP AF восстанавливает внешний AF, RET снимает настоящий адрес возврата. FArcReturnFrame содержит SavedAF по смещению 0 и ReturnAddress по смещению 2, размер 4. После выхода SP=RasterStack+4. Промежуточные флаги сканирования не возвращаются вызывающему коду. IX, IY, I и IFF не меняются.

## Проверка

[Модель](../Tools/Disasm/Research/CheckArcClosing.py) проверила 393728 случаев, оба режима для всех байтов, 65536 пар, всех снимаемых F и случаев общего адреса. Дополнительно исполнен настоящий пролог DFC3 для всех 256 значений DFC4, подтверждены все четыре записываемых кода. [Отчёт](../Tools/Disasm/Reports/ArcClosingVerification.json) разделяет эти 256 настроек и проверки самих масок. Подмен вызовов нет. Проверка этих масок сама по себе не доказывает диспетчер DFC3, IRQ, сборка и нативный запуск не выполнялись.
