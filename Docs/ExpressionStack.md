# Физические слова стека выражений

[ExpressionStack](../Source/Text/Data/ExpressionStack.asm) представляет исходные 20 байтов CA67..CA7A физическим экземпляром FExpressionStackStorage. Десять полей Word00..Word09 размером по два байта имеют смещения 0, 2, 4, 6, 8, 10, 12, 14, 16 и 18. Начальные значения всех десяти слов в исследуемом образе равны нулю. Названия обозначают позиции переменного стека, постоянное назначение отдельным слотам не приписывается.

[TestExpression](../Source/Text/TestExpression.asm) устанавливает HL' в начало этого диапазона. Читатели полей и EmitOperator добавляют по одному слову через альтернативный указатель. CallExpression читает последние Left, Handler и Right, возвращает вершину на начало тройки и записывает одно слово результата. Скобочный читатель действует на том же стеке, временно добавляя слова вложенного выражения. [Алгоритм](ExpressionControl.md) описывает последовательность вычисления и границы терминаторов.

После CA7A физически следует [AssignmentScratch](../Source/Text/Data/AssignmentScratch.asm), начинающийся по CA7B. Это граница исходного промежутка, а не проверяемое программой ограничение глубины. Код не сравнивает указатель с концом диапазона. Глубокое выражение может записать следующие исходные области, нельзя обещать безопасные десять слов для любого сценария. Новое место под стек не выделяется.

AssignValue использует собственную запись по CA7B и временно сохраняет прежний HL', но её общий буфер и операнды писателей не допускают произвольного повторного входа. Первоначальный нулевой массив не является мусором, он изменяется при вычислении сценария.

[VerifySources](../Tools/Disasm/VerifySources.py) сверяет десять фактических инициализаторов с исходными байтами LANG. [Модель выражений](../Tools/Disasm/Research/CheckExpressionControl.py) проверяет изменение вершины и физический результат на настоящих исходных инструкциях. Сборка и проверка произвольной глубины не выполнялись.
