# Создание случайной записи класса 20

[CreateRandomClass20Record](../Source/Action/CreateRandomClass20Record.asm)
занимает исходные байты ACTION `#617D..#6200`, перенесённые в фиксированную
RAM банка 5. Штатный игровой вызывающий путь пока не установлен.
Номер класса установлен по физической записи, игровое название не назначается.

Процедура вызывает [FindReusableRecord](../Source/Action/FindReusableRecord.asm).
Отказ завершает внешний вызов. Поиск сохраняет своё исходное поведение,
в том числе очистку ReuseByte пропускаемых слотов со значением FF.
При успехе один раз обновляется [случайный поток 8](ActionFoldedRandom.md).

Из младшего и старшего байтов нового слова получаются две компоненты.
Для знакового байта s используется `4*s + 1024` при s>=0,
либо `4*s - 1024` при s<0. Это создаёт отступ от нулевой области,
а не обычное умножение с последующим ограничением. Третья компонента
равна 30000 при нулевом байте `#6E75`, иначе равна -30000.
Общий игровой смысл этого байта пока не установлен.

Затем исполняется настоящий
[TransformVectorTransposed](../Source/Action/TransformVectorTransposed.asm).
Все три возвращённых слова записываются в Components. При переполнении
процедура не отказывается от создания, частично сохранённые результаты
дочернего преобразования остаются действующими.

| Поле | Исходное значение |
|---|---|
| ModelOffset | C0 |
| OffsetPhase0, OffsetPhase1, OffsetPhase2 | 0C, 1D, 37 |
| StateCode | 04 |
| ClassCode | 14, десятичное 20 |
| Unknown13 | FA |
| ReuseByte, LinkFlags, Unknown24 | 00 |
| TargetCodeStep, Unknown10, TargetIndex | 02 |

Остальные поля свободного слота не инициализируются и сохраняют прежние
байты. Связь с другой записью здесь не создаётся. Значения неизвестных
полей описаны как значения, их игровые роли не выдумываются.

При успехе AF=0044, HL, DE, BC содержат результаты преобразования.
Альтернативные пары HL', DE', BC' оставлены потоком 8, AF' оставлен
преобразованием. IX и paging сохраняются. Дополнительная глубина стека
составляет восемь байтов, включая рамки дочерних вызовов.

[Композиционная модель](../Tools/Disasm/Research/CheckActionClass20Spawn.py)
сопоставляет числовой эталон с исполнением оригинальных инструкций,
не подменяя поиск, поток или преобразование. Проверяются все регистры,
R, SP, восемь физических банков, значения и кратность записей.
Исчерпаны все 65536 слов начального состояния потока на выбранных
свёртках, предусмотрены разные места выделения, отказ и матрицы.
Полное произведение входных данных, аппаратные IRQ, сборка и нативный
запуск игры этой проверкой не подтверждаются.
