# Подготовка огибающей в музыкальном тике

[StageEnvelopeAndNoise](../Source/Music/StageEnvelopeAndNoise.asm) переносит форму огибающей и базовый шум в буфер AY, перезапускает базовый период и подготавливает отложенное скольжение. [CommitEnvelopeSlide](../Source/Music/CommitEnvelopeSlide.asm) завершает установку шага и последовательно входит в [AdvancePatternA](../Source/Music/AdvancePatternA.asm).

[Наблюдение](../Tools/Disasm/Research/InspectMusicRuntimeFlow.py) исполнило инициализацию MUZ1 и 5377 кадров до первого возврата списка позиций на петлю. В [реестре](../Tools/Disasm/Reports/MusicRuntimeFlow.json) зафиксированы 1010 исполненных адресов, варианты изменяемых инструкций и их писатели. Обнаружена прежде не выделенная инструкция `LD HL,nn` по DF6D. Она исполняется после превращения `JR` по DF6B в `LD B,n`, при неизменной длине двухбайтовой команды. Число nn является изменяемым операндом, исходное значение ноль.

Три исходных байта DF6D..DF6F выделены из прежнего бинарного диапазона в исходник, физические адреса и байты сохранены. Наблюдение потока отделяется от независимой проверки состояния ниже. Аппаратное воспроизведение и полный набор команд PT3 не проверены.

## Чтение команды

[ReadEnvelopeSlide](../Source/Music/ReadEnvelopeSlide.asm) читает по DE задержку, младший и старший байты шага. Выход HL содержит шаг, DE продвинут на три, A=06, F сохранён. Записаны Delay по DF74, Step по DF6E и код SlideGate=06 по DF6B. Обработчик выделен из физического хвоста [ClearAyRegisters](../Source/Music/ClearAyRegisters.asm) после его RET. Само глушение AY этот хвост не исполняет. Указатель DB8C находится в трёх исходных таблицах по DDCE, DDEE и DE0E.

## Применение перед разбором канала A

Shape по DF48 переносится в буфер AY13 по DC0D. Если он ненулевой, Base по DF50 переносится в EnvelopeBase по E2F1, а Shape, SlideOffset по E2EE и SlideCounter по E2FA обнуляются. При нуле эти поля сохраняются. Ноль в буфере AY13 означает отсутствие новой аппаратной записи формы, он не принуждает запись аппаратной формы 0. Код вывода по E370..E37A проверяет буфер, пишет ненулевую форму и очищает буфер.

Затем Phase по E37D получает RowTempo из изменяемого операнда DF62. Исходный байт инструкции равен 03, но InitializeModule заменяет его байтом заголовка модуля со смещения 100, команда 09 может изменить его позже. Это числовой счётчик распределённого разбора каналов, не маска микшера. При входной фазе 2 выполняется обработка B, при фазе 1 обработка C, остальные значения уменьшаются с байтовым оборачиванием. Noise по DF67 переносится в буфер AY6 по DC06.

В исходном состоянии SlideGate содержит `18 12`, команду JR на DF7F. Запись 06 превращает эти же два байта в `LD B,12`, и выполнение доходит до PendingStep по DF6D. Его слово загружается в HL и записывается в SlideStep по E302. Delay записывается в текущий счётчик и перезагрузку E309. В конце A получает E, штатное E=18 восстанавливает JR и выключает повторное применение команды. Значения шага и задержки не нормализуются.

У блоков подготовки нет собственного RET. Контракт фиксирует состояние на границе DF7F, где продолжается текущий кадровый вызов. До этой границы C и DE сохранены, альтернативные пары, IX, IY и SP не меняются. F=44, A равен Noise без отложенной команды либо 18 после неё. При выключенной команде HL сохранён только при нулевой форме, иначе он обнулён. При включённой команде HL равен Step, B=12. Прямой вход в CommitEnvelopeSlide сохраняет HL, DE, BC и F, меняет A на E.

## Независимые проверки

[CheckMusicEnvelopeStaging.py](../Tools/Disasm/Research/CheckMusicEnvelopeStaging.py) проверяет 3072 подготовки и 6144 фиксации шага, все байты формы, задержки и темпа, граничные слова шага и оба состояния изменяемого JR. Сравнивается вся память, выходные и сохраняемые регистры на границе DF7F. [Отчёт](../Tools/Disasm/Reports/MusicEnvelopeStagingVerification.json).

[CheckMusicEnvelopeCommand.py](../Tools/Disasm/Research/CheckMusicEnvelopeCommand.py) проверяет 3072 чтения команды, все байты задержки и F, переход указателя через границу страницы, точные записи операндов и физические указатели трёх таблиц. [Отчёт](../Tools/Disasm/Reports/MusicEnvelopeCommandVerification.json). Эти модели не исполняют последующий AdvancePatternA и не являются независимым аудиосинтезатором.
