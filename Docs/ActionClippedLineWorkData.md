# Физическое рабочее состояние отсечения ломаной

[Описание и обратимый разбор](../Tools/Disasm/Research/ActionClippedLineWorkData.py) оформляют 11 исходных байтов уже разобранных [RenderClippedRecords](../Source/Action/RenderClippedRecords.asm) и [RenderInsideRecords](../Source/Action/RenderInsideRecords.asm). Новая память не выделяется, порядок файлов и все нули первоначального состояния сохранены.

| Адрес | Физическая запись | Поля |
| --- | --- | --- |
| 8D3A..8D3F | [ClipLineHead](../Source/Action/Data/ClipLineHead.asm), FClipLineHead | CurrentSecond, CurrentFirst, NextSecond, три полных слова |
| 8D4A..8D4D | [ClipLineTail](../Source/Action/Data/ClipLineTail.asm), FClipLineTail | NextFirst, полное слово, CurrentCode и NextCode, два байта |
| 8D5A | [FaceGate](../Source/Action/Data/FaceGate.asm), FFaceGateCode | Code, полный байт состояния ориентации |

Две части линейного контекста разделены реальной десятибайтовой маской полигона по 8D40..8D49. Она остаётся на своём месте, общая фиктивная непрерывная структура поверх неё не создаётся. Существующие EQU из ActionClippedPacketRendererState связаны ASSERT с физическими полями. Шесть координатных младших байтов и старшие байты не смешаны с упакованными конечными точками [растеризатора](ActionRasterWorkData.md).

CurrentSecond/CurrentFirst содержат полные координаты первого конца текущего сегмента. NextSecond/NextFirst содержат следующий конец. CurrentCode/NextCode содержат полные ClipCode по договору [кодирования и отсечения точек](ActionClippedPacketRenderer.md). RenderClippedRecords сохраняет следующий конец и его код даже при пропуске сегмента, поэтому эти поля не являются только выходом успешного отсечения. Доказанные числовые единицы координат и ограничения сохраняются в договоре алгоритма.

FaceGate является числовым кодом полного байта, не набором независимых разрядных признаков. Ноль допускает ломаную, связанную с предыдущей гранью, любое ненулевое значение подавляет её. Писатели записывают 0 для отрицательной ориентации и 1 для неотрицательной. Нулевой код точки либо общий внешний предел после отрицательной ориентации не возвращает FaceGate в 1. Прежний входной полный байт может учитываться до первой грани.

Последующие пять байтов 8D5B..8D5F остаются неизвестными. Указание на FaceGate по 8D5A не доказывает назначения всей соседней шестибайтовой области.

Действуют прежние [3906 композиционных сценариев отсечения](../Tools/Disasm/Reports/ActionClippedPacketRendererVerification.json) и [проверка внутреннего рисователя](../Tools/Disasm/Reports/ActionPacketRendererVerification.json). Физическая публикация проверяет реальные STRUCT, все 11 байтов, смещения, размеры и семь привязок, инструкции не изменяются. Сборка и нативный запуск новой разметки не исполнялись.
