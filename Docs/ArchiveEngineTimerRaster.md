# Растр цифр таймера ENGINE

Вход `#4AF2` рассчитывает адрес первого байта левой цифры в рабочем
фоне. Для начала окна `ViewColumn` и вертикального смещения `y`
адрес равен `ViewColumn + 92 × (y + 189) + 15`. Правая цифра начинается
на байт правее. Следующая строка цифры лежит на 92 байта ниже числом,
поскольку окно выводит исходные строки в обратном вертикальном порядке.
[Расчёт адреса](../Source/ArchiveEngine/CalculateTimerAddress.asm)
· [Умножение](../Source/ArchiveEngine/MultiplyByteWord.asm)

По `#4B28` лежат десять 32-байтовых шаблонов. Для каждой из 16 строк
идут байт маски и байт рисунка. Для исходного пиксельного байта `p`
результат равен `(p AND маска) OR рисунок`. Вход `#4A95` берёт старшую
и младшую цифры из BCD и независимо выбирает два шаблона. Сначала
он сохраняет фон левой цифры по чётным адресам буфера `#4C68`, затем
сохраняет фон правой по нечётным. Вход `#4B0B` восстанавливает из
буфера обе колонки по прежнему адресу перед подготовкой нового кадра.
[Две цифры](../Source/ArchiveEngine/DrawTimerDigits.asm)
· [Одна цифра](../Source/ArchiveEngine/DrawTimerGlyph.asm)
· [Восстановление](../Source/ArchiveEngine/RestoreTimerBackground.asm)
· [Физические данные](../Source/ArchiveEngine/Data/TimerRaster.asm)

При выводе окна цифры занимают строки экрана 2–17 и байтовые
столбцы 15–16. Строки 2–14 входят в полную верхнюю часть окна.
Строки 15–17 выводятся через двухбайтовый промежуток между полосами
индикаторов. Это сохраняет цифры и оставляет боковые полосы без записи.
[Вывод окна](Scene1PixelPairs.md#полный-фон-кадра)
· [Индикаторы](ArchiveEngineMeters.md)

В модели сверены 67 328 произведений, все 708 адресов окна и 600
пар операций наложения и восстановления. Во всех шести проверенных
окнах байты цифр дошли до ожидаемых экранных позиций.
