# Пустое событие счётчика

[IgnoreCounterEvent](../Source/Station/IgnoreCounterEvent.asm), исходный EventHandler элемента 1, содержит JP по адресу `#A6EA` во внутренний RET `#A6ED`. Диспетчер может использовать этот внутренний вход напрямую. В обоих случаях сохраняются полный AF, остальные основные, альтернативные и индексные регистры, I, IFF и IM. Память и порты не меняются, SP увеличивается на два, PC берётся с исходной вершины стека. Выборки JP и RET увеличивают младшие семь битов R, через Entry на два, при прямом ReturnNoop на один.

Эта процедура не выполняет тик BCD-счётчика и не читает устройства ввода. [Основной цикл](MainLoopControl.md) обрабатывает накопленный Pulse отдельно, а рисователь DrawItem01 лишь выводит его состояние по собственному договору.

[CheckCounterEvent.py](../Tools/Disasm/Research/CheckCounterEvent.py) проверяет все 65536 AF для каждого входа, сохранность общих, альтернативных и индексных регистров, всей памяти и портов, SP и точное увеличение R. [Отчёт](../Tools/Disasm/Reports/CounterEventVerification.json). Прерывания, сборка и нативный запуск не выполнялись.
