# Общий хвост отказа сканера

[AbortProjectedVertexScan](../Source/Action/AbortProjectedVertexScan.asm) содержит три исходных байта DEF0–DEF2 банка 0. Это общий хвост сканера экранных точек, вход через JR после обнаружения старшего байта 80 второй координаты.

На CPU-стеке сначала лежит сохранённый HL сканера, затем внешний адрес возврата. POP HL восстанавливает указатель, XOR A устанавливает A=0/F=44, RET возвращает внешнему вызывающему коду. Прямой CALL сюда с обычной рамкой некорректен. DE, BC, альтернативный набор, IX/IY, I/IM/IFF и paging сохраняются. SP увеличивается на четыре, RAM не записывается.

Предыдущие коды точек остаются записанными. Нулевой результат не является откатом или очисткой буфера. [Проверка сканера](../Tools/Disasm/Research/CheckActionVertexCodes.py) действительно выполняет этот хвост в 2228 из 525288 сценариев. [Отчёт](../Tools/Disasm/Reports/ActionVertexAbortVerification.json) общий с проверкой сканера, это не 525288 отдельных вызовов хвоста. Время и точное обновление R, IRQ, сборка и нативный запуск не проверялись.
