# Исходные байты рабочих страниц предпросмотра

В записи D3D (слот 6) выделены четыре страницы. При загрузке файла с C000
они попадают в окно банка 4. Из образа берутся исходные байты, вычисленные
позднее значения в файл не подставляются.

| Адреса | Смещение файла | Ресурс |
|---|---|---|
| C800..C8FF | 0800 | [Страница контуров](../Source/D3D/Resources/InitialPreviewContour.bin) |
| C900..C9FF | 0900 | [Старшие байты строк](../Source/D3D/Resources/InitialPreviewRowHigh.bin) |
| CA00..CAFF | 0A00 | [Младшие байты строк](../Source/D3D/Resources/InitialPreviewRowLow.bin) |
| CB00..CBFF | 0B00 | [Байтовые столбцы](../Source/D3D/Resources/InitialPreviewColumn.bin) |

[RenderPreviewInsideFaces](../Source/D3D/RenderPreviewInsideFaces.asm) и
[RenderPreviewClippedFaces](../Source/D3D/RenderPreviewClippedFaces.asm)
копируют пары колонка, строка внутренних граней в C800.
[AppendPreviewClipPoint](../Source/D3D/AppendPreviewClipPoint.asm) и
писатели пересечений дописывают отсечённые пары со смещения ByteCount.
При увеличении младшего байта адрес оборачивается внутри страницы C8.
[FillPreviewPolygon](../Source/D3D/FillPreviewPolygon.asm) использует
пары для обхода рёбер. Исходное содержимое страницы не объявляется
готовым контуром.

[SetupPreviewModel](../Source/D3D/SetupPreviewModel.asm) вызывает
[BuildSpriteLineTable](../Source/Station/BuildSpriteLineTable.asm)
из фиксированной памяти при подключённом банке 4. Построитель заполняет
C900 и CA00 байтами 256 адресов строк и CB00 байтовыми столбцами.
Эти страницы относятся к предпросмотру. Те же CPU-адреса в другом
банке могут иметь самостоятельное назначение.

[Проверка настройки](../Tools/Disasm/Reports/PreviewSetupVerification.json)
исполняет исходный построитель и сверяет все изменённые адреса.
[Проверка пересечений](../Tools/Disasm/Reports/PreviewClipIntersectionsVerification.json)
сверяет страницу C8 и соседние контрольные байты. [Сверка размещения](../Tools/Disasm/Reports/PreviewRenderWorkspaceClassification.json)
подтверждает 1024 дисковых байта. Хвост C7FC..C7FF входит в
[авторский резерв L9D](../Source/D3D/Resources/QueuePageTail.bin).
Область CC00..CDAF оформлена в
[адресных страницах отсечения](PreviewClipTablePages.md).

## Границы смежных таблиц

В штатном профиле вставки `NextFree` изменяется с шагом 14.
Последний узел начинается по `#C7EE` и заканчивается по `#C7FB`.
При `NextFree=#FC` вставщик завершает построение до записи узла.
Это исключает `#C7FC..#C7FF` из узлов очереди при допустимом
состоянии. [Разбор вставки](PreviewQueue.md)

Построитель читает десять начальных байтов записи по `#CDC0`, затем
прибавляет шаг `#40`. Исходное слово `#8080` по `#CE00` завершает
обход до чтения других полей второй записи. Поэтому промежутки
`#CDCA..#CDFF` и `#CE02..#CE3F` этот проход с исходным списком
не читает. [Разбор построителя](PreviewQueueBuild.md)

Таблица указателей одиннадцати моделей занимает `#D000..#D02B`.
Таблица шаблонов заливки занимает `#D100..#D10F`, оба обработчика
граней ограничивают её индекс маской `#07`. Эти границы относятся
к потребителям таблиц. [Модели](PreviewQueueBuild.md) ·
[Заливка](PreviewPolygonFill.md)

## Исходное размещение резервов

Первые 8406 байтов `D3D.C` совпадают с одноимённым файлом из
`awk6.trd`. В этот общий префикс входят все 16 промежутков.
Авторские исходники задают их границы следующим образом.
[Авторский архив](https://opensourcezx.untergrund.net/a_games-awaken_src.html)

| Адреса в банке 4 | Исходное размещение |
|---|---|
| Десять промежутков в `#C200..#C2FF` | Страница L90..L91 в `DATA3D.a` выделена целиком. Переменные и рабочие поля занимают отдельные позиции в её пределах |
| `#C7FC..#C7FF` | Конец зарезервированной страницы L9D за последним полным узлом очереди |
| `#CDCA..#CDFF` и `#CE02..#CE3F` | Хвосты двух записей Carsb длиной `Olen=#40`, первая содержит десять начальных байтов, вторая начинается с маркера `#8080` |
| `#CF04..#CFFF` | Макрос `ADRXX00` в `DATA3D.a` выравнивает указатели L97 до `#D000` |
| `#D02C..#D0FF` | Макрос `ADRXX00` в `DOS.a` выравнивает начало `XR2` до `#D100` |
| `#D110..#D1BF` | Конец резерва `XR2` до кода по `#D1C0`. В исходнике резерв начинается по `#D10A`, первые шесть его нулевых байтов входят в индексируемую таблицу шаблонов текущего рисователя |

Трасса 33 вызовов окна и 66 периодических кадров не зафиксировала
обращений к этим 945 байтам банка 4. В модели IRQ принимается
в проверенных точках HALT. Сверка размещения и трасса относятся
к разным свойствам диапазонов, обращения в других режимах остаются открытыми.
[Сверка с авторскими исходниками](../Tools/Disasm/Reports/PreviewArchivedStorageVerification.json) ·
[Трасса](../Tools/Disasm/Reports/PreviewUnclassifiedAccesses.json)
