# Построитель писателя атрибутов вступления

[BuildAttributeWriter](../Source/Intro/BuildAttributeWriter.asm), вход `692D`,
строит код и таблицы, затем последовательно входит в
[CombineAttributeNibbles](../Source/Intro/CombineAttributeNibbles.asm).
Завершающий RET относится ко всему вызову построителя.

Исходный IXL одновременно задаёт старший и младший байты первого адреса
назначения. Для строки r=0..7 и колонки c=0..3 генерируется `POP HL` и
`LD (nn),HL`, где H=(IXL+r) modulo 256, L=(IXL+2*c) modulo 256.
Перенос между младшим и старшим байтом адреса отсутствует. Всего создаётся
128 байтов кода в `68A9..6928`. Здесь этот код ещё не исполняется, поэтому
допустимость будущих назначений не следует из проверки построения.

[BuildPairedPointers](../Source/Intro/BuildPairedPointers.asm) записывает
по 38 одинаковых указателей в `6000+4*i` и `6100+4*i`.
Значение равно входному DE+i*BC modulo 65536. Два байта между словами
остаются прежними. Последний указатель находится в `6094/6194`.

Матрица `60C0..60FF` использует байты `6993..699A`, а матрица
`61C0..61FF` использует **следующие** байты `699B..69A2`.
Атрибут строки r, колонки c равен `(source[c] AND F0) OR (source[r] AND 0F)`.
После первого вызова HL уже продвинут на восемь, повторного присваивания
`HL=6993` нет. Поэтому второй набор не повторяет первый.

После возврата HL=69A3, DE=6100, BC=699B, A равен исходному байту 69A2,
F=42, IX=0. IYH сохранён, IYL содержит младший полубайт того же байта.
Альтернативные HL'=6929, BC'=0, D'=E'=(входной IXL+8) modulo 256,
AF' сохранён. Конечный RET снимает исходный внешний адрес возврата.
Два вложенных CALL и PUSH BC используют до четырёх байтов ниже входного SP.

[Проверка](../Tools/Disasm/Research/CheckIntroAttributeWriter.py) исполняет
оригинальные дисковые байты вместе с обеими дочерними процедурами.
Отдельная числовая модель задаёт все ожидаемые регистры, RAM и кратность
записей, она не исполняет Z80. Все 256 значений IXL проверены при шести
шагах указателя и трёх положениях CPU-стека, всего 1536 сценариев.
Данные обеих матриц меняются между сценариями.

[Отчёт](../Tools/Disasm/Reports/IntroAttributeWriterVerification.json)
подтверждает регистры кроме R, все восемь физических банков RAM и каждую
запись с её кратностью. Проверка не запускает сборку, не измеряет время,
не исполняет аппаратные IRQ и не заменяет нативную проверку вступления.
