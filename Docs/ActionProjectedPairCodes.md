# Коды границ двух точек

[ClassifyProjectedPair](../Source/Action/ClassifyProjectedPair.asm) занимает EC54..ECA7 ACTION банка 0. Обрабатываются ровно две существующие пятибайтовые `FRenderProjectedPoint` по 8E00 и 8E05. Это отдельный алгоритм от [ClassifyProjectedVertices](../Source/Action/ClassifyProjectedVertices.asm), хотя формат кодов совпадает.

## Формат кода

Младшая тетрада содержит внешние стороны, старшая является её побитовым отрицанием. Схема битов 7..0:

| Бит | При единице |
| --- | --- |
| 7 | First неотрицателен |
| 6 | First меньше 96 либо отрицателен |
| 5 | Second неотрицателен |
| 4 | Second меньше 256 либо отрицателен |
| 3 | First отрицателен |
| 2 | First не меньше 96 и неотрицателен |
| 1 | Second отрицателен, кроме маркера 80xx |
| 0 | Second не меньше 256 и неотрицателен |

Обычный внутренний код равен F0. Противоположные стороны одной оси одновременно не устанавливаются. Сначала проверяется полный старший байт Second=80. Для такого маркера записывается нулевой ClipCode, остальная координатная классификация пропускается. Вторая точка обрабатывается и при маркере первой. Это существенное отличие от общего классификатора вершин, который завершает весь проход при первом отказе.

Первая координата допустима в диапазоне 0..95, вторая в диапазоне 0..255. Отрицательная координата получает только отрицательную сторону. Положительный ненулевой старший байт означает превышение верхней границы. First с нулевым старшим байтом дополнительно сравнивается с 96.

## Результат и побочные эффекты

Оба ClipCode записываются всегда. A содержит OR обычных кодов, F соответствует этому OR. Если оба Second являются маркерами, A=0/F=44. Для одной обычной точки результат ненулевой. Старшая тетрада OR показывает, что хотя бы одна точка не вышла за соответствующую сторону, это используется вызывающим кодом для общего отказа пары.

HL=8E0B, B=0A, C содержит стороны второй точки либо ноль при её маркере. DE, альтернативные HL/DE/BC, IX и IY сохраняются. Альтернативный AF получает 0A/4A от сравнения конца второй записи. Внешний RET увеличивает SP на два, дополнительных стековых записей и OUT нет. Изменение R равно 6 M1 плюс стоимость обеих точек, 14 M1 для маркера и 33..39 M1 для обычной точки.

## Проверка

[Независимая модель](../Tools/Disasm/Research/ReferenceActionProjectedPairCodes.py) использует числовой формат сторон, отдельно считает M1 и не интерпретирует инструкции. [Проверка](../Tools/Disasm/Research/CheckActionProjectedPairCodes.py) исполняет настоящий EC54 до внешнего RET. Проверено 268705 сценариев, четыре полных словарных среза и 9^4 углов, включая все комбинации маркеров. Сравниваются точные регистры, флаги, R, вся 64K RAM и порядок двух записей. [Результат](../Tools/Disasm/Reports/ActionProjectedPairCodesVerification.json).

Полное произведение четырёх слов не исчерпано. Аппаратные IRQ, точные T, сборка и нативный вывод не проверялись.
