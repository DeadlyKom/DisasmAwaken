# Дисковая копия блока полётного состояния

Все 7 213 байтов DATAS.C побайтно совпадают с ACTION.C по файловым
смещениям `#2C00..#482C`. В загруженном ACTION это `#8C00..#A82C`.
Две физические копии хранятся отдельно. Суффикс из 211 байтов выделенных
секторов DATAS также сохраняется.
[Физическое подключение DATAS](../Source/Files/18_DATAS.inc)

## Чтение при загрузке ACTION

В двух сквозных профилях ROM TR-DOS 5.04T читает первый сектор DATAS
при вылете и после гиперперехода. Этот сектор непосредственно следует
за 160 секторами ACTION. Номер дорожки 67, номер сектора 12 в контроллере.
Ветка файловой операции `#0E` с `A=0` сначала читает его в `#5D25`,
затем возвращается по нулевому остатку длины без копирования из буфера.
Это физическое чтение 256 байтов при загрузке ACTION. Вход отдельной
загрузки полного файла DATAS и её возможные потребители остаются открытыми.
Девятибайтовый ключ `DATAS   C` встречается на исходном диске один раз,
в записи каталога по `#0120`. Это охватывает буквальный ключ, который
можно скопировать из физического образа без декодирования.
[Сквозной прогон](StationFlightCycle.md#сквозной-прогон-с-rom-tr-dos)

Проверка всего TRD нашла 38 байтовых последовательностей прямого
`CALL` или `JP` по `#3D13`, включая условные формы. Все 28 совпадений
в секторах активных файлов совпали с подтверждёнными инструкциями
загрузчиков и операций SAVE. Два остальных совпадения лежат в выделенных
секторах удалённой записи 0, восемь во внекаталожных секторах.
Одно из внекаталожных совпадений ведёт к поиску отсутствующего
`START.C` в [архивном меню](StartArchiveMenu.md).
В отчёте для каждого активного обращения указаны адрес исполнения,
слот и физическое смещение. Эта сверка охватывает буквальные цели
`#3D13`. Вызовы по вычисляемому адресу и прямое программирование
контроллера требуют отдельных доказательств.
[Реестр совпадений](../Tools/Disasm/Reports/DatasMirrorVerification.json)

## Разметка одноимённой области ACTION

| Вид диапазона | Байтов |
| --- | ---: |
| Типизированные физические данные | 4 277 |
| Ресурсы с установленной физической ролью | 2 863 |
| Неразобранные промежутки | 73 |

Начальные `#0200` байтов совпадают также с таблицами D3D. В загруженном
ACTION доказаны буквальные чтения масок обоих краёв широкого пролёта.
Эти чтения происходят из рабочей копии ACTION. Для полного сопоставления
с текущими исходниками отчёт перечисляет точные смещения всех пересечений
с `SourceMap` и путь к каждому соответствующему файлу.
