# Физические таблицы транспорта и второго оснащения

[Семь корабельных записей](../Source/Station/Data/ShipTradeRows.asm)
занимают 9802..9824. [Четыре записи второго набора](../Source/Station/Data/SkimmerTradeRows.asm)
занимают 9825..9838. Шаг обоих наборов равен пяти.
Два следующих байта относятся к [событиям](InterfaceEventAndSpecialRecord.md).

Для кораблей сценарий использует байт вместимости, слово цены и
байт свойства k.s, по нулю которого выбирает особую продажу.
Это проверено на [исходном сценарии](ShipTrade.md). Поле по смещению 3
сохраняет исходное значение. Для второго набора c читает слово со
смещения 1, v читает байт со смещения 4. Этот байт также прибавляется
в [вычислении загрузки](WeightedLoad.md). Блоков покупки и продажи
скимера в исходном сценарии нет, поэтому действие слова c в такой сделке
не устанавливается. Поля 0 и 3 пока неизвестны.

[Четырнадцать кодов количества](../Source/Station/Data/SecondaryQuantities.asm)
по 98F6..9903 читаются [вторым списком](SecondaryEquipmentRows.md)
и сценарными проверками. В исходной станции они равны FF и декодируются
в нулевые количества. SAVE0..SAVE4 содержат те же байты по +BB..+C8,
SAVE5 сохраняет нули. Маркер 80 в эту физическую область не добавлен.

[Сверка](../Tools/Disasm/Reports/StationTransportTradeTablesClassification.json)
подтверждает исходные значения, смещения и полные размеры записей.
