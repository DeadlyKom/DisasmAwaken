# Генератор группы вершин

[ProjectPreviewVertexGroup.asm](../Source/D3D/ProjectPreviewVertexGroup.asm), банк 4, #D908..#DA13, получает заранее вычисленные произведения и маску в IXL. Он подготавливает до восьми комбинаций, вызывает [перспективу одной вершины](PreviewPerspective.md) переходами и восстанавливает обычный CPU-SP перед RET.

## Физические входы

| Вход | Адрес операнда | Содержимое |
| --- | --- | --- |
| PackedFirst | #D910 | Первая пара произведений, две оси в младшем и старшем байтах |
| PackedSecond | #D913 | Вторая пара произведений |
| PackedThird | #D916 | Третья пара произведений |
| DepthFirst | #D956 | Первое произведение третьей компоненты |
| DepthSecond | #D955 | Второе произведение третьей компоненты |
| DepthThird | #D953 | Третье произведение третьей компоненты |
| NextOffset | #D90D | Младший байт исходного LD SP,#C600 |
| SavedSP | #DA11 | Восстанавливаемый обычный CPU-SP |

Эти адреса не являются новой областью данных. Это существующие изменяемые операнды. Их поставщики [#D8BE и #D85E](PreviewVertexProducts.md) оформлены и проверены отдельно. Масштаб, базы координат и центры уже настроены для перспективы. Внешний проход начинает рабочий SP с #C604, затем сохраняет следующий младший адрес между группами.

## Комбинации

Для упакованных входов U,V,W вводится r(U), циклический RLC каждого байта отдельно. N(U) означает отдельный NEG каждого байта, а не отрицание целого слова. Все сложения и вычитания далее являются исходной арифметикой 16-битных слов, межбайтовые переносы сохраняются.

| Индекс | Упакованная комбинация |
| --- | --- |
| 0 | U+V+W |
| 1 | v0−r(U) |
| 3 | v1−r(V) |
| 2 | v3+r(U) |
| 5 | N(v2) |
| 4 | v5+r(U) |
| 6 | v4−r(V) |
| 7 | v6−r(U) |

Третьи компоненты получают те же комбинации из трёх байтовых входов с байтовым оборачиванием, RLC и NEG. Компоненты 0,1,3,2 сохраняются в IXH,IYH,IYL,IXL, остальные четыре в операндах LD A,n.

Исходный алгоритм нельзя заменять независимой знаковой векторной арифметикой. Сложение упакованных слов переносит переполнение младшей оси в старшую. RLC возвращает старший бит в младший, что отличается от обычного удвоения. Эти особенности сохранены и проверены на нештатных значениях #80 и #FF, а не исправлены.

## Маска и особые пути

Обычный обход проверяет биты в порядке 0,1,3,2,6,7,5,4. Установленный бит вызывает перспективу соответствующей комбинации. Схема маски, разряды 7..0: [v7,v6,v5,v4,v3,v2,v1,v0]. Нулевая маска не выводит вершин.

Маска #01 имеет короткий путь только для комбинации 0. Маска #81 сначала проектирует комбинацию 0, затем отдельно отрицательную по байтам комбинацию 0. Короткий путь #81 нельзя механически заменить обычным обходом битов 0 и 7 при произвольных байтовых входах.

Число результатов n равно числу установленных битов, в том числе для коротких #01 и #81. Каждый результат занимает исходный шаг пять байтов по рабочему SP. Правила двух записываемых слов, маркеров отказа и повторной записи прежнего слова полностью относятся к доказанной перспективе.

## Продолжения и стек

Перед началом обычный CPU-SP записывается в SavedSP. Затем SP становится #C600+NextOffset. Для каждой вершины HL загружается адресом следующего участка диспетчера, выполняется JP к перспективе. Она заканчивается EXX и JP(HL), обычный адрес возврата не создаётся.

Finish складывает нулевое HL с текущим рабочим SP. Младший адрес сохраняется в NextOffset. Затем реальный LD SP,nn восстанавливает CPU-стек и RET читает настоящий адрес возврата. Итоговый CPU-SP равен входному+2, HL содержит следующий рабочий адрес p+5*n.

Модель проверена на буфере страницы C6 с достаточным свободным местом. Сам код не добавляет проверки переполнения выходной области. Прерывания и повторный вход исключены из-за рабочего SP и изменяемых операндов.

## Точный выходной контекст

BC содержит B=исходная маска, C=RLC младшего байта PackedFirst. DE при обычной маске содержит комбинацию 4, даже если её бит не установлен. Для #01 DE содержит комбинацию 0, для #81 её побайтовое отрицание.

IXH содержит третью компоненту 0, при #81 её отрицание. IXL содержит третью компоненту 2. IYH содержит третью компоненту 1, IYL третью компоненту 3. Альтернативный набор принадлежит последней перспективе по её точному контракту. При нулевой маске он целиком сохраняется.

A содержит младший байт следующего рабочего SP. При обычной маске без бита 4 последние S/Z/PV равны #44 от проверки сброшенного разряда, даже если перед этим были другие вершины. Для #01, #81 и обычной маски с битом 4 они принадлежат последней перспективе. Финальное ADD HL,SP сохраняет S/Z/PV, устанавливает биты 5/3 по старшему байту рабочего адреса, сбрасывает N, H и C при сложении нуля с допустимым рабочим SP.

## Проверка

[CheckPreviewVertexGroup.py](../Tools/Disasm/Research/CheckPreviewVertexGroup.py) сравнивает исходный генератор и настоящий проектор с независимой [числовой моделью](../Tools/Disasm/Research/PreviewVertexGroupOracle.py). Пройдены 5632 группы, все 256 масок, шесть предельных наборов произведений и случайная выборка. Спроектированы 22592 вершины.

Сверены весь рабочий буфер, все восемь слов и четыре байта комбинаций, полный основной, альтернативный и индексный регистровый контекст, сохранение CPU-адреса возврата, реальное восстановление SP, свободный индекс и точные границы записей.

[Отчёт](../Tools/Disasm/Reports/PreviewVertexGroupVerification.json) включает 18883 успешных вершины, 3692 отказа глубины, 11 отказов первой и 6 второй оси. Физический обход групп, входные производители, грани, растеризация, IRQ, сборка и нативная игра ещё проверяются отдельно.
