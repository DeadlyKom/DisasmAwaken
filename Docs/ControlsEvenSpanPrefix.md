# Условный вход заполнения 31 байта

[FillSpan31](../Source/Controls/FillSpan31.asm) начинается по #CEB5 банка 1. Два исходных байта `2D 77` выбирают предыдущий младший адрес через `DEC L` и записывают A. После них исполнение продолжается по #CEB7 в FillEvenSpanHead, затем по #CECF в FillEvenSpanTail. Полный путь записывает 31 байт справа налево. Пересечение младшего нуля не меняет страницу H.

На входе HL задаёт правую исключённую границу, A содержит заполнитель. На стеке должны лежать SavedHL и внешний возврат. На выходе HL восстановлен из SavedHL, SP увеличен на четыре, A содержит Mode, флаги получены через AND A. DE, BC, альтернативные и индексные регистры, I, IM и IFF сохранены. R получает 66 M1. [Общий хвост и рамка](ControlsEvenSpan.md)

Штатный `JR` по #CEB3 использует знаковое смещение `(62 - 4*A) AND #FF`. Оно равно двум по модулю четырёх при любом A, поэтому этот переход прямо не выбирает #CEB5 или #CEB6. В 1280 профилях модель явно задаёт вход #CEB5 с подготовленным стеком. Сверены все младшие адреса границы, пять заполнителей, вся RAM, кратность записей и регистры. Штатный вызов входа остаётся неизвестным. [Проверка](../Tools/Disasm/Reports/ControlsEvenSpanVerification.json)
