# Приветствие орбитальной станции

[DrawWelcomePanel](../Source/Station/DrawWelcomePanel.asm) по `#7955` рисует
приветствие элемента 45. Первый изменяемый `LD HL,nn` содержит индекс
`WelcomePanelState.ItemIndex #7956`. Временная замена первого байта на `C9`
полностью отключает вход, сохраняя регистры и память.

После рамки и заголовка включается `Style=1`. Шаблон по `#CD82` содержит
четыре части. Первые три заканчиваются кодом `01`, который возвращает
управление печатателю для вставки следующего значения. Последняя часть
заканчивается LF, её продолжение находится по `#CE19`.

| Часть | Адрес | Вставка после неё |
|---|---|---|
| «Орбитальная станция, модель » | CD82 | подпись модели станции |
| «, системы » | CD9F | имя текущей системы и подпись варианта |
| Приветствие и сообщение о почасовой оплате | CDAA | число 5×L |
| « кредитов.» | CE0E | конец по LF |

[DescribeCurrentKey](../Source/Station/DescribeCurrentKey.asm) возвращает в L
характеристику 1..16. Здесь исходный текст доказывает её использование как
номера модели станции. Из `WelcomeText.ModelLabels #CCF3` выбирается запись
с нулевым индексом L−1. По правилу `SkipLfRecords` сначала пропускается LF
перед первой записью, поэтому выбирается ровно L ограничителей.

Имя строится из физических полей `FSignatureInput` текущего ключа, банк 1
выбирается перед [BuildSystemName](../Source/Map/BuildSystemName.asm).
Сформированный `SystemNameState.Buffer` печатается, CursorX увеличивается
на четыре пикселя по модулю 256, затем
[PrintVariantLabel](../Source/Map/PrintVariantLabel.asm) печатает подпись
варианта того же текущего ключа. После этого выбирается банк станции 0.

Перед ставкой характеристика вычисляется заново. Подпись варианта
переиспользует рабочий ключ, поэтому документировать второй вызов как
лишний и удалять его нельзя. Два удвоения A и прибавление исходного L
дают 5×L, диапазон 5..80. Значение передаётся `Print4DigitCore`. Текст
называет его почасовой оплатой услуг станции. Само приветствие не
списывает деньги и не выполняет расчёт прошедшего времени.

Указатели продолжений шаблона сохраняются через PUSH HL и снимаются после
вставок. Физический `FWelcomeTextFrame` содержит Continuation по смещению 0
и внешний ReturnAddress по смещению 2, размер 4 байта. Вложенные CALL
кладут собственный адрес ниже этого кадра. Это фактические указатели
продолжения `PrintText`. Если печататель
остановился раньше разделителя из-за ограниченного окна, следующий POP
вернёт адрес внутри фразы. Рисователь не проверяет статус каждого вызова,
не восстанавливает начало части и не отменяет уже нарисованные символы.

При полностью успешном тексте итоговые HL=`CE19`, BC=`10`, AF=`0A4A`.
При ограниченном окне HL и AF являются результатом последнего `PrintText`,
BC соответствует последнему числовому печатателю. DE сохраняет код области
и двухбитовый признак второго `DescribeCurrentKey`. HL′ равно первому
слову ключа AND `F0FF`, DE′ второму слову AND `FFF0`, BC′ входному BC.
AF′ содержит восстановленную страницу и флаги её OR. IX, IY, I, IFF и IM
сохраняются при договоре пробуждения HALT. Обычный RET оставляет SP+2.

[CheckWelcomePanel.py](../Tools/Disasm/Research/CheckWelcomePanel.py) проверяет
96 активных вызовов, 864 физических кадра продолжения, все 16 характеристик, обе экранные страницы и три
геометрии, включая ограниченные окна. Проверяются аргументы настоящих
печатателей и банковых помощников, имя по независимой формуле, продолжения
шаблона, ставка и регистры. Исполнены 96 настоящих IM2 у HALT рамки с
выключенной музыкой. Проверены все 256 F отключённого входа.
[Отчёт](../Tools/Disasm/Reports/WelcomePanelVerification.json) не утверждает
независимый oracle всего bitmap, произвольные IRQ, сборку или нативный запуск.

При разработке модели выявлено перекрытие восьми байтов кода B400 искусственным
списком старой фикстуры. Общий конструктор исправлен, рабочий список расположен
по исходному F3DE, сохранность B400 проверяется явно. Повторены все 20 моделей
его потребителей, [сводный отчёт](../Tools/Disasm/Reports/FixtureConsumersVerification.json)
содержит фактические результаты. Байты игры не менялись.
