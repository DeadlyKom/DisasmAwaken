# Делитель ACTION C88C

Диапазон C88C–C940 банка 0 пока находится в начале [DivideSigned32To16.asm](../Source/Action/DivideSigned32To16.asm). Следующий вход C941 относится к диспетчеру отсечения, его договор здесь не объявляется доказанным. [Проверка](../Tools/Disasm/Research/CheckActionSignedDivision.py) исполняет фактические байты ACTION и отдельно сверяет каждую инструкцию делителя с вариантом карты после пересчёта внутренних адресов.

## Представление входа

HL содержит старшее слово числителя N, A следующий байт, альтернативный A младший байт. DE задаёт ненулевой signed16 делитель d. Входной флаг Sign обязан соответствовать знаку d, начальный переход проверяет именно F, а не старший бит D. Carry основного и альтернативного F допускают оба значения и участвуют в точных выходных флагах.

Для N>=0 величина U=N, для отрицательного N величина U=−N−1. Требуется U<abs(d)×65536. Деление на нуль и переполнение частного находятся вне численного договора.

## Алгоритм и частное

В IXL считается число отрицательных входов. Отрицательный делитель превращается в обычный модуль дополнительным кодом. Отрицательный числитель целиком дополняется побитово без прибавления единицы. Затем выполняются шестнадцать развёрнутых восстанавливающих шагов, сначала восемь битов A, затем восемь альтернативного A.

Остаток удваивается с очередным битом числителя, пробуется вычитание модуля делителя. При заёме вычитание отменяется. Carry=1 после восстановления кодирует нулевой разряд истинного частного, поэтому накопитель содержит дополненное частное.

Пусть q=floor(U/abs(d)). При одинаковых знаках возвращается HL=q, при разных знаках HL=q XOR FFFF. Это сохраняет исходную однокомплементную обработку. Она не совпадает с обычным усечением signed32/signed16 во всех случаях. Остаток не возвращается, HL заменяется собранными байтами ответа.

## Регистры

DE содержит модуль d. BC сохраняется при двух неотрицательных входах, получает исходное старшее слово N при отрицательном N, иначе исходный d при отрицательном d. A содержит старший байт HL, альтернативный A младший. Основной F сохраняет S/Z/PV от восьмой попытки старшего байта с последующими изменениями от восстановления знака. Точные формулы обоих F находятся в функции expected исследовательского CheckSignedDivision.py и отдельно проверяются на ACTION.

Альтернативные HL, DE и BC сохраняются. IXH сохраняется, IXL равен числу отрицательных входов минус один по модулю 256. IY, I, IM, IFF и paging сохраняются. SP после RET увеличен на два. Код не записывает RAM и не использует порты. R меняется, точное приращение и время отдельно не вычислялись.

## Проверка и текущий статус

[Отчёт проверки](../Tools/Disasm/Reports/ActionSignedDivisionVerification.json) содержит результаты исполнения ACTION для всех младших слов положительного и побитово дополненного отрицательного числителя против десяти делителей, а также широкие допустимые числители. Сверяются точные регистры и флаги кроме R, отсутствие любых записей RAM и правильный CPU-возврат.

Вход C941 выделен в [отдельный Unknown-файл](../Source/Action/ClipSingleEdge.asm), байты и инструкции сохранены. Делитель опубликован с доказанным договором, статус Unknown сохранён только для соседнего диспетчера. Совпадение инструкций с картой отдельно от численной проверки не считается доказательством всего соседнего диспетчера. Все совместные входы, IRQ, сборка и нативный запуск не проверены.
