# Продолжение большого эффекта

[AllocateLargeEffect](../Source/Action/AllocateLargeEffect.asm)
принимает заголовок после [EA29](ActionLargeEffectEntry.md), выделяет
запись эффекта VOXAL и включает общий обход.

Для класса ниже `#10` счётчик создания равен `2 + (R AND 3)`.
Поиск начинается с первой физической записи ACTION и идёт с шагом
`#40` по старшему байту первой компоненты. Значение `#80` допускает
проверку младшего байта. Слово `#8080` завершает поиск, другие
слова с этим старшим байтом допускают запись. После заполнения
поиск продолжается со следующего слота.

Копируются три слова координат. По смещениям `#06`, `#0A`, `#0C`
пишутся `#B8`, `#04` и ноль. Поля `#0D` и `#0E` получают
соседние байты ROM по адресу из R. Поле `#10` получает
`ChildMask OR (R AND #1F)` с отдельным чтением R. По смещениям
`#12..#16` записываются `#10, #10, #FF, #FF, #00`.

Общий хвост устанавливает курсор канала B в `#EE4D` и передаёт
исходный объект в [MarkRecordForReuse](../Source/Action/MarkRecordForReuse.asm).
Так заканчиваются и путь класса от `#10`, и путь исчерпания слотов.

[Модель](../Tools/Disasm/Research/CheckActionLargeEffectChildren.py)
прошла 640 сценариев с нулём, одним и несколькими свободными слотами.
Сверен точный порядок записей до внешнего возврата. Байты ROM заданы
синтетической таблицей, а значения R для полей наблюдаются в точках
чтения. Нативное содержимое полей и полный регистровый договор
выхода не сверялись. [Результаты](../Tools/Disasm/Reports/ActionLargeEffectChildrenVerification.json)
