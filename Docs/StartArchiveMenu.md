# Архивное меню Start и Options

Блок начинается на физическом смещении `#87400` исходного TRD. Его код
согласуется с загрузкой по `#6000`, в частности ссылка `#6132` попадает
точно на ключ `START   C` по дисковому смещению `#87532`. Сохранившийся
архивный BASIC вызывает `RUN "RUN" CODE`, загрузка подтверждена
[сквозной моделью](ArchiveMenuHandoff.md). Сборочный модуль включает
491 инструкцию, 47 байтов структур, остальные поля и строки меню,
два исходных экрана, шрифт и 35 байтов секторного хвоста. После сборки
Lua возвращает 61 сектор в `#87400` с сохранением исходного заголовка
с нулевым первым байтом. Статическая сверка прошла, фактическая сборка
после включения этого модуля ещё не проверена.

## Инициализация и выбор

Вход `#6000` устанавливает SP, копирует два экрана по 6912 байт из
`#63DD` и `#7EDD` в страницы 5 и 7. Затем выводит основное меню и
устанавливает IM2. Рисователь `#627C` берёт восемь строк глифа из
`#99DD+8×(код−#20)` и накладывает их через XOR. Для обеих страниц
сверены все байты после копирования экранов и после вывода `Start` и
`Options` исходным шрифтом. Таблица IM2 начинается по `#5E00`, вектор ведёт через
`JP` по `#5F5F` в обработчик `#6179`. Цикл после `HALT` по `#6029`
чередует экраны и читает клавиатурные строки. Обработчик выбора `#60DF`
запоминает код действия и блокирует повтор выбора при удержании клавиши.
[Инициализация и цикл](../Source/ArchiveRun/RunMenu.asm)
· [Два экрана и шрифт](../Source/ArchiveRun/Data/Images.asm)
· [Косвенный вызов](../Source/ArchiveRun/InvokeSelection.asm)

Основное меню содержит `Start` и `Options`. Обработчики `#62CC` и
`#62D9` стирают текущий список и выводят следующий. В Options первый
выбираемый пункт циклически меняет `#6330` от 0 до 2 и обратно на 0.
Обработчик `#62E6` обновляет указатель текста `#6359`, затем печатает
новое значение на обоих экранах. Пункт `DONE!` возвращает основной
список с выбранным `Start`. Каждый список начинается с числа записей,
после которого идут пары «адрес подписи, адрес обработчика». Запись 0
задаёт заголовок. Навигация ограничена индексами от 1 до 2.

| Действие | Клавиши |
| --- | --- |
| Предыдущий пункт | `9`, `Q`, `W`, `Caps Shift` + `7` |
| Следующий пункт | `8`, `A`, `S`, `Caps Shift` + `6` |
| Подтверждение | `0`, `Enter`, `Space` |

При удержании `Caps Shift` прямые проверки `9` и `8` заменяются
проверками `7` и `6`. Подтверждение и проверки остальных строк
сохраняются. Предыдущий код хранится по `#609A`, пустой кадр сбрасывает
его. Обработчик подтверждения кладёт адрес возврата на стек и выполняет
`JP (HL)` по выбранной записи. [Предыдущий пункт](../Source/ArchiveRun/MoveSelectionUp.asm)
· [Следующий пункт](../Source/ArchiveRun/MoveSelectionDown.asm)

Стрелка `>` берётся из шрифта по `#9ACD`. Счётчик мигания хранится
в операнде `LD A, n` по `#6189`. При нуле обработчик меняет восемь
байтов XOR в обеих страницах, читает период 8 из `#61A6` и сохраняет
уменьшенный остаток. Положение стрелки вычисляется по X=105 и
Y=112+8×индекс. В 17 кадровых прерываниях переключения пришлись на
кадры 1, 9 и 17. Проверены все варианты клавиш из таблицы.

Адресный преобразователь сверён для всех 49 152 пиксельных координат,
три входа перехода между строками для 18 432 адресов. Отдельный
вход очистки по `#6144` записывает 6144 нулевых байта растра и 769
байтов `#07`, включая `#DB00` за атрибутами. В проверенных путях меню
входов в очистку и три помощника перехода между строками не найдено.

## Запуск и передача настройки памяти

Start переходит на `#610A`. Процедура ставит `SP=#6000`, переключается
на IM 1, сохраняет значение `#6330` в `#5F5E`, выбирает страницу `#10`
и копирует девять байтов ключа в `#5CDD`. Она кладёт адрес `#6000`
на стек и передаёт управление в `#3D13` с `A=#FF`, `C=#0E`, `HL=#6000`.
В исходном каталоге запись `START.C` начинается с нулевого байта.
ROM TR-DOS 5.04T читает три
сектора каталога, возвращает статус 1 по `#5D0F` и оставляет область
назначения побайтно прежней. На возврате PC и SP равны `#6000`.
[Исходник перехода](../Source/ArchiveRun/LoadStartFile.asm)

Два соседних архивных блока читают тот же байт `#5F5E` при старте и
выбирают адрес команды переключения памяти из своих таблиц.

| Режим | Подпись | scene1 | BANK | Записи портов для кода `#08` |
| --- | --- | --- | --- | --- |
| 0 | `256k:Pent` | `#4FB8` | `#63AE` | `#7FFD ← #58` |
| 1 | `256k:Scorp` | `#4FCF` | `#635B` | `#1FFD ← #10`, `#7FFD ← #18` |
| 2 | `256k:ATM-2` | `#4FE5` | `#637E` | `#7FFD ← #18`, `#FFF7 ← #F7` |

Последний режим использует реальный переход в ROM TR-DOS по `#3D2F`
к инструкции вывода `#2A53`. Проверены исходные чтения поля, запись
операндов переходов и выходы в порты для кодов `#08..#0D` в обеих
копиях. Байт передавался читателям в отдельных моделях после возврата
ошибки `START.C`. После восстановления первой буквы записи в модели
подтверждена загрузка через Start в режиме `256k:Pent`. Фактическое
размещение страниц Scorpion и ATM-2 на железе остаётся открытым.
[scene1](Scene1PixelPairs.md) · [BANK](BankStripArchiveConsumer.md)
