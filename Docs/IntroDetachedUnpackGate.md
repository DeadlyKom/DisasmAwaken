# Условный вход за экранным потоком

[UnpackTailGate](../Source/IntroUnpack/UnpackTailGate.asm) начинается по
#74EC после переноса второго экранного ресурса. Физические 19 байтов
#2CEC..#2CFE содержат девять инструкций. Штатная точка вызова этого
фрагмента пока неизвестна.

Вход вызывает #6E3C, внутреннее `ADD HL, DE` распаковщика. Чтобы
распаковать исходный экран, перед вызовом нужны HL=#6E3C, DE=#008F
и состояние, подготовленное префиксом UnpackScreen. Код фрагмента
сам этих регистров не задаёт.

Терминатор заканчивается через `ADC A, #FF`. Если сумма исходного
A и Carry ненулевая, следующий `JR C` продолжает распаковку. Иначе
результат A=#FF, Z=0 и выполняется RET. Проверены все 512 сочетаний
A и Carry. Поэтому после обычного возврата первый `JP Z, #68EE`
пропускается. Затем INC A даёт ноль и второй `JP Z` срабатывает,
когда байт по выходному HL равен нулю.

Модель распаковала специально построенный экран, для которого HL
на возврате равен #5AFF и указывает на нуль. В исходном незаполненном
писателе от #68EE выполняются NOP до #6929. После построения писателя
по #68EE находится запись слова из HL, без предшествующего POP.
Остальная цепочка снимает ещё 14 слов с текущего SP и записывает их
по рассчитанным адресам. Модель сверила всю RAM до #6929. Следующая
инструкция загружает SP из существующего операнда #692A, который этот
вход самостоятельно не сохраняет.
[Построитель](IntroAttributeWriter.md) · [Проверка](../Tools/Disasm/Reports/IntroScreenResourcesVerification.json)

Когда по HL лежит ненулевой байт, фрагмент переносит HL в IX,
читает (IX+8) и сравнивает с #43. Для оригинального потока HL=#5AFF,
(HL)=#07 и читается #5B07. При равенстве #43 дальнейший JR Z берёт
знаковое смещение по #7500, иначе управление идёт на #7501.
В 768 опытах отдельно охвачены все значения читаемого байта
и все значения смещения с обоими исходами.

Опкод #28 по #74FF является последним байтом файла. Смещение #7500
копируется из #9000 за концом загруженных секторов. В двух сквозных
запусках по #9000 наблюдался ноль и обе ветви вели бы к #7501.
Байт опкода сохранён отдельно, значение смещения в дисковый образ
не добавлено. [Перенос и граница](IntroScreenResources.md) · [Трасса запуска](../Tools/Disasm/Reports/BootBankFileReadsVerification.json)
