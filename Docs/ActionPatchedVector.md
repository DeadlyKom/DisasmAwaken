# Три компоненты с переносом от произведений

[ComputePatchedVector](../Source/Action/ComputePatchedVector.asm) занимает
AF43..AFF4 общей RAM банка 2, исходная запись 17 ACTION,
смещения 4F43..4FF4. Он вызывает
[MultiplySignedScaled](ActionScaledMultiply.md) девятью переходами JP,
возвращая управление через IX на именованные промежуточные ступени.
Сам вычислитель завершается JP (IY), входной IX сохраняется через операнд AFF1.

## Физические входы и выходы

| Назначение | Адреса |
|---|---|
| Три слова входа | AF48, AF56, AF69 |
| Коэффициенты строки 0 | CB3E, CB54, CB6F |
| Коэффициенты строки 1 | CB8B, CBA1, CBBC |
| Коэффициенты строки 2 | CBD8, CBEE, CC09 |
| Три слова выхода | D9B6, D7C4, D7A2 |
| Сохраняемый IX | AFF1..AFF2, операнд LD IX,nn |

Коэффициенты и выходы находятся в верхнем окне ACTION банка 0.
Входные слова являются разнесёнными операндами LD DE,nn первой строки.
Они не образуют физическую непрерывную структуру, новые буферы не выделяются.
Коэффициенты берутся целыми байтами, числовой случай 80 сохраняет исходный
нулевой модуль дочернего умножителя. Изменяемые слова коэффициентов
частично переставляет [SwapCodePatchWords](ActionPatchSwap.md).

## Алгоритм строки

Для каждой строки вычисляются три знаковых произведения p0, p1, p2,
каждое с делением на 128 и усечением к нулю. После p0 результат переносится
в SP. Затем исполняется p1 и ADC HL,SP. При отсутствии переполнения
сумма переносится в SP, исполняется p2 и следующий ADC HL,SP.

Carry перед ADC не очищается. Дочерний умножитель возвращает Carry=1
для отрицательного ненулевого произведения и Carry=0 в остальных случаях.
Поэтому частичная сумма равна p0+p1+(p1<0), а итоговая —
частичная_сумма+p2+(p2<0). Например, p0=0, p1=-1, p2=0 дают 0.
Это исходное поведение, обычной формулой матричного произведения его
заменять нельзя. Перенос сохраняется и для всех знаковых граничных случаев.

После каждого из шести ADC проверяется знаковое переполнение P/V.
При переполнении выполняется общий выход. Выходное слово текущей строки
не записывается, последующие строки не исполняются. Выходы предыдущих
строк остаются уже обновлёнными, остальные сохраняют старые значения.
Нет ни атомарной записи трёх слов, ни их обнуления при ошибке.

## Регистры, SP и самомодификация

HL содержит последнюю сумму, включая переполнившуюся, DE и альтернативный
AF соответствуют последнему умножителю. B сохраняется, C=0.
A содержит знаковый XOR последнего умножения, F — результат последнего
ADC HL,SP. P/V установлен при досрочном выходе, сброшен при полном
завершении. Альтернативные HL, DE и BC сохраняются, IX восстанавливается,
IY, I, IM и IFF сохраняются. PC получает IY.

SP остаётся частичной суммой перед последним умножением. Он не указывает
на рабочий CPU-стек и не восстанавливается самим вычислителем.
Исходные цепочки содержат только JP, не используют PUSH, CALL и RET,
не записывают RAM по этому арифметическому SP. Продолжение IY обязано
восстановить стек до стековых операций. IRQ, использующие этот SP, недопустимы
в рамках проверяемого договора, полного нативного доказательства IRQ нет.

Единственная собственная самомодификация — запись входного IX в AFF1..AFF2.
Это операнд DD 21, расположенный на два байта после RestoreIX по AFEF.
Повторный вход до выхода запрещён, иначе сохраняемый IX будет потерян.
Другие записи — от нуля до трёх слов выхода. Переключений банков нет.

R получает точные стоимости исполненных детей и накладные M1 переходной
цепочки. При полном завершении накладная стоимость 84 M1, при аварийном
выходе учитывается только исполненный префикс. Старший бит R сохраняется,
младшие семь переполняются по модулю 128. Это не измерение T-состояний.

## Проверка

[Композиционная модель](../Tools/Disasm/Research/CheckActionPatchedVector.py)
прошла 212236 сценариев с настоящими дочерними умножителями без подмен.
Все 65536 слов каждой из трёх осей проверены на диагонали 7F.
Каждый из 256 байтов каждой из девяти позиций коэффициентов проверен
на пяти граничных входах. Дополнительно проверены все шесть точек
переполнения обоих знаков и 4096 воспроизводимых смешанных матриц.

Сверены все регистры, флаги, альтернативный AF, R, арифметический SP,
каждый байт RAM и кратности записей. Эталон родителя использует ранее
независимо проверенный договор ребёнка, полного независимого эталона
каждого дочернего исполнения здесь нет. Полный совместный перебор всех
векторов и матриц не заявляется. Сборка, IRQ, нативный игровой кадр и
полный пуск ракеты моделью не исполнялись.
