# Исходный список кандидатов ACTION

В исходном ACTION по `#A01C..#A026` находятся десять байтов FF и
завершающий FE. Физические байты оформлены как одиннадцать именованных
[экземпляров FCandidateCode](../Source/Action/Data/CandidateList.asm).
Каждый занимает один байт с полем Code, размер и порядок не менялись.

| Code | Доказанное использование |
|---|---|
| 00..FD | Обычный байтовый индекс, адрес записи A100+64*Code |
| FE | Конец просмотра списка |
| FF | Пропущенная ячейка, доступная писателю |

Разряды 7..0 составляют единый числовой код. Ноль является допустимым
индексом, а не пустой ячейкой. FF и FE являются полными специальными
значениями, их нельзя описывать отдельными независимыми флагами.

[CheckCandidateListReady](../Source/Action/CheckCandidateListReady.asm)
пропускает FF и проверяет первый непропущенный байт, не проверяя
доступность самой записи. [FindNearestListedRecord](../Source/Action/FindNearestListedRecord.asm)
выбирает доступного кандидата по квантованному расстоянию и заменяет
недоступные элементы FF. [SpawnClass19AndUpdateList](../Source/Action/SpawnClass19AndUpdateList.asm)
заменяет FF либо индекс недоступной записи своим вычисленным кодом.
Производный код может оказаться FE и сократить последующий просмотр.

Все три потребителя начинают с адреса перед Slot00.Code. Их исходные
инструкции и арифметика сохранены. Нового буфера, ограничителя и проверки
на десять элементов не добавлялось. Десять слотов описывают именно
физический начальный список. Предельная длина произвольного изменённого
runtime-списка этим не доказывается, при потере FE чтение может продолжиться
в соседних байтах согласно исходному коду.

[Публикация и проверка размещения](../Tools/Disasm/Research/ClassifyActionCandidateListData.py)
сопоставляет каждое поле с исходным ACTION, символами и непересекающимися
диапазонами SourceMap. Соседние байты до A01C и после A026 остаются
неразмеченными. Использованы отдельные проверки реальных
[читателя допуска](ActionCandidateGate.md), [поиска ближайшего](ActionNearestCandidate.md)
и [писателя](ActionClass19Spawn.md). Сборка и нативный запуск не выполнялись.
