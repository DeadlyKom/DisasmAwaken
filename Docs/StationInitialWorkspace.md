# Исходная область станционного интерфейса

Исходные байты STATIONF по `2238..28FF` оказываются по `8238..88FF` в фиксированном банке 2. В проверенном запуске этот диапазон используется под адресные таблицы и рабочие записи интерфейса. Следы прежнего содержимого сохраняются побайтно в исходном образе. [Таблица индексов](../Source/Station/Data/InitialItemIndex.asm), [модель запуска](../Tools/Disasm/Research/CheckStationInitialWorkspace.py).

| Адреса | Байтов | Первое назначение в модели |
| --- | --- | --- |
| 8238..82FF | 200 | Хвост страницы старших байтов экранных строк, писатель 41BD |
| 8300..83FF | 256 | Младшие байты адресов строк, писатель 41BF |
| 8400..84FF | 256 | Номера байтов столбца, писатель 41DA вычисляет X DIV 8 |
| 8500..857F | 128 | Первые 64 индексные пары, ResetIndexTable записывает FF до чтения |
| 8580..85FF | 128 | Следующие 64 индексные пары, ResetIndexTable их сохраняет |
| 8600..88FF | 768 | Владельцы знакомест, ClearWorkspace записывает ноль до чтения |

Исходные страницы оформлены отдельными ресурсами [старших байтов строк](../Source/Station/Resources/InitialRowHighTail.bin), [младших байтов строк](../Source/Station/Resources/InitialRowLow.bin), [столбцов](../Source/Station/Resources/InitialColumnByte.bin) и [владельцев](../Source/Station/Resources/InitialCellOwners.bin). Таблица по 8500 сохраняется как 128 экземпляров `FStationItemIndexPair` с исходными младшими и старшими байтами. FF, вычисленные адреса и нулевое заполнение в дисковые исходники не подставляются.

`StartStation` заполняет все три страницы `8200..84FF`. Первые 56 байтов 8200..8237 лежат в диапазоне исходного станционного кода, уже перенесённого к моменту записи таблицы. Поэтому их физическая разметка как кода сохраняется. Для поздних адресов рабочая роль описывается отдельно. [Загрузчик](../Source/StationBoot/StartStation.asm), [пары и карта владельцев](CellMap.md).

Модель исполняет исходный загрузчик и доходит до трёх входов станционного цикла с подстановкой TR-DOS. Сверены первые значения всех 1608 перезаписанных байтов. Во второй половине страницы 85 у 70 байтов первым обращением оказалось чтение, значения сверены с исходным файлом. Остальные адреса этой половины в проверенном проходе не затронуты. Команды из `8238..88FF` в этом проходе не исполнялись. [Отчёт](../Tools/Disasm/Reports/StationInitialWorkspaceVerification.json).
