# Первая близкая широкая цель

[FindFirstNearWideVector](../Source/Action/FindFirstNearWideVector.asm)
занимает 69BE..6A28 перенесённого ACTION. Исходный байт SeedIndex по
688B используется здесь как число записей, список начинается с
[ActionWideVectors.Vector00](../Source/Action/Data/WideVectors.asm).
Шаг равен FActionWideVector=12. Число ноль возвращает L=7F без чтения
списка, A=0 и F=44, сохраняя H, DE, BC и IY. Числа 1..255 проходят
без дополнительного ограничения, доступность указанных записей является
предусловием. Шесть физических начальных записей не доказывают игровой
предел счётчика, исходная защита диапазона не добавляется.

Для каждой строки вызывается настоящий
[CheckThreeUpperWordsNear](../Source/Action/CheckThreeUpperWordsNear.asm).
Выбирается первая, у которой каждое верхнее signed16 лежит от −60 до 59.
Поздние подходящие строки уже не читаются. IY восстанавливается перед
возвратом, IX и все альтернативные регистры сохраняются.

У найденной строки извлекаются три средних слова, то есть биты 8..23
компонент. Если бит 31 полной компоненты установлен, оба байта среднего
слова инвертируются без прибавления единицы. Сравниваются **только старшие
байты** полученных слов. При равенстве побеждает более поздняя компонента,
даже если её младший байт меньше. Это не максимум полных слов.

L получает старший байт выбранного среднего слова, H его младший байт.
Такая перестановка намеренно сохраняет исходный выход. Поэтому L лежит
в 0..59 при успехе и равен 7F при отсутствии результата. Нельзя заменять
этот признак общим правилом по Z или Carry.

При успехе A=E равен индексу от нуля, B равен оставшемуся числу строк
включая выбранную, C сохраняется. D равен старшему байту свёрнутого
среднего слова третьей компоненты независимо от победителя. F задан
SUB исходного числа и оставшегося B, поэтому Carry=0, а Z=1 только
при первом элементе. При исчерпании B=0, DE=12, L=7F, H и A остались
от последнего предиката. Его S/Z/PV сохраняет последний ADD IY,DE,
H и Carry соответствуют этому сложению, N=0, биты 3/5 берутся из
старшего байта нового IY. IY затем восстанавливается через POP.

Максимальная дополнительная рамка равна четырём байтам. Она представлена
FNearVectorSearchFrame, пока выполняется предикат. За её пределами RAM
не записывается. SP после RET равен входному SP+2, I, IM, IFF и страница
сохранены. Начальный M1 равен 4 при пустом списке. Непустой путь имеет
10 M1 подготовки, каждая отвергнутая строка добавляет Tpredicate+5.
При полном исчерпании добавляются 4 M1. Найденная строка добавляет
Tpredicate+37+6*n+2*r1+2*r2, где n — число отрицательных полных компонент,
r1/r2 обозначают принятие второй и третьей компонент как нового максимума.
Это формула M1 для точного R, точные T не доказывались.

[Независимая модель](../Tools/Disasm/Research/ReferenceActionNearVectorSearch.py)
сопоставлена с [исполнением исходных инструкций](../Tools/Disasm/Research/CheckActionNearVectorSearch.py).
Перебраны все средние слова каждого знака в каждой позиции, все 256
значений счётчика с отсутствием, первым, средним и последним совпадением,
512 граничных троек и 8192 смешанных списка. Проверены регистры включая
R, все банки RAM, кратность записей и остаток стека. Полное произведение
списков и игровой предел счётчика не доказаны. IRQ, сборка и нативный
игровой запуск не выполнялись.
