# Удалённый исходник перевода числа в текст

Каталог оригинального TRD содержит удалённую запись 2, извлечённую как _L->TXT.H. Само содержимое начинается внутренним именем HL->TXT и содержит сигнатуру ALASM по смещению 40. Первые токенизированные строки начинаются по смещению 64. Пятьдесят строк и завершающий нулевой байт точно покрывают исходные 521 байт, включая служебный префикс.

[Исследовательский текст](../Tools/Disasm/Research/Evidence/DeletedDecimalFormatter.asm.txt) получен из токенов. Авторские русские комментарии задают вход HL как число и BC как адрес результата, в котором должны находиться пробелы. Код использует десятичные делители 10000, 1000, 100 и 10, затем выводит последнюю цифру. Изменяемый NCH переключает заполнение ведущих разрядов с пробела на ноль после первой значащей цифры.

Это представление исходного ALASM-текста, не дизассемблирование исполняемых байтов и не файл обычной сборки Awaken. Имена DES_TXT, WYCHET, WCH1, WYCH1, WYCH2, NCH и DCH взяты из исходного файла. Машинный код, фактический игровой вызов, точные выходные флаги и применимость к процедурам текущей игры не проверялись. Удалённый каталог не восстановлен и не переименован.

[Проверка форматов](../Tools/Disasm/Research/InspectAuxiliarySourceFormats.py) восстанавливает исходный файл из всех сохранённых токенизированных кадров и служебного префикса. [Отчёт](../Tools/Disasm/Reports/AuxiliarySourceFormatInspection.json) содержит SHA256, границы и ссылку на исходное извлечение. Описание токенов сопоставлено с [публичным распознавателем форматов ALASM, TASM и ADS](https://github.com/Bedazzle/ZX-M8XXX/blob/main/core/asm-detok.js), сама принадлежность контрольного файла проверена по его фактическим байтам.

У BANK0..BANK5 эта сигнатура не найдена во всём файле. С начала каждого из них не проходит даже первая полная строка TASM с повтором длины, не получается и длинная возрастающая цепочка строк ADS. Это исключает только проверенные начальные представления, не все возможные исходные форматы, произвольные смещения, фрагментацию или упаковку. BANK не объявлен исходником по одному имени файла.
