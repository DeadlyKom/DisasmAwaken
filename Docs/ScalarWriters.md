# Исполняемые писатели скалярных полей

[PushWordFieldWriter](../Source/Text/PushWordFieldWriter.asm) создаёт указатель записи слова #984E. [PushByteUWriter](../Source/Text/PushByteUWriter.asm) создаёт указатель записи байта #984B, [PushByteJWriter](../Source/Text/PushByteJWriter.asm) байта #9851. Entry выполняет LD DE,Invoke и JP PushExpressionWord, добавляет адрес в отдельный стек выражений. Поле на этом этапе не читается и не изменяется. Это статические продолжения, нового машинного кода они не генерируют.

У каждого модуля есть отдельные Invoke и Store. На входе Invoke CPU-стек содержит FFieldInvokeFrame размером 4 байта, Operator со смещением 0 и AfterStore со смещением 2. POP DE снимает адрес оператора, затем LD HL,Store и PUSH HL кладут вместо него адрес сохранения. Получается FFieldOperatorFrame с StoreReturn по смещению 0 и тем же AfterStore по 2. Определения структур не выделяют память, они описывают фактическую динамическую рамку CPU-стека.

Invoke читает текущее значение поля в HL, для байтового поля обнуляет H, затем EX DE,HL даёт DE текущее значение и HL адрес оператора. JP (HL) вызывает оператор без нового возврата. Правый операнд уже находится в BC. Оператор обязан вернуть DE через RET с доступным банком LANG 6. Его RET входит в Store, где записывается результат, следующий RET входит в AfterStore. Полный Invoke потребляет Operator и AfterStore, SP увеличен на четыре. Отдельный Store можно вызывать обычным CALL с DE результатом.

Словный Store не меняет регистры. Байтовый выполняет LD A,E и LD (поле),A, сохраняет F и весь DE, хотя в память записывается только E. Насыщения и проверки D здесь нет, результат FFFF запишет FF. Это отличается от писателей упакованных семибитовых полей, которые разбираются отдельно.

Entry сохраняет основные HL/BC/AF, устанавливает DE и альтернативный DE адресом Invoke, продвигает альтернативный HL на два, остальные альтернативные и индексные регистры, I и IFF сохраняет. Эффекты полного Invoke по регистрам определяются выбранным оператором и указанным Store. Игровые единицы трёх полей одним сохранением не устанавливаются.

[CheckScalarWriters.py](../Tools/Disasm/Research/CheckScalarWriters.py) проверяет 768 созданий указателя, 458752 вызова с настоящим CopyRightOperand и 336 вызовов с настоящими AddSaturated/SubtractSaturated. Проверены все словные записываемые значения, все старые и новые байты с тремя старшими байтами правого операнда, граничная арифметика. Сверены поле, регистры, F, SP, замена слова рамки и сохранность альтернативных регистров. Отчёт [ScalarWritersVerification](../Tools/Disasm/Reports/ScalarWritersVerification.json). Полный AssignValue в этой модели не исполняется, прерывания, сборка и нативный запуск не выполнялись.

## RAM и R по отдельным входам

Entry через PushExpressionWord записывает два байта Invoke в стек выражений и временно в CPU-стек ниже входного SP. Текущего целевого поля он не меняет. Invoke заменяет снятый адрес Operator словом StoreReturn, поле пока только читает. Store не пишет CPU-стек, записывает полный DE для денег либо только E для статуса и вместимости. RET читает AfterStore, временные байты POP не очищаются.

У всех входов меняется R. Entry выполняет 11 M1, полный Invoke с настоящим CopyRightOperand выполняет 12 M1 для слова и 13 для байта. Отдельный Store выполняет три M1, у словного варианта два из них приходятся на ED-префикс LD (поле),DE, у байтового на LD A,E и LD (поле),A. Старший бит R сохраняется, младшие семь увеличиваются по модулю 128. Утверждение о сохранении регистров словным Store относится к основным, альтернативным и индексным парам, не к R.

CheckScalarWriters теперь сверяет собственные записи CPU и точный R для 768 фабрик и 458752 вызовов CopyRightOperand. Прежние 336 арифметических вызовов также прошли. Проверено происхождение байтов из полного оригинального TRD, наблюдатель подтверждён инструкцией CPU. Возврат вызывающего сохраняется. Полное произведение входного R и операндов, произвольные адреса стеков, шинный порядок PUSH и прерывания не проверяются. Для произвольного оператора число M1 и остальные эффекты определяются его отдельным договором.
