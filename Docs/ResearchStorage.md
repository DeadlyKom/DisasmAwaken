# Хранение исследовательских снимков

Рабочие Source, Includes, Builder, текущие реестры Reports, оригинал Disk, извлечённые материалы Extracted и исследовательские сценарии остаются на прежних местах. Обычная сборка не использует архивы и Python.

Старые распакованные Candidates и History заменены каталогами с ARCHIVED.json. Сами каталоги оставлены, поскольку их существование защищает одноразовые операции от повторного применения. Уникальное содержимое всех файлов сохранено в [архиве](../Tools/Disasm/Research/Archives/LegacySnapshots-20261031.zip), идентичные байты хранятся один раз. Полный реестр первоначальных относительных путей, SHA-256, размеров и времён находится внутри index.json. Перед удалением проверяется каждый архивный объект и неизменность рабочих файлов.

EventActionCodeScoped, AnimatedVariantCodeScoped и PeriodicVariantCodeScoped оставлены распакованными, поскольку их использует проверка кандидата. Текущие модели и сценарии продолжают работать с активными материалами.

[CandidateWorkspace](../Tools/Disasm/Research/CandidateWorkspace.py) при явном обращении старого проверяющего инструмента восстанавливает нужный архивный кандидат автоматически. Создание нового кандидата не разворачивает старый и по-прежнему запрещает перезапись существующего каталога. Не следует запускать одноразовые применённые классификаторы повторно.

Для отдельного старого снимка можно вызвать [ResearchArchive](../Tools/Disasm/Research/ResearchArchive.py) из корня проекта, например через доступный интерпретатор Python.

```text
python Tools/Disasm/Research/ResearchArchive.py History/BeforeStoredPointProceduresSplit
```

Восстановление сначала проверяет все пути, контрольные суммы и существующие файлы. Отличающиеся ручные файлы не перезаписываются. Архивные маркеры остаются для учёта происхождения. Для обращения к историческим путям напрямую сначала восстановить соответствующий снимок этой командой.

В .gitignore и настройках редактора старые снимки и архивы исключены из наблюдения и поиска. Это предотвращает повторное сканирование десятков тысяч файлов при восстановлении старого выпуска. Рабочие исходники из поиска и Git не исключены.

[Отчёт очистки](../Tools/Disasm/Reports/ResearchCleanupVerification.json) содержит фактические объёмы и результаты проверки. Очистка не является сборкой или доказательством завершения смыслового дизассемблирования.
