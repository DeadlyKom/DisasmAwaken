# Табличные случаи отсечения ACTION

[Диспетчер C941](ActionClipDispatch.md) и полигональный DispatchEdges выбирают обработчики по двум кодам. [Проверка путей](../Tools/Disasm/Research/CheckActionClipCasePaths.py) сверяет все 1021 исходный байт и 365 инструкций ACTION с явной релокацией варианта карты. 308 абсолютных слов проверяются по установленным соответствиям, совпадение имён не используется как доказательство.

[Численная серия](../Tools/Disasm/Research/CheckActionClipCaseSemantics.py) прошла [176640 сценариев](../Tools/Disasm/Reports/ActionClipCaseSemanticsVerification.json) и выполнила все 241 символический путь для 81 пары. Исполняются настоящие произведения, деление, писатели пересечений и углов. Сверяются координаты и порядок вывода, размер, отметки углов, сохранение входных точек, границы выходной страницы и основные поля обычного/специального возврата. Это композиционная модель по исходным путям, независимым геометрическим доказательством она не является. Отдельная [композиционная проверка регистров и всей RAM](../Tools/Disasm/Reports/ActionClipCaseRegistersVerification.json) прошла те же 176640 сценариев и все 241 путь. Модель [ReferenceActionClipping](../Tools/Disasm/Research/ReferenceActionClipping.py) использует математические договоры помощников и проверяет все выходные регистры кроме R, всю физическую RAM и кратность записей, включая CPU-стек. Точное R и время отдельно не доказаны. Договоры опубликованных Case-входов явно ограничены рамкой трёх C993, контекст полигона требует отдельного разбора.

## Зоны и состояния

I означает внутри, R справа, L слева, B снизу, T сверху. Составные BR, BL, TR и TL задают угловые зоны. Числа младшей тетрады 0,1,2,4,5,6,8,9,A. Границы Second от 0 до 255, First от 0 до 95. Старшая тетрада ClipCode является отрицанием младшей.

Байт CF07 хранит отметки углов. Разряды 7..4 сохраняются. Младшие 3..0 означают TL, TR, BL, BR. Нулевое значение означает отсутствие прежних отметок. BIT проверяет прежнюю отметку, SET не меняет флаги и может предшествовать условному запросу по результату прежнего BIT. Полный ненулевой CornerBlock подавляет фактическую запись угла, но не обязан подавлять установку отметки.

Общий нормальный возврат C993 снимает два подставных слова после возврата обработчика и устанавливает флаги CP размера,4. Специальный вход C6EA при рамке трёх C993 возвращает HL=CA5B, BC=00C8, AF=C989. При полигональной рамке используются другие сохранённые слова, переносить этот результат на DispatchEdges нельзя.

Все четыре числителя вычисляются до использования на каждом символическом пути. При CornerBlock=1 добавляется не более двух точек, в численной серии с разрешёнными углами максимум четыре. Вертикальные пересечения сохраняют исходную проверку знака младшего байта, значения 96..127 не исправляются.
