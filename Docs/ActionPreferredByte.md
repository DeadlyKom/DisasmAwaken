# Выбор байта с приоритетом 74FB

[SelectPreferredByte](../Source/Action/SelectPreferredByte.asm) читает
[PreferredByteState](../Source/Action/Data/PreferredByteState.asm), физический
FPreferredBytePair по 9C10..9C11. Исходные два байта находятся в записи 17 ACTION,
смещения 3C10..3C11. Поле Preferred занимает смещение 0, Fallback смещение 1.
Изначальные значения сохранены буквально, память не выделяется.

Если Preferred ненулевой, A получает его значение, HL=9C10.
Иначе A получает Fallback, HL=9C11. Процедура возвращает адрес выбранного поля
вместе с самим значением. Локальные имена описывают только этот приоритет,
игровое назначение пары пока не установлено.

## Флаги и договор

F на обоих путях определяется AND Preferred. Carry и N сброшены, H установлен.
S, Z и чётность относятся к Preferred, биты 5 и 3 берутся из того же байта.
При выборе Fallback F всегда равен 54. Например, Preferred=00 и Fallback=FF
возвращают A=FF, но Z остаётся установленным и S сброшен.
Заменять эту процедуру выбором с повторной проверкой выходного A нельзя.

DE, BC, альтернативные HL, DE, BC, AF, IX, IY, I, IM и IFF сохраняются.
SP увеличивается на два после RET. Процедура не пишет RAM и CPU-стек.
R увеличивается на 4 M1 при ненулевом Preferred и на 7 M1 при его нуле,
с сохранением бита 7 и переполнением младших семи битов.

В [Unknown6649](../Source/Action/UpdatePanelGauges.asm) сразу после вызова идёт RRA.
Поскольку Carry сброшен на обоих путях, значение для шкалы делится на два.
В [Unknown6780](../Source/Action/Unknown6780.asm) выбранное значение увеличивается,
а при выполнении условия обновления записывается обратно через возвращённый HL.
Именно этот потребитель подтверждает значимость адресного результата.
Полные договоры двух вызывающих процедур здесь не объявляются доказанными.

Контекст пары — загруженный ACTION. Числовое совпадение 9C11 с
StationIrqState.ReturnPC не делает эти поля одним объектом, область Station
имеет другую исходную запись и исполняемый контекст. Физические экземпляры
этой пары принадлежат только ACTION, связь с другими загрузочными фазами
нельзя выводить из одного адреса.

## Проверка

[Модель](../Tools/Disasm/Research/CheckActionPreferredByte.py) проверила
все 65536 пар исходных байтов. 65280 случаев выбрали Preferred, 256 выбрали
Fallback. Проверены все регистры, F, R, SP, каждый байт RAM и отсутствие записей.
Для исполнения использованы фактические байты ACTION с его исходным переносом
ядра в 6000..7F8E. Сборка, прерывания и нативный запуск не выполнялись.
