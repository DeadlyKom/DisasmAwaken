# Таблицы преобразования и кадры VOXAL

[Palette.asm](../Source/Voxel/Data/Palette.asm) содержит 1 024 байта
по #C000..#C3FF банка 3. Старшая тетрада индекса задаёт левый код,
младшая — правый. Каждая страница хранит одну подстроку результата.
Растеризатор использует порядок страниц C3, C0, C2, C1.
Для всех 1 024 значений доказано разложение на старшую половину
таблицы для левого кода и младшую половину для правого кода.
Нулевой код обрабатывается прозрачностью в коде растеризатора.

[LargeEffectFrames.asm](../Source/Voxel/Data/LargeEffectFrames.asm)
содержит восемь кадров от #C400 с шагом #0280. В кадре 20 строк
по 32 байта, исходный размер 20×20 задаётся CreateLargeEffect.
[SmallEffectFrames.asm](../Source/Voxel/Data/SmallEffectFrames.asm)
содержит 13 кадров от #D800 с шагом #00C0. В кадре 12 строк
по 16 байтов, исходный размер 12×12 задаётся CreateSmallEffect.
Старшая и младшая тетрады байта являются кодами для выборки
в зависимости от чётности координаты.

Строки оформлены физическими FEffectByteRow16 и FEffectByteRow32.
Каждое поле PairNN сохраняет один исходный байт. Метки FrameNN
обозначают начало кадра, FNNRMM последующие строки. Размеры,
границы и байты проверяются строгим парсером в
[VoxelPhysicalData.py](../Tools/Disasm/Research/VoxelPhysicalData.py)
и общей VerifySources. Следующие 832 байта E1C0..E4FF сохранены
отдельно, их назначение пока не установлено.

Потребитель и формула выборки описаны в
[разборе растеризатора](VoxelSpriteClipBounds.md), продвижение
адресов кадров — в [обходе эффектов](ActionVisualEffectWalk.md).
