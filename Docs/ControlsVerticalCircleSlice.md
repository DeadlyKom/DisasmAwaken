# Вертикально отсечённое сечение круга

Вход D485 принимает WorkY в C, Radius и Flags из записи проекции, а также
заём от сравнения квадратов диспетчером D236. Граница файла проходит после
исходного RET D484. [Исходник](../Source/Controls/DrawVerticalCircleSlice.asm).

SqrtSquareDiff получает `Radius²−WorkY²−1` по модулю слова. Целый корень
сохраняется в SectionRadius. В альтернативных регистрах E′ получает WorkY,
а C′ получает отрицательный SectionRadius. YMinus выбирает строку 0 и ход
вниз либо строку 95 и ход вверх. Построители масок получают координаты
`CenterX−SectionRadius` и `CenterX+SectionRadius` на этой строке.
Выбранная половина восстанавливает AF. В каждом проходе выполняется
один из двух условных CALL.

При `Radius=WorkY` разность оборачивается в `FFFF`, SectionRadius равен
255. При CenterX в диапазоне 9..247 левая координата становится
`CenterX+1`, правая `CenterX−1`. Левый байтовый адрес не меньше правого.
Обычное ядро возвращается сразу после проверки порядка, сохраняя растр
и SavedSP. SectionRadius, CenterY, SavedB и Direction при этом записаны.

Наибольшая глубина возникает при первом чтении квадрата внутри корня.
При внешнем SP=S стек содержит адрес возврата корня по S−2, сохранённые
BC, DE, HL и AF по S−4..S−10, возврат читателя по S−12 и его сохранённый
HL по S−14. После завершения сечения SP равен S+2.

В 136 370 сценариях выполнены настоящие корень, построители масок и
ядра. Среди них 118 619 случаев касания и 551 207 нарисованных строк.
Сверены регистры кроме R, физические банки, значения и кратность
непиксельных записей. Предел проверки охватывает D485 при условиях
выбора этого пути диспетчером. Остальные входы D340 проверяются отдельно.
