# Построение таблицы приближённой экспоненты

[BuildExponentialTable](../Source/ActionBoot/BuildExponentialTable.asm) занимает 4355..438E загрузчика ACTION и записывает 256 байтов существующей страницы 9300. Точные значения определяет рекурсия фиксированной точки:

```
w[0] = 0
T[n] = floor((w[n]+128)/256) mod 256
w[n+1] = floor((65536+w[n])*65714/65536) mod 65536
```

Индекс n проходит 0..255, округление при точной половине выполняется вверх. Последнее обновление даёт w[256]=FFE4, это слово уже не сохраняется отдельной строкой. Каждая запись страницы производится один раз, исходные адреса не изменяются.

## Умножитель и регистровые наборы

В C:HL помещается 24-разрядное число 01:w. Двадцать четыре сдвига последовательно выбирают его биты. Другой регистровый набор накапливает частичное произведение, при единичном бите к нему прибавляется 100B2h, младшая часть 00B2 находится в BC, старшая 01 учитывается ADC A,1. Сдвиги накопителя и числа связаны Carry. После цикла выбираются средние разряды полного произведения, соответствующие делению на 65536 и сохранению младшего слова.

Каждый внешний шаг меняет активный набор. При чётных 256 шагах D и D′ сохраняют исходную принадлежность, но оба E обнуляются. Исходный AF′ сохраняется. На выходе HL=FFE4, BC=00B2, AF=E451, HL′=ECC8, BC′=00C9. IX возвращается к 9300 после оборачивания только IXL, IY, I, IM и IFF сохраняются. SP увеличивается на два после RET, дополнительных рамок или записей CPU-стека нет. R получает 102375 M1, это не тактовая стоимость. Портовых операций нет.

Таблица приближает `256*2^(n/256)-256`. На n=0..255 отличие фактических байтов от этой вещественной формулы лежит примерно от −0,601093 до +0,413477. Проверка через вещественную степень только характеризует конечную таблицу, она не заменяет точную целочисленную рекурсию и не требуется для обычной сборки. Связь с [логарифмической таблицей](ActionLogarithmTable.md) подтверждается их применением в AE73, полный числовой договор этого потребителя требует отдельного разбора.

[CheckActionExponentialTable.py](../Tools/Disasm/Research/CheckActionExponentialTable.py) исполняет исходные инструкции и сравнивает их с независимым целочисленным произведением, не повторяющим серийный умножитель. [Отчёт](../Tools/Disasm/Reports/ActionExponentialTableVerification.json) содержит 256 полных построений с изменяемыми входными флагами, D, D′, R и AF′. Проверены оба регистровых набора, точные флаги, SP, R, вся RAM и последовательность всех 256 записей. Прерывания, нативный запуск, потребитель AE73 и сборка Codex не выполнялись.
