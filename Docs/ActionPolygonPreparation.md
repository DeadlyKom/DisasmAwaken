# Подготовка линейной заливки ACTION

[PreparePolygonFill](../Source/Action/PreparePolygonFill.asm) занимает D511..D5C8 банка 0. [Назначение всего заполнителя](ActionPolygonFill.md) описано отдельно. В данном фрагменте устанавливаются исходные рёбра, диапазон строк, шаблоны и состояние перед JP D229. При горизонтальном вырождении выполняется ранний POP HL и RET через общий хвост D50F.

Первый минимум выбирается строго. Максимум обновляется при равенстве. От первого минимального индекса код обходит верхнюю горизонталь назад и вперёд, выбирая последнюю верхнюю вершину каждого направления. Курсоры сохраняются по D275 и D3B0. Правый обход оборачивается через последний индекс из D3B7, левый через альтернативный A.

Режим 0..4 выбирает исходную пару D100+2×mode. Первый шаблон сохраняется в A', второй записывается в оба операнда XOR строк. Начальные IX/IY равны фазе минимальной строки, умноженной на 8192, плюс Second выбранного конца, умноженной на 32, плюс удвоенный режим. Правый IY дополнительно содержит 16 для правой половины таблицы масок. Это упакованное состояние, а не обычные указатели на пиксели.

Перед JP D229 HL=8C00 плюс чётный индекс правой верхней вершины, DE содержит минимальную и максимальную First, B=80+минимальная First DIV 8, C=2×mode. A содержит минимум, F относится к сравнению минимума с максимумом. Альтернативные HL/DE/BC сохранены, A' содержит первый шаблон, F' относится к сложению mode+mode. SP=FFE0, по сохранённому CPU SP остаётся входной HL, затем внешний возврат. Устанавливаются ближайший предел и переход к подготовке левого ребра.

При горизонтальном вырождении HL восстановлен, SP увеличен на два, BC=1, DE содержит First в обоих байтах, AF относится к сравнению First с собой. IX/IY и альтернативные HL/DE/BC сохранены, альтернативный A равен размеру списка минус один, его F получен DEC с сохранением входного Carry.

[Числовая проверка](../Tools/Disasm/Research/CheckActionPolygonPreparation.py) прошла [3398 сценариев](../Tools/Disasm/Reports/ActionPolygonPreparationVerification.json), включая 480 горизонтальных. Сверены все регистры кроме R, вся физическая RAM и кратность записей. Профиль содержит выпуклые контуры положительного обхода, 3..60 точек, Second 0..255, First 0..95 и режимы 0..4. Контракт непустого пути заканчивается на границе JP D229. Остальное строковое ядро, R/T, IRQ, сборка и нативное исполнение этой проверкой не доказываются.
