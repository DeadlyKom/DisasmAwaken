# Одиночная клавиша и табличный код

[ReadMatrixKey](../Source/Station/ReadMatrixKey.asm) по `#A116` сначала сохраняет BC, HL и DE в FMatrixKeyFrame. Затем десять раз выполняет HALT с DJNZ. Это десять пробуждений от ISR, реальная длительность зависит от источника прерываний. После задержки ожидание клавиши идёт непрерывным опросом без новых HALT.

## Приоритет и сигнатура

Первый полный порт равен `#7FFE`. При отсутствии нажатия проверяются следующие старшие байты `#BF,#DF,#EF,#F7,#FB,#FD,#FE`, затем цикл повторяется. Внутри каждой строки проверяются биты 0..4, активный низкий уровень означает нажатие. Перед новой строкой E снова получает `#80`, пять RLC дают маски `#01,#02,#04,#08,#10`. Верхние три бита строки не участвуют.

Первая найденная клавиша передаётся [LookupMatrixKey](../Source/Station/LookupMatrixKey.asm), B содержит строку, C маску. Одновременные нажатия выбираются по порядку строк, затем по номеру младшего бита. Ожидания отпускания, обработки модификаторов и составного кода в этой процедуре нет. Уже удерживаемая клавиша возвращается после начальной задержки.

## Физическая таблица

[KeyboardCodes](../Source/Station/Data/KeyboardCodes.asm) начинается с нулевой пары Anchor по `#96AA`, затем содержит 62 позиции Code1D..Code5A. Позиция определяет возвращаемый код, отдельного байта кода в FKeyBinding нет. Каждая запись имеет физические RowMask и KeyMask, повторно используется существующая структура привязки клавиши.

Среди 62 позиций есть ровно 40 ненулевых пар. Они покрывают все сочетания восьми строк и пяти масок. Остальные позиции сохраняют нулевые пары. Anchor пропускается первым увеличением HL на два, первый проверяемый адрес Code1D равен `#96AC`.

Поиск сначала сравнивает RowMask с B, затем KeyMask с C. При несовпадении HL увеличивается на два и поиск продолжается. Проверки конца и ограничителя нет. Нулевая пара не останавливает поиск, прямой BC=0 находит первый нулевой пропуск Code21 и возвращает `#21`.

После совпадения к адресу строки прибавляется исходное `#6954`, равное отрицательному адресу Code1D по модулю 65536. Младший байт результата делится на два, к нему прибавляется `#1D`. Для штатных записей это номер позиции плюс первый код. HL возвращает двойной индекс, BC=`#6954`, DE сохраняется. Сигнатура, отсутствующая на всех чётных адресах памяти, вызывает бесконечный поиск, договор одиночного ввода использует только проверенные 40 пар.

## Выход

ReadMatrixKey восстанавливает HL, DE и BC поверх рабочих результатов поиска. Возвращается A=`#1D..#5A` по найденной сигнатуре. F соответствует сложению индекса с `#1D`, для штатной таблицы S, Z, P/V, N и Carry сброшены, HalfCarry зависит от переноса младшей тетрады, биты 5 и 3 берутся из кода. Индексные и альтернативные регистры сохраняются, SP восстанавливается. I и IFF собственный код не меняет, для настоящего HALT требуется корректно работающий ISR.

Игровые значения трёх специальных кодов перед пробелом и все вызывающие ветви ещё прослеживаются. Табличный номер и аппаратная сигнатура установлены по байтам, назначение обработчиков этих кодов не подменяется предположением.

## Проверка

[CheckMatrixKey](../Tools/Disasm/Research/CheckMatrixKey.py) прошёл [1640 сценариев](../Tools/Disasm/Reports/MatrixKeyVerification.json), все 40 одиночных клавиш и все 780 пар, с немедленным нажатием и двумя полными пустыми обходами матрицы. Проверены порядок IN, приоритет, десять пробуждений HALT, код, полный F, сохраняемые регистры и стек.

Дополнительно выполнен 41 прямой поиск, все 40 аппаратных сигнатур и пара 0/0. Физический выпуск содержит 63 FKeyBinding с учётом Anchor. Модель явно задаёт пробуждения и байты портов, ISR, аппаратный ввод и нативный запуск не исполняются.
