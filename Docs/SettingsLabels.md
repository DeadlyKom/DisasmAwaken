# Подписи двухбайтовых настроек

[FormatSettingsLabel](../Source/Station/FormatSettingsLabel.asm) по `#A163` получает массив DE и существующую нультерминированную подпись BC. На каждый ненулевой символ подписи читается одна двухбайтовая настройка и заменяется ровно один символ. Длина определяется прежним шаблоном, отдельного счётчика массива нет. Ограничитель не меняется, сами настройки не записываются.

## Представление FSettingWord

| Первый байт ValueOrRow | Второй байт KeyMask | Получаемый символ |
| --- | --- | --- |
| 0..126 | не читается | ValueOrRow+#30 |
| #80 | не читается | N, код #4E |
| #81 | не читается | Y, код #59 |
| допустимая строка матрицы, включая #7F | маска клавиши | результат LookupMatrixKey |

Это дискриминатор целого байта, а не схема независимых флагов. Числовая ветвь просто прибавляет код нуля. Значение 10 даёт символ `:`, многозначное десятичное число не печатается. Значения вне штатных строк матрицы при выборе клавиатурной ветви не проверяются, бесконечный поиск возможен по договору [MatrixKey](MatrixKey.md).

Перед выбором представления BC сохраняется. Поиск клавиши получает B=ValueOrRow,C=KeyMask, его рабочие BC и HL не повреждают внешний обход. После каждого символа DE увеличивается ровно на два, BC на один. На выходе HL восстановлен, BC указывает на прежний нуль, DE стоит за последней прочитанной записью, AF=#0054. Индексные и альтернативные регистры сохраняются. Пустая подпись не читает ни одной настройки.

## Фактические вызовы загрузчика

StartStation вызывает процедуру дважды:

| Подпись | Адрес записей | Длина |
| --- | --- | --- |
| [SettingsText.Interface](../Source/Station/Data/SettingsText.asm) #9728 | #99AE | 13 |
| SettingsText.Controls #9736 | #99C8 | 43 |

Первый массив состоит из [четырёх вариантов](../Source/Station/Data/InterfaceChoices.asm), [шести клавиш](../Source/Station/Data/PointerKeys.asm) и [трёх цветовых слов](../Source/Station/Data/InterfaceColors.asm). Физические байты и порядок сохранены.

- MouseOption и JoyOption участвуют в подготовке программного запрета опроса. Маркер Y принудительно снимает этот запрет, N оставляет результат исходной аппаратной пробы. Называть N безусловным запретом устройства неверно.
- MusicMode=#81 выбирает музыкальную ветвь [ISR](StationInterrupt.md), остальные коды работают по его исходному сравнению.
- FillMode проверяется по биту 0 в рисователях, маркер #80 даёт заполнение #FF, #81 нулевой байт для [тела окна](WindowGraphics.md).
- InkBits объединяется с повернутыми PaperRotate и HighRotate в RebuildInterface. Для штатных значений это цвет чернил, цвет бумаги и старшие атрибуты. Исходный код не маскирует произвольные входные байты, точные ограничения редактора ещё прослеживаются.

[Второй массив](../Source/Station/Data/ControlOptions.asm) содержит 43 слова. У Unknown00 маркер #81, у Unknown01..Unknown41 аппаратные сигнатуры клавиш, у Unknown42 числовой байт 0. Их игровой смысл по отдельным действиям ещё не установлен и прямо сохранён в именах Unknown. Доказаны порядок, тип представления, потребление форматировщиком и исходные байты.

## Сохранение начальных текстов

Исходные подписи являются изменяемыми шаблонами, они не обязаны заранее соответствовать всем исходным словам настроек. Первый исходный текст содержит `YNYNQAOP M040`, а форматирование исходных слов без внешней загрузки настроек даёт `YNYNQAOP M050`. Во второй подписи также есть отличия от результата преобразования. Оба первоначальных текста сохранены побайтово, включая коды #1F и конечные нули. Их нельзя заранее заменять «исправленными» результатами.

## Проверка

[Модель](../Tools/Disasm/Research/CheckSettingsLabel.py) прошла [773 случая](../Tools/Disasm/Reports/SettingsLabelVerification.json), все 127 числовых значений, два маркера N/Y, 40 клавиатурных сигнатур, три прежних символа, пустые и смешанные подписи длиной 0..32. Сверяются массив, ограничитель, соседние байты, указатели, полный AF и сохраняемые регистры.

Два дополнительных случая используют фактические адреса StartStation и исходные секторные настройки с длинами 13 и 43. Это проверка самого преобразования, она не моделирует внешнюю загрузку пользовательских настроек, IRQ или нативный запуск. Полный игровой смысл ещё не разобранных параметров этим не объявляется установленным.
