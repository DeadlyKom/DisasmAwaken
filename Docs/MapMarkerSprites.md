# Ресурсы маркеров карты

Шесть исходных ресурсов занимают CDC3..D0C2, по 128 байтов каждый. Все они передаются C000 в [XorMapPointMarker](../Source/Map/XorMapPointMarker.asm). Имена следуют наблюдаемым источникам координат, игровой тип объекта там, где он ещё не установлен, не подставляется предположением.

| Ресурс | Адрес | Имя в авторском KARTA.a | Координаты |
| --- | --- | --- | --- |
| [Selected](../Source/Map/Resources/MarkerSelected.asm) | CDC3 | SPLUS | MapSelection.FirstWord и SecondWord |
| [Secondary](../Source/Map/Resources/MarkerSecondary.asm) | CE43 | SMINI | Последовательные записи второго списка по 993D |
| [ActiveAux](../Source/Map/Resources/MarkerActiveAux.asm) | CEC3 | STREUG | Четырёхбайтовые пары по 997B с положительным ненулевым кодом списка по 99A3 |
| [Cursor](../Source/Map/Resources/MarkerCursor.asm) | CF43 | SNULL | Запись по SecondaryPointState.Cursor, если её первый байт не FF |
| [Primary](../Source/Map/Resources/MarkerPrimary.asm) | CFC3 | SKREST | Основная координатная пара по 983F и 9841 |
| [Stored](../Source/Map/Resources/MarkerStored.asm) | D043 | SQUADR | Записи первого сохранённого списка по 990A, с пропуском FF |

Каждый ресурс содержит восемь физических экземпляров FMapMarkerPhase по 16 байтов. Phase0..Phase7 выбираются по младшим трём битам относительного X. Поля Row0Left/Right..Row6Left/Right задают семь последовательных строк по два смежных экранных байта. Строка каждой фазы равна 16-битной строке Phase0, сдвинутой вправо на номер фазы с нулевым заполнением.

Два конечных поля названы UnknownTail0 и UnknownTail1. Этот рисователь их не читает, во всех 48 исходных фазах они равны нулю. Они сохранены физически, глобальное назначение и остальные возможные потребители не объявляются установленными. Декларация структуры нейтральна, инициализаторы экземпляров сохраняют исходные значения всех 768 байтов.

[Статическая проверка ресурсов](../Tools/Disasm/Research/CheckMarkerSpriteResources.py) сравнила 384 двухбайтовые строки, включая конечные пары, с независимым сдвигом нулевой фазы. Отчёт содержит контрольную сумму каждого исходного ресурса. Проверка строк не является сборкой или запуском, 96 конечных байтов остаются явно отмеченным смысловым остатком.

## Совпадение с авторскими объявлениями

В `awk6.trd:KARTA.a` каждый из шести указанных блоков содержит
64 последовательных объявления DB по два двоичных байта. Проверка
разбирает все эти строки, по 128 байтов на блок, и сравнивает результат
с машинным KARTA.C того же архива, затем с текущим ресурсом Awakenv02.
Совпадают все 768 байтов по тем же адресам #CDC3..#D0C2.

Поле archived_provenance каждого ресурса в
[отчёте](../Tools/Disasm/Reports/MarkerSpriteResourcesVerification.json)
содержит исходное имя и номера строк объявления. Нулевые конечные
пары присутствуют в самом авторском тексте, они не добавлены нынешней
разметкой или сборкой. Это доказывает их происхождение в составе
фазовых блоков, но не назначает им роль дополнительной экранной строки,
выравнивания либо рабочего резерва. Имена UnknownTail0/UnknownTail1
сохранены, отсутствие иных потребителей не объявляется доказанным.

Алгоритм семистрочного XOR, строгие границы и координатные слова разобраны в [MapPointMarker](MapPointMarker.md). Контекст подготовительной дуги описан в [ArcDispatcher](ArcDispatcher.md), весь композиционный проход C000 ещё проверяется отдельно.

Полная последовательность потребления этих данных разобрана в [DrawMapScene](../Source/Map/DrawMapScene.asm) и [описании композиции карты](MapScene.md).


## Наблюдение чтений с ненулевыми конечными байтами

Дополнительный режим `--resource-reads` [модели рисователя](../Tools/Disasm/Research/CheckMapPointMarker.py) использует контрольный восьмифазный ресурс по #D800 с ненулевыми конечными парами. Во всех 65542 случаях получены ровно 14 последовательных чтений на каждом из 10680 допусков и ни одного чтения ресурса на 54862 отказах. Всего наблюдались 149520 чтений. Проверка охватывает исходное окно 128×96 и прежние координатные профили, а не все возможные адреса и окна. [Отчёт](../Tools/Disasm/Reports/MapPointMarkerResourceReadsVerification.json), [границы модели](MapPointMarker.md#точное-наблюдение-чтений-фазового-ресурса).

Это усиливает подтверждение того, что данный семистрочный вход не читает конечные пары фаз. Архивный замысел этих пар и глобальные потребители не установлены, UnknownTail0/UnknownTail1 сохранены. Игровые исходники и все 768 физических байтов исходных ресурсов не менялись.
