# Ресурсы маркеров карты

Шесть исходных ресурсов занимают CDC3..D0C2, по 128 байтов каждый. Все они передаются C000 в [XorMapPointMarker](../Source/Map/XorMapPointMarker.asm). Имена следуют наблюдаемым источникам координат, игровой тип объекта там, где он ещё не установлен, не подставляется предположением.

| Ресурс | Адрес | Координаты |
| --- | --- | --- |
| [Selected](../Source/Map/Resources/MarkerSelected.asm) | CDC3 | MapSelection.FirstWord и SecondWord |
| [Secondary](../Source/Map/Resources/MarkerSecondary.asm) | CE43 | Последовательные записи второго списка по 993D |
| [ActiveAux](../Source/Map/Resources/MarkerActiveAux.asm) | CEC3 | Четырёхбайтовые пары по 997B с положительным ненулевым кодом списка по 99A3 |
| [Cursor](../Source/Map/Resources/MarkerCursor.asm) | CF43 | Запись по SecondaryPointState.Cursor, если её первый байт не FF |
| [Primary](../Source/Map/Resources/MarkerPrimary.asm) | CFC3 | Основная координатная пара по 983F и 9841 |
| [Stored](../Source/Map/Resources/MarkerStored.asm) | D043 | Записи первого сохранённого списка по 990A, с пропуском FF |

Каждый ресурс содержит восемь физических экземпляров FMapMarkerPhase по 16 байтов. Phase0..Phase7 выбираются по младшим трём битам относительного X. Поля Row0Left/Right..Row6Left/Right задают семь последовательных строк по два смежных экранных байта. Строка каждой фазы равна 16-битной строке Phase0, сдвинутой вправо на номер фазы с нулевым заполнением.

Два конечных поля названы UnknownTail0 и UnknownTail1. Этот рисователь их не читает, во всех 48 исходных фазах они равны нулю. Они сохранены физически, глобальное назначение и остальные возможные потребители не объявляются установленными. Декларация структуры нейтральна, инициализаторы экземпляров сохраняют исходные значения всех 768 байтов.

[Статическая проверка ресурсов](../Tools/Disasm/Research/CheckMarkerSpriteResources.py) сравнила 384 двухбайтовые строки, включая конечные пары, с независимым сдвигом нулевой фазы. Отчёт содержит контрольную сумму каждого исходного ресурса. Проверка строк не является сборкой или запуском, 96 конечных байтов остаются явно отмеченным смысловым остатком.

Алгоритм семистрочного XOR, строгие границы и координатные слова разобраны в [MapPointMarker](MapPointMarker.md). Контекст подготовительной дуги описан в [ArcDispatcher](ArcDispatcher.md), весь композиционный проход C000 ещё проверяется отдельно.

Полная последовательность потребления этих данных разобрана в [DrawMapScene](../Source/Map/DrawMapScene.asm) и [описании композиции карты](MapScene.md).
