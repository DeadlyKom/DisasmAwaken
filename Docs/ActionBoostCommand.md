# Проверка пространства перед ускорением

[RequestBoost](../Source/Action/RequestBoost.asm) соответствует физическому клавиатурному указателю `74A3`. [Факты, комментарии и договор](../Tools/Disasm/Research/ActionBoostCommandFacts.py), [числовая модель](../Tools/Disasm/Research/ReferenceActionBoostCommand.py), [сквозная проверка](../Tools/Disasm/Research/CheckActionBoostCommand.py).

При MotionOpcode `C9` команда возвращается без изменений. Все остальные значения допускают установку общего Request в 1. Требование опкода `3A` действует позднее, внутри изменения SignedWord. Поэтому два запрета не тождественны.

Список читается с `A100` шагом FActionRecord, 64 байта. High первой компоненты `80` обозначает свободную запись, пара `8080` завершает список. Из активных записей проверяются классы меньше `10` и отдельный класс `12`. StateCode не ограничивается.

Для каждой из трёх компонент берётся только старший байт. При сброшенном знаке он сохраняется, иначе инвертируется без прибавления единицы. Результаты объединяются побитовым OR. Если объединённый байт меньше `30`, команда хвостовым JP передаёт управление [ReleaseClass14Records](../Source/Action/ReleaseClass14Records.asm), который повторным поиском помечает все активные записи класса `14`. Request остаётся установленным. Здесь нет точного евклидова расстояния, сферической проверки или сравнения каждого модуля с порогом по отдельности. Исходная квантованная проверка сохранена.

При достижении конечного маркера переход идёт в [AdvanceBoost](ActionBoostAdvance.md) по `7504`. Между двумя физическими фрагментами находится самостоятельная [SelectPreferredByte](../Source/Action/SelectPreferredByte.asm) по `74FB..7503`. Оба фрагмента сохранены на своих местах, условный JR через эту функцию остаётся настоящим переходом.

69728 сценариев исполняют оба фрагмента и настоящих детей до внешнего RET. Сверяются регистры кроме R и тактов, восемь банков RAM и кратность записей вне 32 временных байтов стека. Отдельно перебраны все пары Preferred/Fallback, все значения каждого старшего байта, класса, входного опкода и вращений на выбранных срезах, все пары FastPhase и трёхбитовой SlowPhase. Полное совместное произведение входов, IRQ, сборка и нативная игра не проверялись.
