# Матрица ориентации модели

[BuildPreviewModelMatrix.asm](../Source/D3D/BuildPreviewModelMatrix.asm), банк 4, #EF5E..#F055, подготавливает девять байтовых операндов кода #D54C. Вход вызывается по #EF33 после распаковки узла очереди. Это самостоятельная процедура с обычными CALL/RET, а не проход рисования всего кадра.

## Данные и соглашения

Три байтовых угла лежат по #C21E..#C220, один оборот равен 256. Flags находится по #CEFA. Бит 0 выбирает короткую ветвь. [Построитель очереди](PreviewQueueBuild.md) устанавливает его, когда первый и третий углы равны нулю. Сама матричная процедура это равенство не проверяет, при установленном бите она игнорирует эти два угла. Другие семь битов выбора ветви не меняют.

Страница #C400 содержит 256 исходных знаковых байтов синусоиды. Все байты совпадают с формулой clamp(round(128*sin(2*pi*i/256)), -127, 127). Это проверенная формула конкретной таблицы, а не замена исходных данных вычислением при сборке. Косинус читается из той же страницы по индексу (angle+64)&255. Значение −128 отсутствует.

В формулах ниже sj=S(aj) и cj=S((aj+64)&255). P(a,b) — точное [табличное произведение](PreviewLookupProducts.md) через свёрнутые квадраты #C300, включая округление отрицательных половин вниз. Его нельзя заменять на обычное целочисленное умножение с делением на 127 или 128.

Имена коэффициентов следуют потребителю #D54C. Там три байта каждого столбца загружаются в B, C, D и комбинируются со строками матрицы сцены. Адреса являются операндами инструкций, отдельная новая область под матрицу не выделяется.

| Поле | Операнд | Формула общей ветви |
| --- | --- | --- |
| Coeff11 | #D561 | P(c3,c2) |
| Coeff21 | #D563 | R(P(P(c2,c1),s3) + P(s2,s1)) |
| Coeff31 | #D565 | R(P(P(c2,s1),s3) − P(s2,c1)) |
| Coeff12 | #D5FD | P(s2,c3) |
| Coeff22 | #D5FF | R(P(P(s2,c1),s3) − P(c2,s1)) |
| Coeff32 | #D601 | R(P(P(s2,s1),s3) + P(c2,c1)) |
| Coeff13 | #D6A9 | −s3 |
| Coeff23 | #D6AB | P(c3,c1) |
| Coeff33 | #D6AD | P(c3,s1) |

Вложенные P вычисляются именно в указанном порядке. Промежуточные значения остаются байтами исходного табличного алгоритма.

## Коррекция R

Сначала выполняется исходный ADD или SUB. Если знакового переполнения P/V нет, его результат и флаги сохраняются. При переполнении выполняется NEG обёрнутого результата. Если NEG также устанавливает P/V, то есть его вход равен #80, выполняется DEC до #7F.

Это отражение, а не насыщение. Например, 127+127 даёт обёрнутый #FE, затем NEG даёт 2. Сумма 127+1 даёт #80 с переполнением, NEG снова даёт #80 с переполнением, DEC даёт #7F. Представимое −128, полученное без переполнения исходного ADD/SUB, сохраняется как #80. Нельзя исправлять эту особенность исходной игры.

Четыре одинаково устроенные коррекции расположены по #EFE0, #F005, #F022 и #F047. Итоговые AF всей общей ветви принадлежат последней коррекции Coeff32. Записи LD и RET флаги не меняют.

## Короткая ветвь

При установленном бите 0 записываются столбцы (c2,0,−s2), (s2,0,c2) и (0,127,0). Она читает только второй угол, не вызывает табличные помощники и не меняет IX/IY. B получает второй угол, C и DE сохраняются. HL равен #C400+второй угол, AF равен #7F44.

При всех нулевых углах обе ветви дают столбцы (127,0,0), (0,0,127), (0,127,0). Нулевая ориентация меняет местами вторую и третью оси. Поэтому эти данные не объявляются обычной единичной Euler-матрицей с произвольно выбранным порядком осей.

## Контракт общей ветви

Все девять коэффициентов записываются. BC содержит s1 и c1, DE содержит s3 и последний прочитанный свёрнутый квадрат. HL содержит страницу #C3 и последний индекс суммы табличного помощника. IX содержит P(c2,c1)*256+s2, IY содержит c3*256+c2. AF содержит Coeff32 и точные флаги его последней арифметической коррекции.

Альтернативные регистры, I, IFF и IM не изменяются. SP после RET равен входному SP+2. Вложенные CALL общей ветви используют два байта непосредственно под входным SP, последний оставшийся там адрес равен #F047. Короткая ветвь эти два байта не пишет. Повторный вход недопустим из-за общих параметров и изменяемых операндов.

## Проверка и границы

[CheckPreviewModelMatrix.py](../Tools/Disasm/Research/CheckPreviewModelMatrix.py) исполняет исходные байты и сравнивает их с независимой [числовой моделью](../Tools/Disasm/Research/PreviewModelMatrixOracle.py). Проверены 7616 наборов, из них 1024 коротких и 6592 общих, включая все одноосные углы, граничные тройки и фиксированную случайную выборку. Проверены коэффициенты, точные регистры, границы записей и стек.

Все 65536 байтовых пар отдельно проверены для каждого из четырёх участков коррекции, всего 262144 случая, включая точные флаги ADD/SUB, NEG и DEC. Исходная синусоида сверена по всем 256 байтам. Это не исчерпывающий перебор всех 16777216 троек углов.

[Отчёт](../Tools/Disasm/Reports/PreviewModelMatrixVerification.json) не подтверждает весь потребитель #D54C, проекцию, грани, растеризацию, IRQ, нативную игру или сборку. [Обзор D3D](D3DPreview.md) сохраняет эти задачи открытыми.
