# State04, ускоренное изменение фаз записи

[StepFastRecordPhases](../Source/Action/StepFastRecordPhases.asm)
занимает F6AB..F6BC ACTION банка 0. Два отдельных INC увеличивают
OffsetPhase1 на два, три следующих INC увеличивают OffsetPhase2 на три.
Каждое промежуточное значение реально записывается, оборачивание байтов
сохраняется. Затем JP передаёт управление
[ApplyRecordLocalOffsets](ActionLocalOffsets.md), увеличивающему
OffsetPhase0 ещё на один.

Изменённые фазы 07..09 не подменяют фазы текущего вычислителя,
которые этот хвост читает из 0D..0F. Дальнейшие результаты регистров,
коэффициентов и Base0..2 определяются его договором. Дополнительного
CALL нет, максимальная рамка CPU-стека равна шести байтам, SP после
внешнего RET увеличен на два. R добавляет 11 M1 к стоимости общего хвоста.

[Независимая модель](../Tools/Disasm/Research/CheckActionLocalOffsetState.py)
исчерпала все 65536 пар OffsetPhase1 и OffsetPhase2 для этого входа.
Ещё 65536 сценариев проверяют общий хвост. Настоящие дети исполняются
до полного возврата, сверены регистры, флаги, R, восемь банков RAM и
кратность всех промежуточных записей. Полное произведение прочих входов,
IRQ, сборка и нативный запуск не выполнялись.
