# Команда возврата к станции

[RequestStationReturn](../Source/Action/RequestStationReturn.asm), исходные 7606..7629 переносимого ядра ACTION банка 5, является целью Index12 [таблицы клавиш](../Source/Action/Data/KeyHandlerPointers.asm). Команда проверяет полное поле ReturnSystem.Value по 9C27, его имя установлено по [авторской раскладке оборудования](ActionEquipmentCodes.md).

Ненулевой CommandDelay даёт немедленный обычный возврат, A содержит задержку, F соответствует AND A, записи памяти и OUT отсутствуют. При нуле CursorA банка 0 получает исходный звуковой поток EE1B, задержка получает 20. Только после этих двух записей проверяется оборудование. Если ReturnSystem.Value=FF, обработка завершается с HL=EE1B, A=0, F=50, DE и BC сохранены. Звуковой поток и задержка уже изменены, сам проигрыватель здесь не запускается.

При любом другом полном коде ReturnSystem.Value получает FF. Затем OUT 7FFD записывает 19, выбирая банк 1, теневой экран и ROM 1 без блокировки paging. Безусловный JP передаёт управление [PrepareStationReload](../Source/Controls/PrepareStationReload.asm). Это успешный переход режима, обычного возврата к RestoreKeyScanFrame нет.

Настоящий банковый подготовитель очищает 768 атрибутов базового экрана, меняет местами два байта LowPairs, сохраняет 512 байтов от HighPairs в 4000..41FF и переносит 256 байтов следующей стадии в 4200..42FF. Списанный ReturnSystem.Value находится внутри сохраняемых 512 байтов, поэтому копия также содержит FF. Старый SP и рамка клавиатурного диспетчера отбрасываются. Новый стек по 5FFD/5FFE содержит 4200, его снимает RET, оставляя SP=5FFF и PC=4200.

На этой границе HL=DE23, DE=4300, BC=0, A=3F, IY=5C3A, I=3F, IM=1, IFF сброшен. IX и альтернативные регистры сохраняются. F сохраняет S/Z/Carry от предшествующего INC кода оборудования, остальные биты определены последним LDIR по [формуле подготовителя](ControlsStationPrepare.md). R учитывает исходные M1 команды и 3097 M1 подготовителя. Итоговая конфигурация 7FFD остаётся 19.

[Композиционная модель](../Tools/Disasm/Research/CheckActionStationReturnCommand.py) исполняет исходные инструкции команды, настоящий OUT и весь PrepareStationReload. [1792 сценария](../Tools/Disasm/Reports/ActionStationReturnCommandVerification.json) покрывают все задержки, все полные коды оборудования и 256 заполнений сохраняемого блока и переносимого следующего блока при пяти кодах оборудования. Сверены точные архитектурные регистры, включая R, вся физическая RAM, кратность записей и порядок портовых выходов. Такты отдельно не проверяются, IRQ не вмешиваются до DI.

Проверка останавливается перед первой инструкцией по 4200. Произвольное содержимое переносимого блока в части сценариев используется только для проверки копирования и не исполняется. TR-DOS, фактическая загрузка STATIONF и нативный переход игры к станции этой моделью не подтверждаются. Сама следующая стадия имеет отдельный [разбор](ControlsStationPrepare.md). Ассемблер не запускался.

[Факты и договор команды](../Tools/Disasm/Research/ActionStationReturnCommandFacts.py) используются [общим издателем команд](../Tools/Disasm/Research/PublishActionTargetCommands.py). Исследовательский Python для обычной сборки не требуется.

[Сквозная модель](StationFlightCycle.md) дополнительно достигает входа 7606
через оригинальный сканер. Index12 использует порт FBFE и маску 08.
Успешная ветвь с подготовленным оснащением восстанавливает контекст,
после чего свежий STATIONF снова доходит до цикла станции.
