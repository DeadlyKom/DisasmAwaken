# Возврат из предупреждения обновления записи

[FinishRecordWarning](../Source/Action/FinishRecordWarning.asm), исходные E655..E657 ACTION банка 0, состоит из POP DE и JR в [RestoreHalvedOffsets](../Source/Action/RestoreHalvedOffsets.asm). Это внутренний вход после CALL очереди, а не самостоятельная процедура с обычным входным стеком.

Слово под входным SP содержит сохранённый DE, следующее слово — внешний возврат. POP DE восстанавливает значение до временной загрузки адреса текста. Общий хвост восстанавливает три смещения только для класса 14, затем RET читает внешний возврат. Итоговый SP равен входному SP+4. CPU-стек не записывается. R получает 13 M1 для класса 14 либо 6 для остальных кодов, бит 7 сохранён. HL и AF определены договором восстановителя, BC, альтернативные и индексные регистры сохранены.

[Модель](../Tools/Disasm/Research/CheckActionRecordWarningReturn.py) проверила все 65536 сохранённых слов DE и все 256 кодов класса. Сопоставлены регистры включая R, все физические банки RAM и записи общего хвоста. Код класса связан со старшим байтом DE, полное произведение двух входов не перебиралось. [Отчёт](../Tools/Disasm/Reports/ActionRecordWarningReturnVerification.json) не подтверждает IRQ, точные T, сборку или нативный запуск.

Пара [UpdateRecordComponents](../Source/Action/UpdateRecordComponents.asm) (0) и FinishRecordWarning (1) зависит от последовательного исполнения include. Дополнительный машинный JP для обозначения продолжения не вводится.
