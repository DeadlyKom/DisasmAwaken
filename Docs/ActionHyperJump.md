# Запрос гиперперехода

[RequestHyperJump](../Source/Action/RequestHyperJump.asm) по `70F6..7175` является последней из 26 отдельных физических целей клавиатурной таблицы. [Договор, комментарии и имена](../Tools/Disasm/Research/ActionHyperJumpFacts.py), [модель](../Tools/Disasm/Research/ReferenceActionHyperJump.py), [проверка](../Tools/Disasm/Research/CheckActionHyperJump.py).

Ненулевая CommandDelay запрещает обработку. При нулевой задержке читается HyperTrail.Value, полный код FF запрещает переход. Команда сама новую задержку не устанавливает.

Сравнение Preferred с существующим операндом Selector по `7104`, исходно `00`, выбирает маршрут расхода. При исходном значении Selector ненулевой Preferred оплачивает удвоенный байт Cost по `9C8A`, нулевой Preferred переводит оплату на Fallback с одинарной стоимостью. Удвоение выполняется в слове, поэтому значения Cost от 128 не превращаются в небольшую байтовую стоимость. При недостаточном запасе команда возвращается с Carry и обёрнутой разностью в HL без изменения запаса.

При достаточном запасе выбранное поле получает остаток до сравнения контекстов. Пять байтов по `9BC6..9BCA` сравниваются с `9BC1..9BC5`, сначала два слова, затем последний байт. Если все байты равны, следует RET, но расход остаётся. Это поведение исходной игры сохранено. При различии второй контекст копируется в первый и последовательное исполнение идёт в [PrepareHyperJumpRelay](ActionHyperJumpPreparation.md) по `7176`. Адреса не перемещаются, include имеют отмеченный жёсткий порядок.

Физические пять байтов уже оформлены в ActionParameterSeeds и ActionOtherContext, их дополнительные игровые смыслы не выводятся только из этого обработчика. Значение Cost читается непосредственно из существующего байта, здесь его производитель не установлен. Selector является изменяемым операндом инструкции, отсутствие найденного писателя не доказывает его неизменность во всей игре.

132864 сценария проверяют все пары запас/стоимость обоих маршрутов, все задержки и коды оборудования, каждое значение каждой позиции контекста. Сверяются регистры кроме R и тактов, все восемь банков RAM и кратность записей. На принятом пути эта серия останавливается перед сообщением по `7176`, его настоящий подготовитель проверен [отдельно](ActionHyperJumpPreparation.md). Полное совместное произведение входов, IRQ, сборка и нативная игра не проверялись.
