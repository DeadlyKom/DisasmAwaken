# Создание предложения и закрытие группы миссий

[RefreshMissionOfferPanels](../Source/Station/RefreshMissionOfferPanels.asm), вход `#AA3D`, связывает уже разобранные процедуры в фиксированном порядке. Сначала [GenerateMissionOffer](../Source/Station/GenerateMissionOffer.asm) формирует предложение с использованием текущего ключа, RNG, ROM как данных и расстояния. Затем BeginScreenUpdate создаёт снимок экрана, [DrawItem31](../Source/Station/DrawItem31.asm) рисует название цели, [DrawItem32](../Source/Station/DrawItem32.asm) условия миссии, [DrawItem00](../Source/Station/DrawItem00.asm) статус игрока. Хвостовой JP EndScreenUpdate показывает результат и возвращается через исходный адрес вызывающего.

Обёртка сама не сбрасывает ActiveCode. У DrawItem32 имеется [собственный путь завершения миссии](MissionCompletion.md), который может начислить награду, изменить груз, вызвать LANG и генератор ещё раз. Поэтому сохранение предложения после всех рисунков гарантируется только при отсутствии этого пути. [Генератор и его пределы](MissionOffer.md) имеют отдельную независимую проверку.

[HandleMissionGroupAction](../Source/Station/HandleMissionGroupAction.asm), вход `#AA58`, вызывает RepaintAndTrack.KeepSelector и сразу выходит при Carry. Селектор 1 собственного действия здесь не имеет, DEC превращает его в ноль, после чего выполняется общий RET. Это не обработчик принятия миссии.

Остальные селекторы передаются CloseMenuOnRow. При несовпадении символьных строк указателя и начала окна группа и периодическая цель самостоятельно не меняются. При совпадении текущая панель уже удалена помощником. Затем PeriodicCall становится EmptyCallback и по текущим изменяемым индексам последовательно удаляются панели названия цели 31, условий 32 и действия 33. Последнее удаление вызывается хвостовым JP. Если текущая панель была одной из этих трёх, повторное удаление может не найти совпадения. Каждое найденное совпадение переносит ровно 128 физических байтов, включая хвост списка.

[CheckMissionPanelActions.py](../Tools/Disasm/Research/CheckMissionPanelActions.py) выполнил 128 полных обновлений с настоящим генератором и рисователями на двух страницах. Результат предложения и RNG совпал с отдельным исполнением генератора. Охвачены ActiveCode 0, 1, 2 и FF, для 1 новый пункт отличается от текущего, завершение не наступает. Исполнено 256 настоящих IM2 в HALT заголовков, музыка выключена. Проверены все 256 селекторов с двумя положениями указателя, 127 закрытий группы и 385 случаев без её закрытия. [Отчёт](../Tools/Disasm/Reports/MissionPanelActionsVerification.json).

Это проверка композиции уже исследованных процедур. Независимое сравнение всего bitmap обновления не заявляется. ROM модели использована только как читаемые данные и не сверялась с ROM Unreal. Сборка и нативный запуск не выполнялись.
