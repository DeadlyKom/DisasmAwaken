# Повторный выбор класса перед общим подготовителем

[RefreshRecordClassAndOffsets](../Source/Action/RefreshRecordClassAndOffsets.asm)
занимает F003..F008 ACTION банка 0. Настоящий CALL вызывает
[DispatchRecordClass](ActionClassDispatch.md), который исполняет одну
из одиннадцати различных процедур по 26 словам исходной таблицы.
RET выбранного ребёнка возвращается по F006, затем JP передаёт
исходный внешний CPU-стек общему PrepareObjectOffsetTransform по F0F8.

Индекс диспетчера отбрасывает бит 7 ClassCode, необходимая граница
договора — ClassCode AND 7F < 26. Фильтры внутри детей могут сравнивать
полные коды, алиас таблицы не объявляется универсальной маской класса.
Регистры и изменения полей до F0F8 определяются точным договором
выбранного ребёнка. D, AF', IX, I, IM, IFF и paging сохраняются.
SP на границе F0F8 равен входному, внешний возврат сохраняется.
Максимальная дополнительная рамка равна двенадцати байтам.

R добавляет 15 M1 к стоимости выбранного обработчика, 13 диспетчера,
один CALL и один JP. Бит 7 R сохраняется. Сам общий F0F8 и его
вычислитель имеют отдельные договоры, этой проверкой они не исполняются.

[Независимая композиционная проверка](../Tools/Disasm/Research/CheckActionClassRefresh.py)
исполнила 39936 сценариев, все 26 классов, оба алиаса старшего бита,
все начальные R и три значения подстановки 0, 1, FF. Специальные
нулевые результаты потока включены для достижения вложенного общего
поиска класса 1 и максимальной рамки. Все одиннадцать различных
целевых процедур исполняются реально. Сверены точные регистры,
флаги, R, SP, восемь банков и кратность всех записей.
Полное произведение входов, аппаратные IRQ, сборка и нативный запуск
не выполнялись.
