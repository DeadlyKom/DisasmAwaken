# Дополнительные пары масок ACTION

Начальные 512 байтов по #8C00..#8DFF совпадают с началом файлов D3D и DATAS. В ACTION это файловые смещения #2C00..#2DFF. 3DPART подменяет область от #C000 и использует те же страницы ниже #C000.

При заливке широкого пролёта D511 выбирает страницу #8C для первой строки и чередует её с #8D на следующих строках. Для левой границы смещение пары равно `32 * (X AND 7) + 2 * Mode`. Для правой границы к этому смещению добавляется 16. Ядро читает оба байта и записывает крайний байт строки по формуле `(старый байт AND AndMask) OR OrMask`. Ранее разобранные геометрические маски относятся к индексам 0..4.

При подаче 5..7 в модель исходный код читает ещё три пары на каждую фазу, сторону и страницу. Для заливки внутренних байтов он при этом берёт начальный шаблон и XOR следующей строки из первых шести байтов кода ClearWorkBuffer. По #D10A, #D10C и #D10E находятся соответственно пары `ED 73`, `29 D1`, `31 00`. Эти чтения установлены отдельно для ACTION и 3DPART. У D3D собственное начало таблицы внутренних шаблонов.

87 полных пар из 96 оформлены через FPolygonLiteralEdgeMask. По #8D2A..#8D2D, #8D3A..#8D3F, #8D4A..#8D4F и #8D5A с чтениями перекрываются 17 байтов существующих рабочих полей. Их исходная структура сохранена. #8D5B служит операндом OR при принудительном индексе 5, правой границе фазы 2 и второй странице. Исходный нулевой байт сохранён отдельно от парного FaceGate. При работе игры фактические значения перекрытых байтов могут отличаться от дисковых. [Операнд OR](../Source/Action/Resources/OddRightPhase2Mode5Or.bin)

В [модели исходного Z80](../Tools/Disasm/Research/CheckActionPolygonExtraMaskPairs.py) выполнено по 384 двухстрочных прямоугольника на оверлей. Трасса сверяет адреса и значения обоих чтений шаблона и всех восьми чтений масок на сценарий. Целочисленный эталон независимо проверяет итоговую память, кратность записей и восстановление SP. [Результат проверки](../Tools/Disasm/Reports/ActionPolygonExtraMaskPairsVerification.json) фиксирует все 192 адреса масок. Штатный выбор 5..7 и их геометрическое назначение остаются неизвестными.
