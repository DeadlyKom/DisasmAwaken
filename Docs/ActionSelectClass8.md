# Выбор записи класса 8

[SelectClass8ForRecord](../Source/Action/SelectClass8ForRecord.asm)
занимает E97C..E98C ACTION банка 0. Это резервный поиск первого полного
кода класса 08, а не проверка набора флагов. Конкретное игровое имя
класса не назначается. IX указывает текущую запись, поле Unknown20
доступно для записи. Исходный IY не задаёт цель поиска.

В D помещается 08, затем
[FindRecordByCode](ActionRecordIterator.md) начинает поиск с A100.
При отсутствии цели IY указывает достигнутый маркер, AF=8042, поле
Unknown20 сохраняется. При успехе
[RecordIYToIndex](ActionRecordIndex.md) вычисляет байтовый индекс
найденного адреса, затем этот индекс сохраняется в Unknown20 текущей
записи. Никакого копирования компонентов выбранного объекта нет.

На обоих путях управление передаётся
[PrepareObjectOffsetTransform](../Source/Action/PrepareObjectOffsetTransform.asm)
по F0F8 с исходным SP. Сам фрагмент внешнего RET не выполняет.
HL и входной E сохраняются, D=08, BC=0040. Альтернативные регистры,
IX, I, IM, IFF и paging сохраняются. IY возвращает найденный адрес
либо маркер. При успехе A и F равны результату преобразования индекса,
по этим флагам нельзя заново интерпретировать успех поиска.

Максимальная дополнительная рамка равна шести байтам CPU-стека.
Внешнее слово возврата сохраняется. R получает стоимость реального
FindRecordByCode плюс три M1 при отсутствии цели либо плюс 23 M1
при успехе. Бит 7 R сохраняется, младшая часть оборачивается.
Точные T этой формулой не доказываются.

[Проверка](../Tools/Disasm/Research/CheckActionSelectClass8.py) исполнила
6656 сценариев, 256 полных кодов класса и 26 вариантов позиции.
Получены 25 успешных выборов всех исходных индексов 0..24 и 6631
отсутствие цели. Реальные поиск и преобразователь адреса исполняются.
Независимо рассчитаны регистры, флаги, R и все записи, включая
остаточные слова CPU-стека. Число слотов исходного состояния не
объявляется общим пределом произвольных игровых списков.

Проверка останавливается перед F0F8. Эффекты общего хвоста описаны в
[подготовке смещений](ActionObjectOffsetTransfer.md) и не выдаются
за выполненные этим тестом. Полное произведение возможных списков,
IRQ, сборка и нативный запуск не выполнялись.
