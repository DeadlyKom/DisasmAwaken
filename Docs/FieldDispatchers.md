# Диспетчеры полей и затенённый символ

[DispatchUnaryField](../Source/Text/DispatchUnaryField.asm) выбирает семь записей после якоря CA4F. [DispatchWriteField](../Source/Text/DispatchWriteField.asm) семь после CA3A. [DispatchReadField](../Source/Text/DispatchReadField.asm) 36 после C980, затем последовательно входит в [DispatchToken](../Source/Text/DispatchToken.asm), этот порядок include жёсткий.

Каждый вход читает A по IX, увеличивает IX на один, задаёт якорь в HL и число записей в B. [FindToken](../Source/Text/FindToken.asm) сравнивает байты по порядку. При первом совпадении B содержит остаток включая найденную запись, C сохраняется, DE=3. DispatchToken получает адрес обработчика в HL, его младший байт в A и входит через JP (HL). F остаётся от совпавшего CP, Z=1. SP на входе обработчика равен входному SP диспетчера, дополнительного CALL обработчика нет. Альтернативные и индексные регистры кроме IX сохраняются самим диспетчером.

У чтения 36 физических записей, но 35 разных символов. Байт y=79 встречается по C998 с PushTrue и по C9EC с ReadFieldLowery. Поиск всегда выбирает ранний PushTrue, поздний вход ReadFieldLowery затенён при обычном DispatchReadField. Его собственный алгоритм разобран и может исполняться по прямому адресу, но таблица чтения через y его не выбирает. Исходный порядок и оба физических экземпляра сохранены.

Если совпадения нет, FindToken выполняет JP SkipLine вместо RET. Поэтому на входе SkipLine остаётся возврат в C7DD, SP равен входному SP диспетчера минус два. A содержит неизвестный символ, B=0, C сохранён, HL у последней записи, DE=3, F от последнего CP. Последующий SkipLine восстановит собственный сохранённый SP, это отдельный договор. Отсутствие символа не является обычным возвратом ошибки.

[CheckFieldDispatchers.py](../Tools/Disasm/Research/CheckFieldDispatchers.py) исполняет все 256 байтов каждого входа до обработчика либо SkipLine. Проверены 49 совпадений и 719 отсутствий, первый y, полные регистры, F, IX, SP и оставшийся возврат. Отчёт [FieldDispatchersVerification](../Tools/Disasm/Reports/FieldDispatchersVerification.json). Сами обработчики проверены отдельными моделями, сборка, IRQ и нативный запуск не выполнялись.
