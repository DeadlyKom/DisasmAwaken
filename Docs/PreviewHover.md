# Пустое наведение панели 3D-просмотра

[IgnoreModelPreviewHover](../Source/Station/IgnoreModelPreviewHover.asm) по #6837 является EventHandler исходной записи 26 FInterfaceItem. Единственная инструкция JP #686F передаёт исходный адрес возврата в [ReturnModelPreviewHover](../Source/Station/ReturnModelPreviewHover.asm), содержащий единственный RET. Дополнительного кадра стека нет.

Полный алгоритм этих входов установлен непосредственно по исходным инструкциям. HL, DE, BC, AF, альтернативные регистры, IX, IY, I, IM и IFF сохраняются. Память и порты не записываются. RET читает исходный адрес, обычный выход увеличивает SP на 2. R сохраняет бит 7, младшие семь бит увеличиваются на два для пути JP+RET либо на один для прямого RET по модулю 128. Внешний CALL не включён. Условия точного счёта требуют исходных команд и отсутствия IRQ/NMI.

Действие вызывается диспетчером отдельно по EventHandler+3, адрес #683A, см. [HandleModelPreviewClick](../Source/Station/HandleModelPreviewClick.asm) и [PreviewAction](PreviewAction.md). Пустое наведение туда не проваливается. Действие разобрано отдельно.

Рисователь [DrawShipPreview](../Source/Station/DrawShipPreview.asm), периодические входы и кадр D3D требуют отдельного разбора, см. [ShipPeriodicCode](ShipPeriodicCode.md) и [D3DPreview](D3DPreview.md). Документирование пустого пути не закрывает их контракты и не доказывает нативную работу панели.

## Проверка обоих пустых возвратов

[CheckPreviewHoverReturns](../Tools/Disasm/Research/CheckPreviewHoverReturns.py)
проверяет также соседнюю панель описания из физической FInterfaceItem 27,
см. [DescriptionPanel](DescriptionPanel.md). Физические записи 26 и 27
подтверждают владельцев JP-обёрток по 6837 и 6913, цели 686F и 693D
содержат исходные RET. Действия по Entry+3 в эти пути не входят.

Все 65536 AF проверены для каждой из четырёх точек, всего 262144 вызова.
Проверены каждая команда, каждый шаг R, сохранение регистров, I/IM/IFF
и полных банков памяти, отсутствие портовых записей и SP после RET.
Отсутствие записей в RAM дополнительно следует из точных опкодов JP/RET.
Для каждого входа охвачены все начальные R, полного совместного
перебора регистров нет. Стек модели фиксирован, возвращённая цель
не исполняется. IRQ, нативная игра и сборка не запускались.
