# Передача управления правому обновлению без изменения контекста

[SelectPolygonRightEdge](../Source/Action/SelectPolygonRightEdge.asm) содержит исходные байты D268..D26A банка 0. Полный регистровый договор и условия временного стека приведены в исходнике. Это переходник [линейной заливки](ActionPolygonFill.md), его назначение ограничено переносом индекса либо восстановлением контекста.

[Проверка](../Tools/Disasm/Research/CheckActionPolygonBridges.py) прошла 256 сценариев, [отчёт](../Tools/Disasm/Reports/ActionPolygonSelectRightVerification.json). Сверены регистры кроме R и отсутствие записей RAM. Для оборачивания левого индекса исчерпаны все байты индекса и флагов, для верхней левой обёртки все альтернативные A и основные F. Расширенные байты локальной проверки не объявляются штатными игровыми индексами. Сборка, IRQ и нативное исполнение не выполнялись.
