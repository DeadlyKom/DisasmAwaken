# Второй список оснащения станции

В STATIONF по файловым смещениям 160B..16C9 лежат 191 исходный байт.
Перенос станционного кода даёт адреса 735F..741D. Процедуры, их прямые
связи и использование текста установлены. Какой штатный интерфейсный
путь назначает эти входы, пока неизвестно.

[ScrollSecondaryRows](../Source/Station/ScrollSecondaryRows.asm) снимает
прежнюю XOR-полосу, если сохранённая строка отличается от FF. При этом
слово DE читается из двух байтов Row, RowCount. В младшем E находится
сама строка. Отступ 24 используется отдельно, уже при вызове прокрутки.
Затем Row становится FF, общий callback получает RenderRows по 73FB,
предел начального индекса равен 13. Полный результат HL записывается
в собственный операнд TopRow по 737D.

[SelectSecondaryRow](../Source/Station/SelectSecondaryRow.asm) проверяет
маркер FF, затем рассчитывает индекс описания (TopRow.low + Row + 30) AND FF.
Новый индекс обновляет описание и обнуляет его прокрутку. Для повтора
исходный режим из 71EC выбирает событие 7 при нуле и 8 иначе. Сценарий
исполняется в LANG банка 6, после него банк 0 снова выбран. Статус и
второй список обновляются независимо от результата сценария.

[TryDrawSecondaryList](../Source/Station/TryDrawSecondaryList.asm)
проверяет текущее слово LD DE в списке рисователей. Исходное слово равно
73DE, поэтому найденный указатель разрешает последовательное продолжение.
Во время работы те же два байта являются Row и RowCount. Если слово
изменилось, тест ищет именно изменённое значение. Этот псевдоним
сохранён в исходнике и в реестре самомодификации.

[DrawSecondaryList](../Source/Station/DrawSecondaryList.asm) строит рамку
с исходным индексом элемента 0, настраивает колонки, обновляет Row=FF
и выводит общие заголовки. RenderRows обходит рамку и сброс Row,
полный индекс принимает в HL. Счётчик попыток печати сохраняется в
RowCount, включая попытку чтения маркера 80.

[PrintSecondaryRows](../Source/Station/PrintSecondaryRows.asm) готовит
четыре базы количеств, цен, порога с весом и типов. Селектор берётся из
CurrentModels.SkimmerIndex. Вместе с указателем текста F066 и полным
индексом это тот же [кадр печати](EquipmentListPanels.md), который
принимает общий вход AtNameStream. Начальный индекс 0 выбирает строку
«Топливо СМРП», индекс 1 строку колонок доставки.

[Проверка](../Tools/Disasm/Research/CheckSecondaryEquipmentRows.py)
сравнила 1020 вызовов общего печатателя по фактическому второму входу
с независимым эталоном. Из них 120 использовали исходный текст F066.
Отдельные 272 профиля охватили прокрутку с недостаточной высотой,
проверку точного указателя, рисование рамки, отсутствие строки,
изменение описания и повторный выбор. Все 256 байтов режима проверены
до входа LANG, три случая выполнены до возврата с исходным сценарием.
Изменяемый ввод и подстановка состояния в модели не подтверждают
штатный путь вызова. [Отчёт](../Tools/Disasm/Reports/SecondaryEquipmentRowsVerification.json).
