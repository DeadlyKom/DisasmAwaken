# Максимум свёрнутых старших байтов

[MaxFoldedVectorHigh](../Source/Action/MaxFoldedVectorHigh.asm) занимает
исходные 699C..69BD перенесённого ACTION. Он читает старшие байты трёх
рабочих компонент по 9B71, 9B74 и 9B77. Каждый код сворачивается функцией
`f(b)=b`, если b<80, иначе `f(b)=b XOR FF`. В L возвращается максимум
трёх свёрнутых значений, диапазон результата 0..7F. H сохраняется.

Отрицательные коды преобразуются через CPL, без прибавления единицы.
Поэтому FF сворачивается в 0, 80 в 7F. Это не точное абсолютное значение
знакового байта и не вычисление модуля всей 24-битной компоненты. Нижние
шестнадцать разрядов здесь не читаются. Алгоритмический результат установлен,
глобальная игровая роль и физические единицы остаются отдельной задачей.

Сначала L получает f(High0), затем обновляется, если f(High1) не меньше L.
Последнее сравнение выполняется между f(High2) и максимумом первых двух.
При не меньшем третьем коде L обновляется ещё раз, флаги CP сохраняются.
Таким образом A=f(High2), а F относится к сравнению с предыдущим максимумом,
не обязательно с конечным L после его обновления.

DE, BC, альтернативные и индексные регистры сохраняются. I, IM, IFF и
страница не меняются. SP после RET равен входному SP+2, RAM и CPU-стек
не записываются.

Пусть ni равен 1 для установленного знака исходного Highi, иначе 0.
Число M1 равно `15+n0+n1+n2+[f(High1)>=f(High0)]`
`+[f(High2)>=max(f(High0),f(High1))]`. Квадратные скобки здесь обозначают
1 при истинном условии и 0 при ложном. Получаются значения 15..20,
бит 7 R сохраняется.

[Модель полного домена](../Tools/Disasm/Research/CheckActionVectorHighMaximum.py)
прошла все 16777216 сочетаний трёх входных байтов. Эталон отдельно вычисляет
математический максимум, финальные флаги CP и число M1. Сопоставлены все
регистры включая R. В каждом сценарии проверялось отсутствие записи RAM,
итоговые восемь банков совпали с входной фикстурой. Полнота перебора относится
к трём прочитанным байтам, а не к полному игровому состоянию. IRQ, точные T,
сборка и нативное исполнение не проверены.
