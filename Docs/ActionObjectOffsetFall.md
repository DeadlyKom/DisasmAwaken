# Уменьшение байта смещения объекта

EF9A вычитает 2 из байта 07 и уменьшает таймер 17 по модулю 256.
Если таймер стал нулём, состояние восстанавливается из байта 16.
Затем выполняется переход F0F8. Сверены все 65 536 пар смещения и
таймера, включая Carry вычитания и флаги уменьшения таймера.
