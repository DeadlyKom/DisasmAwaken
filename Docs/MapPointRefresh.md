# Регистр R в процедурах точек карты

[Проверка исходных инструкций](../Tools/Disasm/Research/CheckMapPointRefreshWitness.py),
[отчёт](../Tools/Disasm/Reports/MapPointRefreshWitnessVerification.json).
Это отдельные контрольные вызовы, дополняющие прежние числовые модели.

Проверены [BuildMapPointOutcodes](../Source/Map/BuildMapPointOutcodes.asm),
[BuildVisibleMapPoints](../Source/Map/BuildVisibleMapPoints.asm),
[SelectNearestVisiblePoint](../Source/Map/SelectNearestVisiblePoint.asm) и
[MeasureCoordinateDistance](../Source/Map/MeasureCoordinateDistance.asm).
У каждой есть исходный путь с изменённым конечным R, поэтому регистр входит
в Corrupt. Старший разряд R сохраняется. Совпадение конечного R на другом
пути не означает, что процедура сохраняет регистр для всех входов.

Сектора STATIONF и KARTA заново сопоставлены с полным оригинальным TRD и
его SHA256. Общие фиксированные окна подготовлены существующим загрузочным
контекстом, KARTA помещён в верхнее окно. Таблицы точек и сохранённых
вариантов являются явно заданными фикстурами. Все дочерние процедуры
исполняются настоящими инструкциями, вызовы не подменяются.

## Подсчёт выборок M1

Для каждой достигнутой команды подсчитываются M1, включая префиксы
CB, ED, DD и FD. После каждой команды R сверяется с отдельной формулой
обновления младших семи разрядов при сохранённом старшем разряде.
Повторные DD/FD, сочетание DD/FD с ED и LD R,A не допускаются этой
ограниченной проверкой, в контрольных путях они не встречаются.

Всего выполнено 26 вызовов с начальным R=00 либо 95. Таблица показывает
наблюдавшиеся M1 для заданных входов, это не универсальная стоимость процедур.

| Процедура | Контрольный путь | Заданные циклы HALT | M1 |
| --- | --- | --- | --- |
| BuildMapPointOutcodes | одна точка (0,0) | 0 | 54 |
| BuildMapPointOutcodes | одна точка (-1,256) | 0 | 46 |
| BuildVisibleMapPoints | пустой результат | 1 / 4 | 3111 / 3114 |
| BuildVisibleMapPoints | одна принятая точка | 1 / 4 | 3135 / 3138 |
| SelectNearestVisiblePoint | указатель вне области | 1 / 4 | 3122 / 3125 |
| SelectNearestVisiblePoint | одна точка, сохранённого варианта нет | 1 / 4 | 3328 / 3331 |
| MeasureCoordinateDistance | совпавшие координаты | 0 | 52 |
| MeasureCoordinateDistance | разность (3,4) | 0 | 337 |
| MeasureCoordinateDistance | переполнение квадрата при разности (256,0) | 0 | 202 |

У классификатора количество равно одному, исходные верхние пороги равны FF.
У фильтра начало (0,0), размеры 2×2. В четырёх секторных таблицах по 128
слов стоят (100,100), для принятой точки первое слово заменено на (1,1).
У выбора ближайшей точки пиксельное начало равно (16,16), указатель
равен (0,0) для отказа либо (17,17) для принятия. Сохранённый список
заканчивается отрицательным ограничителем 80. Для расстояния первое
начало равно (0,0), второе задано указанной разностью.

3328 равно 26×128. Поэтому на одном полном пути выбора ближайшей точки
конечный R совпадает с начальным, хотя было много выборок M1. Четыре
заданных HALT-цикла вместо одного меняют этот результат на три.

## HALT и пределы доказательства

Фильтр начинает с исходного HALT по C4E5. Проверка исполняет один либо
четыре HALT-цикла при выключенном IFF и неподвижном PC, проверяя R после
каждого. Затем явно снимает состояние HALT и продолжает с C4E6.
ISR и аппаратный источник пробуждения не исполняются и не имитируются
как доказанный игровой обработчик.

Восемь пар одного входа с задержками 1/4 HALT дали ровно три дополнительных
M1. Во всех этих парах прочие конечные регистры и все 65536 байтов
моделируемой памяти совпали побайтово. Конечный R и время исключены
из этого сравнения. Портовых записей в контрольных вызовах не было.

В реальном окружении число повторных HALT-выборок, обработчик и дальнейшие
прерывания могут добавить собственные изменения R и других состояний.
Поэтому единая точная стоимость фильтра или его вызывающей процедуры
без условия на пробуждение не заявляется. Проверка не охватывает все
координаты, количества, размеры, старые выборы, сохранённые списки,
значения альтернативного AF или аппаратные шинные циклы. Полные числовые
модели остаются отдельными доказательствами со своими границами.
Сборка и нативный запуск не выполнялись.
