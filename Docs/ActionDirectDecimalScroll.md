# Число с обязательной прокруткой

[PrintByteAndScrollBank1](../Source/Action/PrintByteAndScrollBank1.asm)
занимает 6010..6028, выводит байт через банк 1, обязательно прокручивает
окно и сохраняет исходную попытку записи нуля в ПЗУ.
[Полный алгоритм, контракты и границы проверки](ActionDirectDecimal.md).
