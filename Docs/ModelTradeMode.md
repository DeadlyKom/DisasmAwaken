# Продажа и покупка моделей

Две центрируемые кнопки имеют исходные подписи **Продажа**, запись 28, и **Покупка**, запись 29. Подписи читаются из CenterTextBase по E4AA, другая таблица CaptionTextBase по E399 даёт для тех же числовых индексов другие строки и не определяет эти кнопки.

[DrawSaleModeButton](../Source/Station/DrawSaleModeButton.asm), 7A55..7A63, и [DrawPurchaseModeButton](../Source/Station/DrawPurchaseModeButton.asm), 7A82..7A91, загружают свои изменяемые индексы и хвостовым JP вызывают [DrawCenteredItem](CenteredItem.md). Временный C9 отключает всю обёртку без чтения индекса. Само рисование не выбирает режим и не меняет модель.

[SelectSaleMode](../Source/Station/SelectSaleMode.asm), 7A24..7A54, и [SelectPurchaseMode](../Source/Station/SelectPurchaseMode.asm), 7A64..7A81, начинаются с RET C. При Carry=1 регистры, флаги, память и порты сохраняются. При Carry=0 оба выбирают банк 4, пишут ноль только в RowOperand по E146, возвращают банк 0 и устанавливают PendingRedraw=1. Это изменение существующего операнда LD A по E145 банка D3D, отдельного массива не создаётся. Немедленного 3D-кадра нет, ненулевой запрос обрабатывает последующий [периодический проход](ShipPreviewCallbacks.md).

Продажа проверяет полный Selector. При нуле читается CurrentModels.ShipIndex по 9849, при любом ненулевом байте SkimmerIndex по 984A. INC собственного типа проверяет FF. Любое не-FF здесь рассматривается как наличие собственного объекта, диапазон каталога не проверяется. При наличии OwnedMode=1, старый индекс берётся из DrawItemState.Index29, новый остаётся входным DE, штатно 28. При FF код переходит к общему ApplyMode покупки: старый индекс 28, новый 29.

Покупка устанавливает OwnedMode=0, читает старый индекс из DrawItemState.Index28 и сохраняет входной DE новой кнопки, штатно 29. **ApplyMode по 7A78** является отдельным внутренним входом. Он обходит RET C, выбор банков, сброс RowOperand и установку PendingRedraw. Сам хвост меняет только режим и вызывает переключение кнопок. Продажа использует его после собственного предварительного сброса.

OwnedMode — целый режим, не набор независимых флагов. Выходные записи этих действий имеют вид:

| Разряды 7..0 | Значение | Смысл |
| --- | --- | --- |
| 00000000 | 0 | Каталог покупки |
| 00000001 | 1 | Собственный объект продажи |

Читающие проходы списка и цены различают ноль и ненулевое значение, независимого назначения остальных семи битов этим не вводится. Полный разбор всех игровых потребителей остаётся самостоятельной задачей.

[SwitchItemContour](ItemContourSwitch.md) сбрасывает только бит 0 Flags старой кнопки, рисует её, устанавливает бит 0 новой и рисует новую. На выходе HL и DE равны новому индексу, BC сохранён, A=C3, F последнего текстового прохода, H', DE', BC', IX, IY, I, IM и IFF сохранены, L' и AF' рабочие. Указатель возобновлён, UpdateBlocked=0, SP обычного возврата равен входному+2. Общая область двух рамок не закрыта одним общим запретом указателя, действуют договоры каждого помощника.

SelectRamBank объединяет аргумент со старшими битами тени порта. При исходной странице 10 последовательность 14→10, при 18 последовательность 1C→18. Экранный бит сохраняется, окно RAM в конце выбрано в банк 0. Требуются загруженный D3D и отсутствие аппаратной блокировки переключения.

[CheckModelTradeMode](../Tools/Disasm/Research/CheckModelTradeMode.py) и [отчёт](../Tools/Disasm/Reports/ModelTradeModeVerification.json) проверяют 65536 ранних возвратов всех AF с Carry, все 65536 пар Selector/собственный тип и все слова нового индекса покупки до обращения к записи. Потенциально недопустимые индексы дальше не запускаются. Выполнены 192 настоящих переключения двух рамок и восемь общих входов ApplyMode, проверены все остальные байты банка 4, оба экранных бита, Flags, запрос и режим. Восемь сопоставлений кнопочных обёрток с реальным DrawCenteredItem и 512 временных RET сохраняют их прежний договор. Независимого oracle всего итогового bitmap контуров нет. Сборка, IRQ и нативный запуск не выполнялись.
