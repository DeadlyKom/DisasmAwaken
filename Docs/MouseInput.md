# Мышь, настройка кнопок и счётчики

Вход [PollMouse](../Source/Station/PollMouse.asm) по `#65A7` обслуживается из Interrupt после клавиатуры и джойстика. Он использует физическую [FMouseInput](../Source/Station/Data/MouseInput.asm) по `#6585`. Ненулевой изменяемый операнд Disabled запрещает опрос, в этом случае нет аппаратных чтений, очистки флагов и изменения координат. Меняется только AF от AND Disabled.

## Физические поля

| Смещение | Поле | Писатель и потребитель |
| --- | --- | --- |
| 0 | Action2 | кнопка, вклад с весом 2 в MergeActionInputs |
| 1 | Up | отрицательная экранная разность Y |
| 2 | Down | положительная экранная разность Y |
| 3 | Right | положительная разность X |
| 4 | Left | отрицательная разность X |
| 5 | Action1 | другая кнопка, вклад с весом 1 в MergeActionInputs |
| 6 | ExtraButton | третий разряд инвертированной выборки кнопок |
| 7 | PreviousX | последнее байтовое показание порта `#FBDF` |
| 8 | PreviousY | последнее байтовое показание порта `#FFDF` |

Первые семь полей являются отдельными байтами, а не разрядами одного байта. Полный опрос очищает их перед чтением, устанавливаемые значения равны 1. Ноль означает отсутствие соответствующего действия в текущей выборке. Счётчики являются числами по модулю 256, их нельзя описывать как флаговые маски. Названия Action2 и Action1 отражают доказанный вклад в [MergeActionInputs](InterfaceInput.md), а не утверждение о физической левой или правой кнопке устройства.

## Одноразовая настройка

Порт `#FADF` читается с последующим CPL. В инвертированном байте разряды 0, 1 и 2 задают три кнопки, ноль каждого разряда означает отсутствие нажатия. Верхние разряды не участвуют в декодировании кнопок. В исходном коде по `#65C7` находится JR в [ConfigureMouseButtons](../Source/Station/ConfigureMouseButtons.asm). Пока оба младших разряда нулевые, переход направляет выполнение сразу к чтению движения. Третья кнопка в этом начальном состоянии отдельно не декодируется.

Первый ненулевой двухбитовый код выбирает соответствие действий. Код 1 оставляет исходные смещения 0 и 5 двух RL `(IX+d)`. Коды 2 и 3 заменяют их на 5 и 0. Затем слово 0 записывается поверх JR, превращая его в два NOP. Сохранённый IX снимается, и PollMouse выполняется ещё раз, теперь уже с обычным декодированием. Первая выборка служит настройке, итоговые кнопки берутся из повторной выборки.

[DecodeMouseButtons](../Source/Station/DecodeMouseButtons.asm) последовательно переносит два младших разряда A через Carry в соответствующие обнулённые байты. [DecodeThirdButton](../Source/Station/DecodeThirdButton.asm) продолжает ту же последовательность для разряда 2 и поля ExtraButton. Изменяемые смещения находятся внутри исходных инструкций `DD CB displacement 16`. Новых областей памяти для настройки не выделяется.

## Перемещение

[ReadMouseMotion](../Source/Station/ReadMouseMotion.asm) сначала читает старые координаты и оба прежних счётчика. Далее читает X через `#FBDF`, сохраняет новое показание и вычисляет `dx=signed8(newX-oldX)`. Для Y используется `dy=signed8(-(newY-oldY))`, поскольку экранное направление противоположно направлению счётчика. Разность `-128` остаётся `-128` при байтовом NEG.

Ненулевая разность устанавливает байт направления даже при упоре в границу. Для каждой оси выполняется удвоение шага. При отрицательной разности результат равен `max(0,old+2*delta)`. При положительной равен `min(limit,old+2*delta)`, где limit=254 для X и 191 для Y. При нулевой разности координата остаётся прежней.

Эти ограничения односторонние. Отрицательная ветвь не исправляет превышение верхнего предела, нулевая не нормализует координату вообще. Поэтому формула общего clamp на обоих концах была бы неверной для произвольного входного байта. При штатных исходных координатах результат остаётся в допустимом диапазоне, за исключением сохранённого X=255 при отсутствии движения, если такой X уже был на входе.

После обоих чтений PointerXY обновляется. HL содержит итоговые X,Y, DE прежние аппаратные X,Y, BC=`#FFDF`. AF рабочий, его флаги не являются общим признаком движения. IX снимается из FMousePollFrame. IY и альтернативные регистры сохраняются. Внутренние входы декодирования и движения требуют уже подготовленного IX и сохранённого слова IX на стеке, обычный CALL без этого кадра недопустим.

## Связанный пустой обработчик

[NoPointerMotion](../Source/Station/NoPointerMotion.asm) по `#6762` состоит из RET. Таблица направлений по `#66EE` выбирает его для нулевого сочетания и ряда противоречивых сочетаний младших четырёх направлений при нулевых верхних разрядах входа. Регистры и память не меняются. Это реально используемый общий выход, а не доказанный свободный байт.

## Проверка

[CheckMouseInput](../Tools/Disasm/Research/CheckMouseInput.py) исполняет исходные инструкции с явно заданными байтами портов. [Отчёт](../Tools/Disasm/Reports/MouseInputVerification.json) содержит 133887 случаев, из них 131072 проверяют все 256 положений и все 256 знаковых разностей каждой оси. Дополнительно проверены все байты кнопок, оба соответствия двух действий, все младшие трёхбитовые сочетания начальной настройки, 1536 случаев завершения настройки и все 255 ненулевых программных запретов. Проверяются физические байты состояния, порядок чтений, самомодификация, координаты, регистры и стек.

Модель не подключает аппаратную мышь и не исполняет IRQ. Она подтверждает алгоритм преобразования заданных показаний, но не частоту поступления данных, нативный ввод или актуальную сборку проекта.
