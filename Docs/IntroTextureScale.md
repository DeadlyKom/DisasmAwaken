# Изменение масштаба текстуры

[AdvanceTextureScale](../Source/Intro/AdvanceTextureScale.asm), вход `6C21`,
обновляет три счётчика, физически расположенных в операндах `LD A,n`.
Они названы `IntroScaleState.WarmupLeft`, `.RampLevel` и `.CycleIndex`.
Адреса остались исходными `6C22`, `6C2E`, `6C3F`, новая RAM не выделяется.

WarmupLeft уменьшается до единицы и остаётся равным единице.
Разветвление использует уже обновлённое значение. Поэтому входное значение
два сразу включает циклическую фазу, а входное значение три даёт последний
шаг начального нарастания.

В начальной фазе RampLevel растёт до 63, индекс строки равен
39+floor(RampLevel/2). CycleIndex не меняется. При исходном WarmupLeft=A1
получается 159 вызовов начальной ветки.

В циклической фазе CycleIndex сначала увеличивается по модулю 40,
затем из `6C62..6C89` читается байт и к нему добавляется 56.
Исходная таблица содержит значения 0..15, индекс строки равен 56..71.
RampLevel не меняется. Исходный CycleIndex=0 сначала выбирает запись 1,
запись 0 выбирается после перехода 39 → 0.

Оба пути входят в [SelectTexturePointerRow](../Source/Intro/SelectTexturePointerRow.asm),
который записывает адрес `F000+16*A` в существующий операнд
`IntroScaleState.PointerRow` по `6BB2`. Его RET завершает весь вызов.
В конечном состоянии HL содержит адрес строки, DE=F000, A содержит индекс,
F=20. BC, альтернативные и индексные регистры сохранены.
CPU-стек только читается конечным RET.

[Проверка](../Tools/Disasm/Research/CheckIntroTextureScale.py) исполняет исходные
байты вместе с настоящим хвостовым селектором. Независимая числовая модель
задаёт формулы счётчиков, конечные регистры и все записи.
10 176 сценариев покрывают 159 значений начального счётчика и все 64 уровня,
ещё 80 покрывают оба перехода в цикл и все 40 индексов.
Неактивные счётчики варьируются выборочно.

[Отчёт](../Tools/Disasm/Reports/IntroTextureScaleVerification.json)
подтверждает регистры кроме R, все восемь физических банков RAM и кратность
записей. Доказанный профиль ограничен WarmupLeft=1..161, RampLevel=0..63,
CycleIndex=0..39 и исходной таблицей. Повреждённые состояния вне этих
пределов, время, аппаратные IRQ и нативное выполнение не проверялись.
