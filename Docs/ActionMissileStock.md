# Выбор остатка ракет 70ED

[SelectMissileStock](../Source/Action/SelectMissileStock.asm) возвращает байтовое
значение выбранного запаса и адрес этого счётчика. Физическая запись
[MissileStock](../Source/Action/Data/MissileStock.asm) занимает 9C12..9C13,
исходная запись 17 ACTION, файловые смещения 3C12..3C13.
FMissileStock содержит Fallback по смещению 0 и Preferred по смещению 1.
Обратный порядок отличается от [SelectPreferredByte](ActionPreferredByte.md).
Оба исходных байта сохранены, новые области памяти не выделяются.

## Выбор и договор

Если Preferred по 9C13 ненулевой, A получает его значение, HL=9C13.
Иначе HL уменьшается до 9C12, A получает Fallback.
DE, BC, альтернативные HL, DE, BC, AF, IX, IY, I, IM и IFF сохраняются.
SP увеличивается на два после RET. Записей RAM и CPU-стека нет.
R увеличивается на 4 M1 при выборе Preferred либо на 7 M1 при выборе Fallback,
с сохранением бита 7 и переполнением младших семи битов.

Флаги всегда относятся к AND Preferred. Carry и N сброшены, H установлен.
На запасном пути F=54 даже при ненулевом возвращённом A.
Поэтому вызывающий код по 70AF отдельно выполняет AND A для проверки наличия
ракет. Значения полей используются целиком, отдельных игровых флагов в них
этим кодом не проверяется. Разновидности двух запасов пока не установлены.

## Подтверждение назначения

В исходном обработчике по 706F находится CALL 70ED, сразу за ним JP 70C6.
Первая команда по 70C6 — DEC (HL), поэтому уменьшение относится к выбранному
этой процедурой счётчику. Последующее уменьшение байта по 9BD2 — отдельная
операция, её назначение здесь не подменяется смыслом возвращённого HL.

По 70DE вызывается тот же читатель, по 70E1 его A передаётся
[QueueNumberBank1](../Source/Action/QueueNumberBank1.asm), затем по 70E8
вызывается [QueueTextItemBank1](../Source/Action/QueueTextItemBank1.asm)
с DE=F277. Число добавляется между фрагментами «Осталось» по F26D и
«ракет» по F277. При отсутствии запаса используется сообщение по F280
«Ракеты исчерпаны». По F2E9 находится сообщение «Ракета ушла».

Все указанные тексты относятся к Controls банка 1 и декодируются как CP866.
По тем же числовым адресам банка ACTION расположены другие байты.
Текстовое свидетельство читается именно из исходных CONTROL0/CONTROL.
Алгоритмы вызывающих обработчиков и весь пуск ракеты этой проверкой
не объявляются завершёнными.

## Проверка

[Модель](../Tools/Disasm/Research/CheckActionMissileStock.py) проверила все
65536 пар Preferred/Fallback. 65280 случаев выбрали Preferred,
256 случаев выбрали Fallback. Проверены все регистры, F, R, SP,
каждый байт RAM и отсутствие записей. Тексты банка 1 независимо сверены
с исходными байтами. Сборка, IRQ и нативное исполнение не выполнялись.
