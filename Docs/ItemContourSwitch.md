# Последовательное переключение форм двух рамок

[SwitchItemContour](../Source/Station/SwitchItemContour.asm), A806..A82C, получает старый индекс в HL, новый в DE. Бит 0 Flags выбирает форму рамки в [DrawCenteredItem](../Source/Station/DrawCenteredItem.asm). Функция не меняет группу элемента и не устанавливает отдельный признак активности окна.

Новый индекс сначала помещается на стек. Затем старый индекс сохраняется в DE, [GetItemFlags](../Source/Station/GetItemFlags.asm) получает адрес поля старой записи. RES сбрасывает только бит 0. Индекс восстанавливается в HL, указатель приостанавливается, старый элемент целиком перерисовывается, указатель возобновляется.

После POP HL новый индекс находится в HL. Он также копируется в DE. Адрес Flags получается заново, SET устанавливает только бит 0 новой записи. Вторая пара SuspendPointer/ResumePointer окружает полную перерисовку нового элемента. Между двумя рисунками указатель уже разрешён. Все эти действия сохраняют исходный порядок, общий внешний запрет вместо двух пар не введён.

Равенство индексов не проверяется. В этом случае одна запись сначала рисуется со сброшенным битом, затем с установленным. Итоговый бит равен единице независимо от исходного состояния, остальные семь разрядов сохраняются. Функция не подменена единственной установкой бита и одним рисованием.

Физический динамический FItemContourFrame после первого PUSH состоит из SavedNewIndex по SP+0 и ReturnAddress по SP+2, оба поля по два байта. На время каждого CALL вложенные кадры располагаются ниже. После первого этапа POP удаляет SavedNewIndex, конечный RET использует исходный ReturnAddress. Дополнительной постоянной памяти не выделено.

При обычном завершении HL и DE равны новому индексу, BC сохранён. AF содержит A=C3 и флаги последнего текстового прохода второй рамки. Последний ResumePointer сохраняет этот основной AF. Альтернативный HL рабочий с сохранением H′, альтернативные DE и BC и оба индексных регистра сохраняются. AF′ рабочий. Рисователь меняет bitmap, текстовое окно, код режима строки и регистрацию владельцев по своему отдельному договору. UpdateBlocked в конце равен нулю.

[CheckItemContourSwitch.py](../Tools/Disasm/Research/CheckItemContourSwitch.py) проверил 1280 исходных вызовов, все 256 старых Flags и пять сочетаний индексов, в том числе 256 совпадающих пар. Непосредственно на входах настоящих DrawCenteredItem проверены порядок индексов, значения Flags, запрет указателя и расположение сохранённого нового индекса. На выходе проверены оба индекса, AF второго рисунка, сохранённые регистры, поля всех записей и стек. Вызовы не подменялись.

В этой интеграционной модели указатель исходно восстановлен и расположен вне рамок. Отдельного независимого oracle всего составного bitmap в ней нет. Пиксельные алгоритмы помощников проверены в [CenteredItem](CenteredItem.md) и [Pointer](Pointer.md). Аппаратные IRQ, произвольные callback указателя, сборка и нативный игровой запуск этим тестом не доказаны.
