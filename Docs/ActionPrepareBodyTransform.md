# Подготовка компонент тела к преобразованию

Вектор по 9B6F..9B77 содержит три 24-битные компоненты в дополнительном
коде. Его физическое начальное состояние равно 0, 0 и E08000.
Используется существующая структура FActionWorkVector24 с тремя вложенными
FActionWorkComponent24. [Физическая запись](../Source/Action/Data/TransformWorkVector24.asm).

Вход 6A6E копирует все девять байтов в Component0..2. Он переносит
их старшие слова в Input0..2 вычислителя AF43, сохраняет CPU-стек в
операнд 6AAE и обнуляет младший байт каждой компоненты проекции.
IY получает вход восстановления стека 6AAD. [Подготовитель](../Source/Action/PrepareBodyTransform.asm).

AF43 выполняет исходные знаковые умножения и сложения, используя SP
для промежуточной суммы. Возврат через IY восстанавливает SP. P/V и
частично записанные результаты сохраняются до начала 6AB0. Модель
проверила 8 846 проходов, включая все шесть точек переполнения, точные
регистры и R, физическую память и записи.
[Восстановление стека](ActionRestoreBodyStack.md).
[Отчёт](../Tools/Disasm/Reports/ActionPrepareBodyTransformVerification.json).

Продолжение 6AB0 использует восстановленный CPU-стек. RET PE завершает
обработку при переполнении. Иначе старшие знаковые байты результатов
AF43 записываются в First.X, First.Y и First.SignSource. После этого
слова преобразуются в знак и модуль. Для Y сначала выполняется
байтово точное отрицание 16-битного слова, включая оборачивание 8000.
[Публикация компонент](../Source/Action/PublishTransformedBody.asm).

При FirstMode=2 выбирается сплошная заливка 00FF, иначе 0000. Проекция
выполняется через банк CONTROL, затем возвращается банк ACTION. Для
6AB0 проверены 4 959 проходов проекции и 32 768 возвратов по P/V. В
глубокой ветви используются 20 временных байтов. Сверены регистры
кроме R, память вне внутренней рамки проекции, записи рисователя и OUT.
[Отчёт продолжения](../Tools/Disasm/Reports/ActionPublishBodyTransformVerification.json).
