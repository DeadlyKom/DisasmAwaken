# Статусная строка станции

[DrawItem00](../Source/Station/DrawItem00.asm) регистрирует и заливает свой элемент через RegisterAndFillItem, устанавливает Style=1. Это позволяет обычной печати переносить строки, если хватает высоты. Ширина текстового окна остаётся байтовой. Исходная ширина 32 знакоместа преобразуется в ноль, это ограничение SetupTextWindow сохранено.

RegisterAndFillItem возвращает HL у Flags записи. INC HL выбирает TextIndex. По нему от EA89 пропускается TextIndex+1 ограничителей LF и печатается первый фрагмент подписей. Возвращённое продолжение сохраняется на стеке, пока из отдельного списка EA3B выводится полицейский статус. Затем продолжение снимается, печатается подпись денег, денежное слово 984E с бюджетом нулей A=0, следующая подпись, используемый тоннаж 9850, двоеточие и вместимость 9851. Два тоннажа являются байтами, B принудительно обнуляется перед PrintMin2. Завершение передано хвостовому [PrintPlayerRank](PlayerRank.md).

Выбор полицейского статуса использует многобитовое поле, а не независимые флаги.

| Разряды 7..5 | Выбранная строка |
| --- | --- |
| 000 | Чистый |
| 001 | Подозреваемый |
| 010 | Розыскиваемый |
| 011..111 | Приговоренный |

Маска выбора подписи E0. Разряды 4..0 на этот выбор не влияют,
но входят в [полное числовое значение статуса](PlayerSavedFields.md).
Сценарий штрафа различает числа с одинаковой подписью, например
32 и 48. Это не независимые флаги и не неизвестный резерв.
Нулевое старшее поле означает первую строку. Коды 4..7 ограничиваются
индексом 3 до поиска текста.

Каждый PrintText сохраняет DE, BC, альтернативные и индексные пары по своему договору. RegisterAndFillItem меняет AF альтернативного набора. Последующие числовые помощники и PrintPlayerRank его сохраняют. Поэтому HL', DE', BC', IX и IY сохраняются всем рисователем, AF' определяется регистрацией элемента. Окончательные основные пары задаёт PrintPlayerRank. Отказ промежуточной печати не прерывает выполнение, возвращённые флаги не проверяются.

[Модель](../Tools/Disasm/Research/CheckStatusDraw.py) исполняет настоящую регистрацию, заливку и все печати для каждого из 256 статусных байтов с разными денежными словами, тоннажами и рангами. Отдельно проверены 256 отключённых входов RET. В полном текстовом сценарии используется ширина 31. Модель выдачи миссионной награды дополнительно проверяет ширины 31 и 32. Это статическая модель исполнения без IRQ, сборки и нативного запуска.


## Физические поля и полное значение статуса

Команды DrawItem00 используют существующие поля FPlayerSaveHeader.StatusCode, UsedTonnage и Capacity, расположенные в PlayerSaveHeader.Entry. Выбор подписи по StatusCode по-прежнему равен min(StatusCode SHR 5, 3). Младшие пять бит не участвуют только в выборе подписи, но не являются неизвестными флагами. Полный байт проверяет и уменьшает [станционный сценарий штрафа](StationScripts.md), его проверка охватывает все 256 значений.

Загрузки BC от UsedTonnage и Capacity остаются 16-битными, после каждой исходный LD B,0 отбрасывает соседний старший байт. Новые области и загрузки не добавлялись. Старое адресное имя Status984B остаётся совместимым псевдонимом, действующий рисователь ссылается на физическую структуру. [Раскладка полей](PlayerSavedFields.md), [модель рисователя](../Tools/Disasm/Research/CheckStatusDraw.py).
