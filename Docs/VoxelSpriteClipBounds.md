# Отсечение прямоугольника VOXAL

[ClipSprite](../Source/Voxel/ClipSprite.asm) принимает знаковые координаты
левого верхнего угла в `HL` и `DE`. В `B` находится высота, в `C` ширина.
Нулевой размер возвращает управление до записи координат в операнды.
После этого исходные координаты записываются в операнды `#EC9D` и `#ECD2`,
а исходные размеры сохраняются в `IYH` и `IYL`.

Проверяемый прямоугольник окна занимает полуоткрытые интервалы
`[0, 64)` по горизонтали и `[0, 24)` по вертикали. При непустом
пересечении на входе `#ED06` регистр `C` содержит видимую ширину,
`E` содержит видимую высоту. Изменяемый операнд `#ED7E` содержит число
срезанных единиц слева, `B'` число срезанных единиц сверху.
Биты 0 и 1 `C'` показывают соответственно левое и верхнее отсечение.
Правое и нижнее отсечение уменьшают видимые размеры.

[Модель](../Tools/Disasm/Research/CheckVoxelSpriteClipBounds.py) сравнила
фактическое выполнение оригинальных байтов страницы 3 с пересечением
прямоугольников в 51984 сценариях. Из них 10900 прошли до подготовки
шагов ресурса, а 41084 вернулись. Сверены регистры размеров и смещений,
положение стека и операнды сохранённых координат.
[Результаты](../Tools/Disasm/Reports/VoxelSpriteClipBoundsVerification.json)

Предыдущий этап [двух проекций](ActionVisualEffectWalk.md) проверен отдельно
до входа в эту процедуру.

## Буфер результата

Одна строка окна разворачивается в четыре строки линейного буфера с шагом
32 байта. Для координат окна `x`, `y` и подстроки `s` адрес равен
`#8000 + 128*y + 32*s + floor(x/2)`. Два четырёхбитных кода ресурса
образуют индекс таблицы. Левый код занимает старшие четыре бита, правый
младшие. Ноль прозрачен. Страницы таблиц по порядку подстрок
`#C3`, `#C0`, `#C2`, `#C1`.

Если оба кода ненулевые, байт результата берётся из таблицы целиком.
Если виден только один ненулевой код, старый байт сначала маскируется
по прозрачной половине, а затем объединяется с байтом таблицы через OR.
Таблица тоже участвует в значении прозрачной половины результата.

[Модель одноцветного ресурса](../Tools/Disasm/Research/CheckVoxelSpriteSolidRaster.py)
выполнила исходную процедуру до возврата в 3520 сценариях. Сверены все
3072 байта буфера и восстановление SP. Проверены все 16 одинаковых кодов
в обеих половинах байта, чётные и нечётные границы, обрезка и полностью
прозрачный ресурс. [Результаты](../Tools/Disasm/Reports/VoxelSpriteSolidRasterVerification.json)

## Выбор кодов ресурса

Исходная ширина находится в `L'`, высота в `H'`, адрес в `DE'`.
Строка ресурса занимает 16 байтов при ширине до 16 и 32 байта при большей
ширине. Шаг по каждой оси вычисляется [делителем F957](../Source/Voxel/Divide7BitFixed.asm)
по исходному размеру и размеру до отсечения. Начальное смещение ресурса
получается умножением шага на младшие семь битов числа срезанных единиц
и делением на 256 с округлением вниз. Дробная часть этого начального
смещения отбрасывается. От первой видимой единицы дробная часть
накапливается заново. Чётная координата берёт старшую половину выбранного
байта, нечётная младшую.

[Модель неоднородного ресурса](../Tools/Disasm/Research/CheckVoxelSpriteSampleRaster.py)
сверяет делитель во всех 65280 сочетаниях байтового числителя и ненулевого
делителя. При делителе выше 128 модель сохраняет исходный перенос при
удвоении остатка и восстановлении после заёма. Растр сверяется в 8114
сценариях с шестью размерами ресурсов, включая границу между шагами
строки 16 и 32. Сверены значения и порядок записей в код, кратность записей в буфер
и регистры видимого пути. [Результаты](../Tools/Disasm/Reports/VoxelSpriteSampleRasterVerification.json)


## Развёрнутая строка и состояние после возврата

[RasterizeSprite](../Source/Voxel/RasterizeSprite.asm) занимает
`#EE7A..#F930` и содержит 32 группы по 84 байта и общий хвост.
Группа считывает два кода. При двух нулевых кодах она продвигает
позицию без записи. При одном ненулевом коде сохраняет соответствующую
прозрачную половину назначения, а при двух ненулевых переписывает байт
целиком. Записываются четыре подстроки в порядке, заданном чётностью
номера группы. Последняя группа отдельно применяет маску правого края.

Пусть `g` равно 32 минус число байтов, затронутых видимой шириной
с учётом чётности левой границы. Адрес первого блока `P=#EE7A+84g`.
При нечётной левой границе операнд `P+4` временно получает нуль,
а первый вход становится `P+3`. На выходе маска по `P+4`
всегда получает `#F0`. Операнды `#F8B5` и `#F8DB` получают
нуль при нечётной исключённой правой границе, иначе `#0F`.
Чётность `g` выбирает форму операции с C по `#F905` и начальную
страницу по `#F907`. Шаг ресурса и сохранённый SP записываются
в операнды общего хвоста.

Для проверенных видимых входов со страницей ресурса по `#D800`
и без перехода через конец адресного пространства:

| Регистры | Значение при возврате |
| --- | --- |
| HL | `P+4` |
| DE, BC | D и B содержат старший и младший байты базы ресурса после последнего шага по Y. E содержит младший байт адреса последней правой выборки, даже если она замаскирована. C содержит дробную часть шага по Y. |
| AF | A содержит остаток от произведения видимой высоты на шаг по Y по модулю 256. F равен `#42`. |
| HL', DE' | H' равно `#C3` при нечётном `g`, иначе `#C0`. L' содержит индекс последней пары. D' равно `#0F`. E' содержит последнюю применённую маску прозрачности или младший байт начального адреса назначения при отсутствии частичных пар. |
| BC', AF' | B' и A' содержат старший и младший байты адреса следующей строки назначения. C' повторяет A', при чётном `g` дополнительно ставится бит 5. F' берётся от прибавления `#80` к младшему адресу, при переносе дополнительно меняется командой INC B. |
| IX, IY, SP | IXH равен нулю, IXL содержит младший байт целого шага по Y в байтах ресурса. IYH содержит высоту до отсечения, IYL равен A'. После RET SP равен входному SP+2. |

Модель проверила все 32 вычисляемых входа, включая временную замену
и восстановление маски, основные и альтернативные регистры видимого
пути и каждый адрес записи в буфер. Другие записи ограничены
перечисленными операндами и восемью байтами под входным SP.
Значения остаточных временных слов стека, точное изменение R,
IRQ и нативное выполнение отдельно не подтверждены.

### Ранние возвраты

Нулевая высота или ширина возвращает `AF=#0044`, остальные
регистры сохраняются, SP снимает только внешний возврат.
При ненулевых размерах IX и альтернативные HL, DE, AF сохраняются.
В IY записываются исходные размеры, E получает исходную высоту,
B и B' обнуляются. При отказе по X D сохраняет исходный старший
байт Y и C сохраняет исходную ширину. При отказе по Y D равен
нулю, C содержит видимую ширину после отсечения X, C' содержит
признак левого отсечения. При отказе по X C' равен нулю.

Для отрицательной отвергнутой координаты HL содержит сумму
исходной координаты и исходного размера по этой оси. A
содержит старший байт исходной координаты, F берётся от ADC HL.
Для неотрицательной координаты HL содержит её исходное значение.
Если старший байт ненулевой, A содержит этот байт, F берётся
от AND A. Иначе A содержит младший байт координаты, F берётся
от сравнения с 64 по X или 24 по Y. Модель сверила регистры
и флаги кроме R на всех 41084 отвергнутых входах из набора.

[Физические таблицы преобразования и кадры эффектов](VoxelPhysicalResources.md) оформлены строками структур с сохранением всех исходных байтов.
