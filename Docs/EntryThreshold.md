# Порог одной индексированной записи

[CheckEquipmentThreshold](../Source/Text/CheckEquipmentThreshold.asm) получает индекс через GetEquipIndex и использует базу порогов #95F0. [CheckSecondEntryThreshold](../Source/Text/CheckSecondEntryThreshold.asm) получает SumSecondaryIndex и базу #9632. Оба используют [ParseFieldSuffix](../Source/Text/ParseFieldSuffix.asm) с четырьмя свойствами c, v, s, k. Без точки проверяется байт по (база+2*индекс) AND FFFF. Явное число даёт (число-1) AND FFFF, без числа используется исходный байтовый индекс списка.

После чтения порога выполняется PUSH AF. [DescribeCurrentKeyForLang](../Source/Station/DescribeCurrentKeyForLang.asm) возвращает L характеристики текущего ключа, оно копируется в A. Затем POP HL восстанавливает сохранённый AF в HL, а не в AF. Поэтому H содержит порог, L флаги адресного сложения, прежний адрес записи потерян. Выполняется CP H. Если признак меньше порога, DE=A=0 и F остаётся от CP. Иначе INC A после LD A,0 даёт DE=A=1 и F=0. Z=0 при обоих результатах, при отказе Carry=1.

В прямом пути B=0, C сохраняет исходный индекс списка даже при явном числе. Альтернативный B установлен в 4, его C и альтернативные HL, DE сохраняются. Альтернативный AF изменён банковым запросом. IX у первого непрочитанного символа, IY, I и IFF сохраняются, SP увеличен на два. Рабочий ключ обновлён, выбран банк LANG 6. Общий CheckAtBase принимает полный HL индекс и DE базу порогов.

Суффикс c первого набора читает слово по #9592+2*младший_индекс, второго [Property070](../Source/Text/Property070.asm) по #95D4. Суффикс v первого читает байт по #95F1+2*младший_индекс, второго [Property071](../Source/Text/Property071.asm) по #9633. Эти входы используют общий алгоритм [MarketAccess](MarketAccess.md), хотя игровые роли дополнительных полей пока неизвестны. Суффиксы s и k используют соответствующие наборы [MembershipFlags](MembershipFlags.md), проверку отсутствия селектора и код старшего бита. При неизвестном суффиксе FindToken передаёт управление SkipLine, обычного результата нет.

[CheckEntryThreshold.py](../Tools/Disasm/Research/CheckEntryThreshold.py) исполняет оба исходных прямых входа, разбор чисел, запрос ключа и реальные переключения страниц в 848 случаях. Охвачены все байты порога, равенство, отказ, разные варианты ключа и переполнение индекса. Проверяются результат, полные F и сохранённый в HL AF, BC, IX, SP и страницы. Отчёт [EntryThresholdVerification](../Tools/Disasm/Reports/EntryThresholdVerification.json). Составные пути с суффиксами в этой модели не исполняются, их ядра проверены отдельно. Сборка, IRQ и нативный игровой запуск не выполнялись.
