# Продолжение обработки эффекта после преобразования координат

[ResumeVisualEffect](../Source/Action/ResumeVisualEffect.asm) занимает
исходные 90 байтов от `#6DD1` по `#6E2A`. Вход восстанавливает настоящий
стек. При переполнении, отрицательной или нулевой глубине управление
переходит к следующей записи без выбора страницы 3.

Путь отрисовки вычитает половины размеров ресурса из проецируемых
координат, выбирает страницу 3, сохраняет `IX` и вызывает `#FA3A`.
На возврате `IX` восстанавливается, выбирается страница 0 и управление
передаётся в обходчик по `#6D4C`.

Сквозная модель подтверждает порядок переключений, восстановление стека
и итоговый буфер. Полный контракт побочных записей и регистров
остаётся открытым. [Алгоритм, формулы и проверки](ActionVisualEffectWalk.md)
