# Продолжение обработки эффекта после преобразования координат

[ResumeVisualEffect](../Source/Action/ResumeVisualEffect.asm) занимает
исходные 90 байтов от `#6DD1` по `#6E2A`. Вход восстанавливает настоящий
стек. При переполнении, отрицательной или нулевой глубине управление
переходит к следующей записи без выбора страницы 3.

Путь отрисовки вычитает половины размеров ресурса из проецируемых
координат, выбирает страницу 3, сохраняет `IX` и вызывает `#FA3A`.
На возврате `IX` восстанавливается, выбирается страница 0 и управление
передаётся в обходчик по `#6D4C`.

Во всех выходах SP равен сохранённому слову по `#6DD2`,
управление передаётся по `#6D4C`, внешний возврат остаётся на стеке.
При входном P/V=1 остальные регистры сохраняются, R получает 2 M1.
При отрицательной глубине BC получает Output2, A сохраняется,
F задаётся `BIT 7,B` с исходным Carry, R получает 7 M1.
При нулевой глубине BC=0, AF=`#0044`, R получает 10 M1.
Два последних пути сохраняют HL, DE, альтернативные и индексные пары.
Ранние выходы не пишут память и порты.

На пути рисования HL=X−floor(FrameWidth/2),
DE=Y−floor(FrameHeight/2), BC=Output2. A содержит Mode, а F
равен флагам OR двух байтов глубины. HL′ содержит исходную
пару размеров, DE′ указатель ресурса, BC′ сохраняет входное значение.
На стеке перед `#FA3A` лежат `#6E21` и сохранённый IX.
По возврате восстановлен IX, A получает `#10`, выбран банк 0.
Остальные регистры сохраняют результат дочернего вызова, кроме R,
SP и PC. Последний селектор страниц записывает под SavedSP
слово BC дочернего выхода и адрес `#6E28`.

Модель проверяет 1152 ранних выхода по всем регистрам, R,
записям памяти и портов. Ещё 168 случаев исполняют настоящий
DrawProjectedEffect, сверяют его вход, сохранение результатов и
все четыре записи завершающего кода. Ресурсы имеют исходные
размеры 12×12 и 20×20. Точное время, R рисующей ветви и
прерывания внутри временных стеков остаются за границей проверки.
