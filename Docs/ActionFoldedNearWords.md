# Проверка близости трёх верхних слов

[CheckThreeUpperWordsNear](../Source/Action/CheckThreeUpperWordsNear.asm)
занимает 6A29..6A6D перенесённого ACTION. Читаются слова little-endian
по IY+2, IY+6, IY+10. Два предшествующих младших байта каждой компоненты
не читаются. Назначение всех байтов списка и физические единицы этим
локальным предикатом не доказываются.

Для каждого слова x вычисляется f(x)=x при x<8000, иначе x XOR FFFF.
Сначала проверяется ненулевой старший байт f, затем младший сравнивается
с десятичным 60. Первый отказ немедленно возвращает Carry=0, следующие
слова не читаются. Если все три f<60, возвращается Carry=1. Для signed16
это в точности диапазон от −60 до 59 включительно для каждого слова.

Это не вычисление обычного модуля отрицательного числа. Для отрицательных
x инверсия даёт −x−1. Поэтому FFC4, то есть −60, проходит, FFC3, то есть
−61, не проходит. 003B проходит, 003C не проходит. FFFF сворачивается
в ноль. 8000 сворачивается в 7FFF и отвергается по старшему байту.

При возврате HL содержит последнее проверенное свёрнутое слово. Если его
старший байт ненулевой, A=H и F получен OR A. Иначе A=L и F получен CP 60.
Таким образом, Z не является признаком успеха, успешное последнее слово
всегда меньше 60 и даёт Z=0. DE, BC, альтернативные регистры и IX/IY
сохранены. Страница, I, IM и IFF не меняются. SP увеличивается на два
байта внешнего возврата. Записей в RAM, включая CPU-стек, нет.

На каждое прочитанное слово приходится 10 M1 до включённого RET NZ.
Инверсия отрицательного слова добавляет 6 M1. Если H=0, чтение L,
сравнение и соответствующий RET добавляют 3 M1. Для всех предыдущих
пройденных слов учитывается та же полная сумма. R обновляет только
младшие семь битов, его бит 7 сохраняется. Для трёх отрицательных
подходящих слов полный путь составляет 57 M1. Точные T не измерялись.

[Независимая модель](../Tools/Disasm/Research/CheckActionFoldedNearWords.py)
сопоставлена с исполнением оригинальных байтов в 401920 сценариях.
Перебраны все 65536 значений слова в каждой позиции, все входные AF
для отказа по H, отказа по L и успеха, добавлены 8192 смешанных тройки
и 512 комбинаций восьми граничных значений.
Проверены регистры включая R, отсутствие записей и итог восьми банков
RAM. Полное произведение трёх слов не перебиралось. IRQ, сборка и
нативный игровой запуск не выполнялись.
