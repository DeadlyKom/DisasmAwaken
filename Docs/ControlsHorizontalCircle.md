# Круг с одним горизонтальным отсечением

Входы D3DA и D3E4 используют общую последовательность D3E7..D403.
Файл выделен по исходным передачам управления D3D9 и D401.
[Исходник](../Source/Controls/DrawHorizontallyClippedCircle.asm).

| Вход | Начальное состояние | Порог в A′ |
| --- | --- | --- |
| D3DA | WorkX уже уменьшен на 120, при входе прибавляются те же 120 по модулю байта | 0 |
| D3E4 | WorkX содержит исходное горизонтальное смещение | `(WorkX−119)&FF` |

XPlus выбирает правое отсечение. Тогда правый край фиксирован по X=248,
левый криволинейный край начинается с `(128+WorkX−Radius)&FF`.
При сброшенном XPlus левый фиксированный край допускает пиксели с X=8,
правый криволинейный край начинается с `(128+Radius−WorkX)&FF`.
Маски исключают пиксель самого криволинейного края. На каждой стороне
сначала вызывается подготовитель масок и рисуется нижняя половина.

После возврата тот же подготовитель повторно выставляет адреса и маски
для строки центра. Он сохраняет A′ и текущий рисунок IXL. Верхняя половина
входит через JP и использует исходный внешний возврат. Центральная строка
обрабатывается обеими половинами с текущей фазой каждой из них.
При совпадении C′ с A′ соответствующая фаза может продолжиться в обычном
ядре. [Внутренние фазы растра](ControlsCircleKernels.md).

Самый глубокий CPU-стек нижней половины занимает восемь байтов под внешним
возвратом. В эти байты входят её собственный возврат, SavedAF и два
временных слова. Верхняя половина использует внешний возврат напрямую.
Выходные пары регистров могут остаться переставленными при раннем выходе
с активным EXX. Ветвь не приводит их к единому порядку.

Проверка исполнила оба оригинальных входа, настоящие подготовители и обе
половины. В 50 808 сценариях смоделированы 4 590 839 строк и 5 187 переходов
к обычному ядру. Проверены все пары Radius и WorkX в пределах допуска
обоих входов с выбранными строками и сторонами, плюс смешанные сценарии.
Сверены регистры кроме R, содержимое восьми банков и кратность непиксельных
записей. Прочие ветви D340 проверяются отдельно.
