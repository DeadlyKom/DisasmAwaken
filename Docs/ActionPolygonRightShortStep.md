# Короткий отрицательный шаг правого ребра ACTION

[SetShortNegativeRightStep](../Source/Action/SetShortNegativeRightStep.asm) занимает D4F5..D502. Этот хвост физически расположен после [общего выбора предела](ActionPolygonRowSelection.md), к которому возвращается через JP. Он является частью [заливки](ActionPolygonFill.md), обычного RET не имеет.

Входной A сохраняется в RightSubtract по D21F. Для штатного короткого отрицательного наклона A равен abs(dx), меньшему высоты ребра. Альтернативный DE получает 2000, то есть строковый шаг с нулевой целой горизонтальной частью. Из временного стека снимается HL со страницей масок и текущей строкой, затем D восстанавливается из L. Основные BC, E и AF сохраняются, SP увеличивается на два. Остальные альтернативные и индексные регистры сохраняются.

[Локальная проверка](../Tools/Disasm/Research/CheckActionPolygonRightShortStep.py) прошла [65536 комбинаций A/F](../Tools/Disasm/Reports/ActionPolygonRightShortStepVerification.json). Сверены регистры кроме R и весь журнал записей, единственная запись идёт в RightSubtract. Произвольный A в этой локальной серии не доказывает его игровую допустимость. R/T, IRQ, сборка и нативный запуск не проверены.
