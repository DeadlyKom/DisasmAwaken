# Защёлки управления и фазовое затухание

[LatchControlsAndDecay](../Source/Action/LatchControlsAndDecay.asm)
занимает 6F55..7016 перенесённого ACTION в физическом банке 5.
Все защёлки и фазы являются исходными изменяемыми операндами. Новая
память не выделяется. Значения XControl, YControl, TurnControl уже
используются [движением точек](ControlsPointMotion.md), их единицы здесь
не переопределяются.

Request по 6F56 является текущим общим запросом, SkipDetail по 6F59
хранит предыдущее значение. Предыдущее значение сначала читается в C,
затем SkipDetail получает Request. Только сочетание Request=0 и прежнего
SkipDetail не ноль вызывает настоящий
[ReleaseClass14Records](../Source/Action/ReleaseClass14Records.asm).
Это падающий фронт, ненулевое значение не трактуется как отдельный бит.
Затем LimitWord по 7693 и SignedWord по A78F получают 0088, SixthRequest
по 669F получает единицу. Request очищается независимо от фронта.

| Канал | Старая защёлка | Новая защёлка | Фаза | Значение | Сбрасываемые операнды |
| --- | --- | --- | --- | --- | --- |
| X | XPrev, 6F7B | XNext, 6F7E | XPhase, 6F8D | XControl, 9B96 | 7736 и 7713 получают C8 |
| Y | YPrev, 6FB0 | YNext, 6FB3 | YPhase, 6FC2 | YControl, 9B95 | 7759 и 777C получают C8 |
| Turn | TurnPrev, 6FE5 | TurnNext, 6FE8 | TurnPhase, 6FF6 | TurnControl, 9B97 | 76CD и 76F0 получают FA |

Для каждого канала сначала проверяется старый Prev, затем Next копируется
в Prev без изменения проверенных флагов. При старом Prev не ноль канал
полностью пропускается. Следовательно, новый запрет начинает влиять только
в следующем вызове. Процедура сама Next не очищает.

При разрешённом канале сначала сбрасываются два байтовых операнда
клавиатурных обработчиков. Затем Phase циклически вращается вправо через
RRCA и сохраняется. Затухание разрешено только при прежнем бите 0 равном
единице. Разряды 7..0 фазы являются восемью последовательными разрешениями,
а не независимыми игровыми флагами. Нулевая фаза никогда не допускает
затухание. FF допускает его каждый раз. Начальный 92 даёт цикл
92, 49, A4, 52, 29, 94, 4A, 25, затем снова 92. При непрерывно нулевом
Prev затухание выполняется в трёх из восьми вызовов. При запрете фаза
не вращается, календарной периодичности в игровых кадрах это не доказывает.

Ненулевой signed8 сдвигается на единицу к нулю. Положительные уменьшаются,
отрицательные увеличиваются. FF переходит в 00 через отдельный XOR,
128 переходит в 129 без особого насыщения. Уже нулевое значение не
записывается повторно. Все операции и переходы оригинала сохранены.

При падающем фронте HL=0088, D=14, BC=0040 и IY указывает маркер списка.
Без него HL, DE, B, IY сохраняются, C равен прежнему SkipDetail. E всегда
сохраняется. Альтернативные регистры, IX, I, IM, IFF и страница сохранены.
AF полностью определяется каналом Turn. При старом TurnPrev не ноль
A=TurnNext, F соответствует OR старого TurnPrev. При пропуске по фазе
A=вращённая фаза, F=44 OR (A AND 28). При нулевом TurnControl A=0, F=54
после AND A. При положительном затухании F соответствует SUB 1, при
отрицательном от 80 до FE — ADD 1, при FF возвращаются A=0, F=44.

Максимальная дополнительная глубина CPU-стека равна шести байтам,
FControlDecayFrame описывает три вложенных возврата при освобождении.
SP после внешнего RET равен входному SP+2. Для настоящего поиска нужен
ACTION банка 0 в верхнем окне, восемь проверенных значений 7FFD равны
00, 08, 10, 18, 20, 28, 30, 38. Сама процедура не выполняет OUT.

Для R числовая модель считает M1 отдельно от исполнения инструкций.
Начальная проверка и перенос Request занимают 5 M1, при Request=0 ещё
2 M1. Падающий фронт добавляет TRelease+7, обнуление Request добавляет
2 M1. Каждый канал добавляет 5 M1, разрешённый ещё 7 M1 на сброс и фазу,
нечётная фаза ещё 3 M1 на проверку значения. Ненулевое значение добавляет
4 M1, либо 6 при FF, для последнего канала добавляется один M1 внешнего
RET после записи. Во всех ранних выходах RET уже включён в указанную
условную проверку. R сохраняет бит 7, точные T не устанавливаются.

[Независимая модель](../Tools/Disasm/Research/ReferenceActionControlDecay.py)
и [проверка оригинальных байтов](../Tools/Disasm/Research/CheckActionControlDecay.py)
прошли 462929 сценариев. Перебраны все пары общих запросов, все пары
фаз и signed8 каждого канала, все пары Prev/Next каждого канала, позиции
записей класса 14 в трёх состояниях и 4096 смешанных случаев. Выполняются
настоящие освобождение, поиск, итератор и пометка. Сопоставлены регистры
включая R, записи и остаток стека, все восемь банков RAM. Полное
произведение входов, IRQ, аппаратные шинные циклы, сборка и нативный запуск
не проверялись. Шесть клавиатурных потребителей сброшенных байтов
накопителей теперь разобраны в [ActionControlKeys](ActionControlKeys.md).
Потребитель LimitWord по 7693 разобран в [ActionGaugeWordKeys](ActionGaugeWordKeys.md).
