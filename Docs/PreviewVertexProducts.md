# Поставщики произведений группы

Исходные входы #D8BE и #D85E банка 4 пока сохраняются в [BeforeVertexGroup.bin](../Source/Resources/06_D3D/BeforeVertexGroup.bin). Их числовая композиция с [генератором группы](PreviewVertexGroup.md) уже проверена, выделение в самостоятельные ассемблерные модули ещё не выполнено.

Общий вход #D8BE принимает три байтовых параметра группы в B,C,D. Девять коэффициентов берутся из операндов, которые заполняет [композиция матриц](PreviewMatrixCompose.md). Каждая строка вычисляет три исходных табличных произведения. Физический порядок столбцов в потребителе равен 1,3,2. Полученные первые две строки упаковываются по парам, третья записывается тремя отдельными байтами.

| Параметр группы | Packed, младший байт | Packed, старший байт | Третья компонента |
| --- | --- | --- | --- |
| B | P(Coeff21,B) | P(Coeff11,B) | P(Coeff31,B) |
| C | P(Coeff23,C) | P(Coeff13,C) | P(Coeff33,C) |
| D | P(Coeff22,D) | P(Coeff12,D) | P(Coeff32,D) |

Упрощённый вход #D85E использует четыре изменяемых байта по #D861,#D869,#D871,#D87B. Для них в модели используются имена c1,s1,s2,c2. Внешний код #D819 заполняет две пары равными косинусами и синусами относительного второго угла. Наличие реального вызывающего пути к #D819 в уже проверенных кадрах ещё не установлено.

| Параметр | Packed, младший байт | Packed, старший байт | Третья компонента |
| --- | --- | --- | --- |
| B | 0 | P(c1,B) | P(−s2,B) |
| C | C без преобразования | 0 | 0 |
| D | 0 | P(s1,D) | P(c2,D) |

Оба входа записывают одни и те же девять байтов по #D910,#D911,#D913,#D914,#D916,#D917,#D953,#D955,#D956 и завершаются JP #D908. Исходный CPU-возврат принимает генератор группы, после восстановления CPU-SP он выполняет RET. Табличные CALL производителей временно используют два байта под CPU-SP.

[CheckPreviewVertexProducts.py](../Tools/Disasm/Research/CheckPreviewVertexProducts.py) исполняет каждый настоящий производитель, табличные помощники, генератор и перспективу. Независимая [модель произведений](../Tools/Disasm/Research/PreviewVertexProductsOracle.py) задаёт девять байтов входа независимой модели группы.

Проверены 5120 случаев, по 2560 на каждый вход, с 17003 вершинами. Включены все байты общих коэффициентов в выборке, все 256 углов исходной синусоиды, особые маски, произвольные четыре коэффициента короткого входа и случайные параметры перспективы. Сверены девять записей произведений, рабочий буфер, все регистры, фактический CPU-возврат и точные границы записей.

[Отчёт](../Tools/Disasm/Reports/PreviewVertexProductsVerification.json) не подтверждает физический обход всех групп #D896/#D819, грани, растеризацию, IRQ, сборку или нативную игру. Следующий отдельный разбор должен связать эти входы с заголовками и физическими четырёхбайтовыми записями моделей.
