# Остаток ветви движения и поля архивного контекста

## Байт перед банковой обёрткой

В авторском `awk5.trd` файл `SP.C` переносит ядро из `#623D`
по `#6000`. Модель исполняет исходный `LDIR` по `#420A`.
В перенесённом ядре по `#6947` читается `#9BC3` и сравнивается с E.
При равенстве `RET Z` по `#694B` снимает внешний возврат. Иначе
`LD A,E` по `#694C` и следующая запись меняют `#9BC3`, после чего
выполнение доходит до выбора банка 1 по `#6950`.

В Awakenv02 соответствующее сравнение читает `#9BC5`, и по `#697C`
стоит безусловный `RET`. Тот же байт `#7B` по `#697D` остался между
возвратом и обёрткой `#697E`, а запись после него удалена из этой цепочки.
В 65 536 парах прежнего байта и E архивная ветвь возвращалась только
при равенстве. Текущая ветвь возвращалась в каждой паре, сохраняя
значение `#9BC5`. Исходный байт `#7B` сохранён в слоте 17 по смещению
`#0BBA`. Штатный отдельный вход по `#697D` остаётся неизвестным.

## Пара SPEED и слово DALNO

В авторском `DATA_M.a` непосредственно после NEWS и четырёх ORDER
стоят два байта SPEED для скорости корабля и скимера, затем слово
DALNO для дальности выбранной звезды. В машинном `SP.C` все 75 байтов
от начала NEWS до конца DALNO побайтово совпадают с дисковым ACTION.
Смещения в ACTION увеличены на четыре. После этих полей начинается
группа точек карты.

| Исходный байт | `SP.C` | `ACTION` | Роль в архивной раскладке |
| --- | --- | --- | --- |
| `#64` | `#9C84` | `#9C88` | Первый байт SPEED |
| `#64` | `#9C85` | `#9C89` | Второй байт SPEED |
| `#00` | `#9C86` | `#9C8A` | Младший байт DALNO |
| `#00` | `#9C87` | `#9C8B` | Старший байт DALNO |

В архивном гиперпрыжке `LD HL,(#9C86)` по `#703B` читает всё слово.
`RET NZ` по `#7040` возвращает управление при ненулевом H, ещё до
сравнения топлива с L. Подтверждены все 256 значений старшего байта
с четырьмя значениями младшего.

В текущем обработчике Preferred читает только байт `#9C8A` по
`#7108`, Fallback читает тот же байт по `#7127`. В 1536 прогонах
обе ветви проверены при допуске, равном ключе назначения и нехватке
запаса. Каждый соседний байт `#9C89` и `#9C8B` перебран по всему
диапазону. В каждом профиле совпали регистры, порядок записей и
содержимое всех восьми банков, кроме двух подставленных байтов.
Граница проверки при допуске — вход сообщения `#7176`.
[Модель](../Tools/Disasm/Research/CheckHyperJumpAdjacentState.py)
· [Сравнение](../Tools/Disasm/Reports/HyperJumpAdjacentStateVerification.json)

Станционный счётчик при переносе занимает `#9C88`. Для `#9C89` и
`#9C8B` подтверждены архивное происхождение и перенос. Штатные
игровые потребители этих двух байтов в текущей версии остаются
неизвестными.
