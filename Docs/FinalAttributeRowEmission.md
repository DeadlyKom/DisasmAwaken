# Выдача шаблона ряда атрибутов

[EmitAttributeRow](../Source/Final/EmitAttributeRow.asm) копирует 23 байта
из `#627D..#6293` по входному DE. Затем прибавляет `#20` к слову
AttrStack по `#6282`. Сложение оборачивается по модулю 65536.
Копия содержит прежний операнд, а исходный шаблон уже подготовлен
для следующего ряда.

В штатном построителе операнд начинает с `#5820`. Для 24 рядов
копируются окончания от `#5820` до `#5B00`, каждый экземпляр
содержит 16 PUSH HL и записывает 32 атрибута. После последнего
копирования исходный операнд становится `#5B20`, но ещё один
экземпляр не создаётся. Длина самого шаблона равна 23 байтам,
число атрибутов и число байтов команд различаются.

На выходе HL равен новому операнду, DE увеличен на 23, BC=`#0020`.
A сохраняется. Последний LDIR сохраняет исходные S и Z, сбрасывает
P/V после обнуления счётчика. ADD HL,BC сохраняет эти три флага,
сбрасывает N, задаёт H и C по переносам, а биты 5/3 по старшему байту
результата. Альтернативные и индексные регистры сохраняются.
Стек читается только инструкцией RET, собственных PUSH и CALL нет.

Для указанного адреса шаблона и длины `#0017` процедура занимает
561 T и 53 M1 без ожиданий памяти и прерываний. Это 22 повторения
LDIR по 21 T и последнее по 16 T, остальные инструкции занимают
83 T. R изменяется по модулю 128 с сохранением бита 7.

[Модель](../Tools/Disasm/Research/CheckFinalEmitAttributeRow.py) проверяет
все 65536 исходных слов AttrStack и все 256 значений F для каждого
из 24 штатных рядов, всего 71680 сценариев. Проверяются все
регистры, R/T, копирование до обновления операнда и ровно 25 записей
в память. Приёмник в тесте расположен по `#9000`, адрес возврата
и контрольное слово под стеком сохраняются.
[Отчёт](../Tools/Disasm/Reports/FinalEmitAttributeRowVerification.json).

Модель не исполняет полученный шаблон. Изменение адреса источника,
длины, перекрытия и прерывания этой проверкой не подтверждены.
Генерация всей цепочки и её исполнение описаны в [разборе финала](Final.md).
