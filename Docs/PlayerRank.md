# Выбор и печать ранга

[PrintPlayerRank](../Source/Station/PrintPlayerRank.asm) находится по самостоятельному входу AC74. Его вызывает хвостом DrawItem00. Предшествующий генератор AC14 заканчивается RET и отдельным повторным JP AC14, поэтому он не является началом этой печатающей процедуры. Фрагменты разделены по исходным входам, адреса и инструкции не менялись.

Сначала PrintText выводит подпись из RankCaption.Entry. Затем читается беззнаковый счётчик RankState.Score по 984C. Шесть записей проверяются в порядке убывания. Сначала сравниваются старшие байты, младшие проверяются только при равенстве старших. При равенстве всего слова найденный порог считается достигнутым. C хранит число пропущенных записей, B число оставшихся с учётом найденной. Если ни один порог не достигнут, C=6 и B=0.

| Счётчик | Выбранная исходная строка |
| --- | --- |
| 10000..65535 | БОГ ВОИН |
| 3000..9999 | 1ЫЙ ВОИН |
| 1000..2999 | 2ОЙ ВОИН |
| 300..999 | 3ИЙ ВОИН |
| 100..299 | ОХОТНИК |
| 30..99 | ЕБУТ ТЕБЯ |
| 0..29 | СОСУНОК |

Тексты приведены по исходным CP866-байтам, включая написание и лексику оригинала. [PlayerRanks.asm](../Source/Station/Data/PlayerRanks.asm) содержит все семь LF-строк, шесть физических FRankThreshold и подпись. Общая длина 82 байта, диапазон ACE3..AD34. FRankThreshold размером два байта имеет HighByte по смещению 0 и LowByte по смещению 1. Пороги хранятся старшим байтом вперёд, DW Z80 изменил бы их порядок. Все инициализаторы связаны с конкретными значениями порогов.

Последний вывод имени выполняется через JP PrintText и использует исходный адрес возврата. DE содержит прочитанный счётчик, BC содержит остаток и номер уровня. HL и AF соответствуют завершению выбранного PrintText. При достижении LF AF=0A4A, HL сразу после него. Альтернативные и индексные регистры сохраняются. Курсор и bitmap изменяются обеими печатями. Отказ первой печати не отменяет поиска уровня, возвращённые ею флаги не проверяются. Полный смысл писателей рангового счётчика, в частности игровые причины его роста, здесь ещё не установлен.

[CheckPlayerRank.py](../Tools/Disasm/Research/CheckPlayerRank.py) проверяет все 65536 значений слова до окончательного входа в PrintText. Для 20 граничных значений исполняются также настоящие подпись и имя, без заглушек печати. Проверены выбор строки, регистры, альтернативный контекст и стек. [Отчёт](../Tools/Disasm/Reports/PlayerRankVerification.json). [VerifySources](../Tools/Disasm/VerifySources.py) отдельно восстанавливает все 82 байта из фактических DB и шести STRUCT-инициализаторов. Сборка, ISR и нативный запуск не выполнялись.
