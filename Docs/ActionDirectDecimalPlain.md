# Прямой десятичный вывод байта

[PrintByteBank1](../Source/Action/PrintByteBank1.asm) занимает 6029..603F,
выводит байт через банк 1 и сохраняет исходную попытку увеличить байт
ПЗУ. Прокрутка перед цифрами остаётся свойством дочернего рисователя.
[Полный алгоритм, контракты и границы проверки](ActionDirectDecimal.md).
