# Вращение трёх векторов в VOXAL0

[RotateBasisVectors](../Source/Voxel/RotateBasisVectors.asm) работает с
девятью словами по 9B00..9B11. Последовательно обрабатываются углы
Phase2, Phase0, Phase1. Нулевой угол пропускает арифметику этого этапа,
но сохраняет соответствующие промежуточные слова.

Для ненулевого угла a коэффициент c читается по индексу a. Коэффициент s
читается по (a − 64) AND FF. Страницы
[EA00](../Source/Voxel/Data/CosineLow.asm) и
[EB00](../Source/Voxel/Data/CosineHigh.asm) дают младшие и старшие байты
одного слова. Все 256 исходных слов совпадают с round(16384 × cos(2πa/256)).
Величина s соответствует синусу того же угла. Таблица хранится буквальными
байтами. EA00 банка 3 отличается от EA00 банка ACTION.

Если P(x,k) обозначает вызов SignedSeededProduct, а S обозначает исходное
сложение результатов, для каждого из трёх векторов выполняется:

| Угол | Первое обновление | Второе обновление |
|---|---|---|
| Phase2 | X = S(P(X,c), P(Y,s)) | Y = S(P(X,−s), P(Y,c)) |
| Phase0 | Y = S(P(Y,c), P(Z,s)) | Z = S(P(Y,−s), P(Z,c)) |
| Phase1 | X = S(P(X,c), P(Z,−s)) | Z = S(P(X,s), P(Z,c)) |

В пределах одной строки таблицы обе формулы читают компоненты,
сохранённые до начала этого этапа. Произведения идут слева направо,
IY переносится между всеми вызовами, в том числе между векторами и
этапами. Для каждого P новое IY равно
(64×IY + 2×abs(x)×(abs(k) AND 63)) AND FFFF. Знак x и k влияет на
результат произведения по [его договору](Effects.md).

ADC HL,DE складывает слова после второго P с Carry=0. При знаковом
переполнении результат отрицается по модулю 65536. Если значение
8000 остаётся после отрицания с переполнением, DEC HL даёт 7FFF.
Эта поправка сохраняет исходную арифметику, длина вектора в общем случае
не обязана сохраняться. Девять промежуточных слов остаются в исходных
операндах E7AF, E801, E853, E67B, E6CD, E71F, E7BA, E80C, E85E.

[Проверка](../Tools/Disasm/Research/CheckVoxelBasisRotation.py) сверяет
1792 сценария, включая все 256 углов каждого этапа и 1024 смешанных
входа. Проверены 45 816 наборов аргументов произведения, весь переход IY,
девять выходных слов, девять промежуточных слов, IX и SP.
[Отчёт](../Tools/Disasm/Reports/VoxelBasisRotationVerification.json)
отдельно сохраняет 807 положительных и 820 отрицательных переполнений.
Остальные конечные регистры сравнивались с прямым исходным вызовом
в [модели банковой обёртки](../Tools/Disasm/Reports/ActionBankedBasisRotationVerification.json).
