# Остановка финальной сцены

[HaltFinal](../Source/Final/HaltFinal.asm), вход `6148`, завершает финальную
сцену без RET. Она устанавливает IM 0, выдаёт в порт 7FFD значение 17,
устанавливает I=3C, выполняет EI и выдаёт значение 1F в тот же порт.
Затем очищает 768 атрибутов D800..DAFF и выполняет DI, HALT.

При доступной защёлке итоговое 1F выбирает банк 7, ROM 1 и теневой экран.
Бит запрета paging остаётся сброшенным. Если защёлка уже была заблокирована
битом 5, обе записи в порт игнорируются и очищаются атрибуты текущего банка.
Код не проверяет блокировку и не умеет её снять.

Первый ноль записывается по D800, следующие 767 распространяются LDIR.
Конечные HL=DAFF, DE=DB00, BC=0, A=1F.
F равен `(входной F AND C1) OR 28`, поскольку LDIR сохраняет S, Z и Carry,
а недокументированные биты получает из суммы A+скопированный байт.
Альтернативные и индексные регистры сохранены, CPU SP не изменяется.

Конечные I=3C, IM=0, IFF=0. HALT по 616B не снимается обычным маскируемым
IRQ после DI. Соседний [Interrupt](../Source/Final/Interrupt.asm) не является
обычным продолжением этого пути. NMI и другие внешние события здесь
не рассматриваются.

[Проверка](../Tools/Disasm/Research/CheckFinalHalt.py) исполняет исходные
байты с настоящей моделью защёлки 7FFD и портовыми операциями.
Все 64 начальных значения шести битов защёлки проверены со всеми 256 F,
всего 16384 сценария, из них 8192 с запретом paging.
Сверены регистры кроме R, физические банки, кратность записей и оба OUT.
Проверяется исполнение HALT при запрещённых прерываниях, не возврат по
искусственному адресу.

[Отчёт](../Tools/Disasm/Reports/FinalHaltVerification.json)
относится к пути без принятого аппаратного IRQ. После EI имеется короткое
окно разрешённых прерываний до DI, его влияние модель не доказывает.
R/T, NMI и нативное завершение игры также не проверялись.
