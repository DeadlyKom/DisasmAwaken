# Допуск полного класса к списку кандидатов

[CheckCandidateListClass](../Source/Action/CheckCandidateListClass.asm)
занимает EA00..EA14 ACTION банка 0. Читается полный ClassCode записи IX.
По порядку сравниваются коды 0, 4, 5, 8, 1, 9. Первое совпадение возвращает
Z, отсутствие совпадений возвращает NZ после сравнения с 9.
Коды не маскируются, их игровые названия здесь не назначаются.

HL, DE, BC, альтернативные регистры, IX, IY, I, IM, IFF и paging сохраняются.
A равен ClassCode, F соответствует последнему выполненному CP. RAM не
изменяется, SP увеличивается внешним RET на два. R добавляет 2+2*k M1,
где k — число выполненных сравнений от одного до шести, бит 7 R сохраняется.

[CheckCandidateListReady](../Source/Action/CheckCandidateListReady.asm)
использует установленный Z для допуска к просмотру списка.
[Независимая модель](../Tools/Disasm/Research/CheckActionCandidateEligibility.py)
проверила все 256 классов при всех 256 исходных флагах, точные регистры,
R, SP и отсутствие записей RAM. Ещё 4096 сценариев проверяют вызывающий
обработчик, общий отчёт содержит 69632 сценария. IRQ, сборка и нативный
запуск не выполнялись.
