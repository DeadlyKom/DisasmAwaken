# Кнопка «Контракт» и фактическое центрирование карты

Исходный элемент 18 имеет TextIndex=20. Его физическая LF-запись содержит подпись `Контракт` и подсказку о центрировании изображения карты относительно звезды следующего выбранного контракта. Байты исходного текста, включая отсутствие пробела между `карты` и `относительно`, сохранены.

[InstallContractMapCallback](../Source/Station/InstallContractMapCallback.asm) устанавливает адрес [CenterContractMap](../Source/Station/CenterContractMap.asm) через общий ActivateInterfaceCallback. Само центрирование здесь не вызывается. [DrawContractButton](../Source/Station/DrawContractButton.asm) является изменяемой индексной обёрткой DrawCenteredItem.

## Локальный алгоритм

CenterContractMap сначала записывает `DecodedMessageConst.AlienSignal=1` в `MissionOffer.Entry.MessageIndex`, затем читает изменяемый курсор из операнда `ContractMapState.Cursor`, исходно `#99A3`. При каждой попытке увеличивает HL и читает **абсолютный адрес ROM `#0001`**. Исходные инструкции `3A 01 00` не заменены чтением через HL.

| Первое чтение | Действие |
|---|---|
| 0 | Повторить INC HL, сохранённый курсор пока не менять |
| 1..127 | Сохранить увеличенный HL как курсор |
| 128..255 | Заменить HL базой кодов `MapAuxiliaryCodes.State=#99A3` и сохранить её как курсор |

При постоянном нулевом первом чтении локального выхода нет, HL оборачивается по слову, SP остаётся прежним. После сохранения курсора второе абсолютное чтение `#0001` проверяется только на ноль. Ноль завершает процедуру с AF=0054 и уже изменённым курсором. Для другого значения рассчитывается адрес:

`Address = (MissionOffer.Entry + 4 * (Cursor - MapAuxiliaryCodes.State)) AND FFFF`.

Из четырёх байтов читаются FirstWord в DE и SecondWord в HL. Исходный JR передаёт их в [CenterKeyAndRefreshMap](../Source/Station/CenterKeyAndRefreshMap.asm). Тот выбирает систему, получает вариант из первого совпадения списка A либо ноль, центрирует начало и выполняет [RefreshStoredMapPanels](../Source/Station/RefreshStoredMapPanels.asm), условную панель сведений и полный рисунок карты. Собственного запроса Pending в CenterContractMap нет.

## Проверенный ROM-профиль

В локальной конфигурации Unreal выбран PENTAGON, ROMSET пустой и задан объединённый файл `pentagon.rom`. Его SHA256 записан в [отчёте профиля](../Tools/Disasm/Reports/ContractRomProfileVerification.json). Последний блок 16 KiB, файловое смещение 49152, имеет SHA256 `8d93c3342321e9d1e51d60afcd7d15f6a7afd978c231b43435a7c0757c60b9a3` и побайтово совпал с ROM 1 прежней исследовательской модели. Отдельный `48for128.rom` отличается от этого блока одним байтом по смещению `#006D`. По адресу `#0001` оба содержат `AF`.

Для стабильного AF первое чтение всегда устанавливает курсор в `#99A3`, второе не равно нулю, относительный индекс равен нулю. Выбираются первые четыре байта `MissionOffer.Entry`, то есть ключ текущего предложения. Старое значение курсора при этом не меняет выбор. Подсказка говорит о следующем контракте, однако этот проверенный профиль всегда возвращает к первому ключу. Особенность оригинала сохранена.

Это подтверждение содержимого локальных ROM-файлов и поведения заданной модели. Состояние запущенного процесса Unreal, выбранная в нём конфигурация и нативное нажатие кнопки не проверялись. Изменять код игры для обхода этого поведения оснований нет.

## Что остаётся неизвестным

При положительном ROM-байте формула может читать другие физические поля после начала предложения. Вся область после `#98B0` не объявляется массивом контрактов. Промежуточные неизвестные слова предложения сохраняют свои Unknown-имена. Для нестандартной либо меняющейся ROM не установлены все игровые значения таких выборок. Нулевое число Unknown-процедур станции после этого разбора не означает завершённости её физических данных и всех вызывающих контрактов.

## Проверки

[CheckAuxiliaryCycleReads.py](../Tools/Disasm/Research/CheckAuxiliaryCycleReads.py) проверяет все 256 значений первого ROM-чтения, 11 курсоров, обнуление второго чтения, 2805 передач ключа, 2805 ранних возвратов и 704 наблюдаемых повторения нулевой петли. Это локальная проверка до общего хвоста. [Отчёт](../Tools/Disasm/Reports/AuxiliaryCycleReadsVerification.json).

[CheckContractRomProfile.py](../Tools/Disasm/Research/CheckContractRomProfile.py) получает ROM-файлы явными входными аргументами, проверяет их байты и исполняет полный исходный путь на 96 сценариях. Охвачены четыре ключа, три прежних курсора, оба экранных бита, наличие панели сведений и совпадение списка A. Координаты центра рассчитаны независимо. Исполнены 240 настоящих IM2 только в HALT, музыка выключена. [Отчёт](../Tools/Disasm/Reports/ContractRomProfileVerification.json).

Код ROM не исполняется, ROM используется как данные. Независимый bitmap всей карты, сборка и нативная игра этими моделями не подтверждены.
