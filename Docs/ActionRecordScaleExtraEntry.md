# Дополнительное удвоение масштаба ACTION

Байт #29 по #E59F расположен сразу за изменяемым JR по #E59D. Подготовитель вычисляет смещение как `6 − e`, где e — старший байт заголовка модели. Для 128 исходных указателей e лежит в диапазоне 1..5, поэтому цели штатной проверки начинаются с #E5A0. При e=6 смещение равно нулю, и JR передаёт управление на #E59F. [Подготовка](ActionRecordScale.md) · [Исходник](../Source/Action/DoubleRecordScale.asm)

По #E59F выполняется ADD HL,HL. Затем управление доходит до #E5A0 без записи на стек. При HL=200 цепочка из пяти удвоений даёт 6400 перед вычислением границы, что соответствует B=100 в следующем фрагменте.

Модель исполнила исходный читатель заголовка и изменяемый JR для обычного класса и класса #14 с тестовым e=6. Отдельно проверены все 65 536 значений HL, результирующие флаги, неизменность остальных рабочих регистров и отсутствие записи памяти у дополнительного удвоения. Штатный сценарий с e=6 пока не установлен. [Проверка](../Tools/Disasm/Reports/ActionRecordScaleExtraEntryVerification.json)
