# До двух связанных записей класса 3

[CountClass3LinksUpToTwo](../Source/Action/CountClass3LinksUpToTwo.asm)
занимает 62CF..6310 перенесённого ACTION. Список начинается с Record00,
шаг равен размеру FActionRecord=40. Счётчик учитывает только активные строки,
в которых одновременно ClassCode=3, StateCode=02 и LinkedIndex равен
Unknown0D записи, указанной IX. Код 02 проверяется целиком, независимым
флагом он не объявляется. Глобальные игровые роли классов и Unknown0D
этим локальным предикатом не устанавливаются.

Первое действие цикла прибавляет шаг к HL=A0C1, то есть читает High первой
записи по A101. При High=80 проверяется Low. Low=80 означает конец,
другой Low означает пропуск. Значения остальных High, включая ноль,
считаются активными. Подходящая ссылка FF учитывается, если целевой
Unknown0D также равен FF, дополнительной проверки диапазона индекса нет.

Просмотр прекращается сразу после второго совпадения либо первого маркера.
Возвращаются A=B=0, 1 либо 2. При нуле и одном F=93, Carry=1, при двух
F=42, Carry=0 и Z=1. Полное число совпадений дальше второго не вычисляется.
Завершение требует достижимого маркера либо двух подходящих строк,
самостоятельного ограничения длины массива нет.

При выходе по маркеру HL указывает его Low по смещению 0, при двух
совпадениях High второй записи по смещению 1. Это различие сохранено.
DE=40. C содержит младший адрес High последней проверенной активной строки,
даже если она не прошла предикат. Неактивные строки C не обновляют, если
активных не было, сохраняется входной C. Альтернативные и индексные
регистры сохранены, I, IM, IFF и страница не меняются. SP после RET равен
входному SP+2, RAM и CPU-стек не записываются.

## R

Подготовка даёт 4 M1. Неактивная строка даёт 9, активная с другим классом
12, с классом 3 и другим StateCode 19, с классом 3, кодом 02 и другой
ссылкой 27, полное совпадение 31. Терминальный маркер даёт 8 M1, после
обоих видов завершения добавляются 3 M1 окончательного A, CP и RET.
Бит 7 R сохраняется. В фикстурах наблюдалось 15..544 M1, это не общий
предел длины исходного списка.

## Проверка

[Числовая модель списка](../Tools/Disasm/Research/CheckActionClass3LinkCount.py)
прошла 202350 сценариев, все 65536 пар ClassCode и StateCode, все пары
LinkedIndex и целевого Unknown0D, все пары двух байтов заголовка, позиции
нуля, одного и двух совпадений с тремя видами префиксов, все исходные C
при отсутствии активных строк и 4096 смешанных списков.

Сопоставлены все регистры включая R. В каждом сценарии отсутствовали
записи, итоговые восемь банков совпали с входной фикстурой. Начальные
значения 7FFD 0..63 распределены по тестам, переключений нет. Полный набор
списков, штатная игровая ёмкость, IRQ, точные T, сборка и нативный запуск
не проверены.
