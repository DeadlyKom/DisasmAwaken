# Создание связанной записи класса 17

[CreateClass17LinkedRecord](../Source/Action/CreateClass17LinkedRecord.asm) занимает исходные 60E8..6144 в перенесённом коде банка 5. Физическое смещение в ACTION отличается на 23D, ни новый адрес, ни новая память не выделяются.

## Вход и выделение

Альтернативные HL/DE/BC задают три Components ребёнка, альтернативный A задаёт Unknown11. Основной B копируется в Unknown0D, C является обычным индексом цели, A становится начальным Unknown13. Назначение этих неизвестных полей в других состояниях данным договором не переопределяется.

A записывается в операнд InitialParam по 612E ещё до поиска. [FindReusableRecord](../Source/Action/FindReusableRecord.asm) может очистить ReuseByte=FF и пропустить такую запись один раз. При отсутствии слота возвращаются A=80/F=42, IY указывает маркер, BC и альтернативные пары сохранены. Параметр уже изменён, его запись не отменяется.

## Поля ребёнка

| Поле | Исходное значение |
| --- | --- |
| Components | альтернативные HL, DE, BC |
| ModelOffset | 90 |
| OffsetPhase0/1/2 | 0 |
| StateCode | 08 |
| LinkedIndex, LinkFlags | 0 |
| Unknown0D | входной B |
| TargetIndex | входной C |
| Unknown11 | входной альтернативный A |
| ClassCode | 11, десятичный класс 17 |
| Unknown13 | входной A |
| TargetCodeStep | 2 |

Все остальные поля сохраняются после побочных действий поиска. Дополнительного обнуления Unknown10 или оставшегося хвоста нет.

## Обратная связь и результат

Цель вычисляется обычной формулой A100+64*C. FF здесь не является специальной ссылкой A780. У цели устанавливается бит 1 LinkFlags, затем LinkedIndex получает индекс созданной записи IY. Целевая запись не проверяется на активность и класс, эту исходную особенность нельзя исправлять при дизассемблировании.

При успехе HL=0040, DE указывает LinkedIndex цели, BC сохранён, A содержит индекс ребёнка, Carry установлен. Остальные F сохраняются от преобразования IY. Индекс ноль способен вернуть Z=1 даже при успешном создании. Альтернативный AF равен 0044, остальные альтернативные пары, IX, I, IM, IFF и paging сохраняются. IY указывает ребёнка. Внешний RET увеличивает SP на два, требуется до шести дополнительных байтов стека. R добавляет стоимость поиска и 88 M1 при успехе либо 5 при отказе.

## Проверка

[Независимая модель](../Tools/Disasm/Research/ReferenceActionClass17Spawn.py) сопоставлена с настоящими командами и поисковыми детьми [проверкой](../Tools/Disasm/Research/CheckActionClass17Spawn.py). Прошли 66560 сценариев, все пары B/C, все начальные A, разные позиции слота, FF-пропуск и отказ выделения. Сверены точные регистры, флаги, R, все восемь банков, кратность RAM-записей и остатки стека. [Результат](../Tools/Disasm/Reports/ActionClass17SpawnVerification.json).

Полное произведение входов, аппаратные прерывания, точные T, сборка и нативная игра не проверялись.
