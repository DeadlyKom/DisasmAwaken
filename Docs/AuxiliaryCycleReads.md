# Неразобранный выбор по 7CC6 и абсолютный адрес 0001

[Unknown7CC6](../Source/Station/Unknown7CC6.asm) сохраняет статус Unknown. Ни соседние записи интерфейса, ни внешний вид петли не доказывают предназначенный игровой алгоритм. Ниже отдельно перечислены проверенные факты.

В исходных инструкциях 7CCF и 7CDE стоят байты 3A 01 00, то есть LD A,(0001). Это не LD A,(HL) и не чтение соседнего кода списка. Код сначала пишет 1 по 98BF, затем читает изменяемый указатель по 7CCC, исходно 99A3. Указатель увеличивается, но обе проверки обращаются к абсолютному 0001.

Если первое чтение неотрицательное и ненулевое, увеличенный адрес сохраняется обратно по 7CCC. Если его бит 7 установлен, указатель заменяется 99A3. Если первое чтение нулевое, указатель снова увеличивается без сохранения. При постоянном нулевом байте локальный цикл не имеет выхода, HL циклически оборачивается по слову, SP не меняется. Это утверждение относится к постоянному отображению памяти без внешнего изменения кода либо ROM.

Второе абсолютное чтение имеет отдельный RET Z. Если значение изменилось на ноль между двумя чтениями, возврат происходит уже после сохранения указателя, AF=0054. При ненулевом втором чтении вычисляется адрес 98B0+4*(сохранённый указатель-99A3), оттуда читаются два слова и передаются в [CenterKeyAndRefreshMap](../Source/Station/CenterKeyAndRefreshMap.asm). Первые четыре байта области и записанный 98BF могут пересекаться с реально используемыми данными, окончательная структура и роль записи здесь ещё не объявлены установленными.

Единственное обнаруженное прямое чтение 98BF вне этого входа находится в [Unknown6E76](../Source/Station/Unknown6E76.asm), где значение выбирает LF-запись PrintAfterLF от E262. Это ещё не полный проход по косвенным писателям, загрузкам и возможному переиспользованию областей. Прямых записей в операнды 7CD0 и 7CDF в текущих размеченных инструкциях не найдено, отсутствие динамической самомодификации из этого не следует.

[CheckAuxiliaryCycleReads](../Tools/Disasm/Research/CheckAuxiliaryCycleReads.py) и [отчёт](../Tools/Disasm/Reports/AuxiliaryCycleReadsVerification.json) проверили все 256 значений первого чтения и 11 исходных курсоров. Получены 2805 передач ключа, 2805 ранних возвратов при обнулённом втором чтении, 704 наблюдаемых повторения нулевого цикла. Исходные абсолютные инструкции проверены по байтам. Общий центрирующий хвост в этой модели не исполняется.

Содержимое ROM выбранного пользователем Unreal этими проверками не подтверждено. Нельзя переносить байт из библиотечной ROM модели на нативный эмулятор. Назначение 98BF, всей вычисляемой области ключей, достижимость рабочего пути в реальной игре и возможные динамические писатели ещё требуют разбора. Сборка, аппаратные IRQ и нативный запуск не выполнялись.
