# Расчёт базовых слов смещения объекта

6D06 сохраняет IX и входное DE, затем вызывает построитель трёх
коэффициентов. Для каждого коэффициента MultiplySignedScaled получает
то же исходное слово DE. Вычислитель возвращается через IX на один
из трёх адресов сохранения результата. Три слова записываются в
Base0, Base1 и Base2 в коде обновления записи.

Первая и вторая передачи сохраняют исходное DE на CPU-стеке. Третья
использует последнее восстановленное DE, затем IX снимается перед
обычным RET. Максимум шесть временных байтов приходится на CALL
построителя коэффициентов. IYL сохраняет результат фазовой выборки.

Проверены все 65 536 исходных DE и 8 192 дополнительных прохода с
другими фазовыми значениями. Сверены регистры, R, все записи и глубина
стека. [Исходник](../Source/Action/ApplyObjectOffsetVector.asm).
