# Архив ZXTime в удалённой записи 0

Каталог TR-DOS хранит удалённую BASIC-запись длиной 327 байтов, за которой
числятся 237 секторов. [Логическая часть](../Tools/Disasm/Extracted/Deleted/00__XTime15.B.bin)
содержит строку `zxtime#0F` и подпись Karlo Computer Software.
[Полные сектора](../Tools/Disasm/Extracted/Deleted/00__XTime15.B.sectors.bin)
содержат продолжение загрузчика и сжатые данные.

В машинной части BASIC по смещению 0037 задаются HL=6000 и B=26h,
вызывается дисковая процедура 5D86, затем CALL 6000. По смещению 0200
в секторах начинается распаковщик, за ним по 0303 находится заголовок HR.
Абсолютное смещение заголовка в TRD равно 01303. Длина потока равна 9350
байтам, размер результата равен 40960 байтам.

Распаковщик сохраняет SP и переносит 222 байта из 6025 по 5B00, за счёт
чего продолжает исполняться вне выходной области. Упакованный поток
сдвигается в конец RAM через LDDR. После восстановления хвостовых байтов
и исходного SP выполняется JP 6000 в полученный код. Внутри результата
по смещению 6C00 находится подпись ProTracker 3.6.

[Исследовательская проверка](../Tools/Disasm/Research/CheckDeletedXTimeArchive.py)
выполнила оригинальный распаковщик после подстановки уже загруженных 38
секторов. Состояние остановлено перед первым исполнением распакованной
программы. Все 40960 байтов совпали с независимым декодером HR.
[Извлечённый результат](../Tools/Disasm/Extracted/Deleted/00__XTime15.B.unpacked.bin)
сохранён отдельно. [Отчёт](../Tools/Disasm/Reports/DeletedXTimeArchiveVerification.json)
содержит границы и SHA256. Каталог и сектора образа сохранены в прежнем виде.
