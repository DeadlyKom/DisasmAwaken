# Проекция и рисование тела из ACTION

CEFA сохраняет входной DE как Pattern по D240 и обнуляет CEF9.
ProjectAndCheckComponents использует режим 0 с Component2 как глубиной
и проверяет компоненты после проекции. При A=0 рисование пропускается,
записанные поля проекции сохраняются. При ненулевом A вызывается
DrawProjectedBody. [Вход CONTROL](../Source/Controls/ProjectAndDrawBody.asm).

6C7E задаёт Pattern=FFAA, выбирает CONTROL записью 11 в 7FFD,
вызывает CEFA и затем пишет 10 в 7FFD. Рисунок имеет чередование AA/55.
Последний селектор возвращает A=10 и сохраняет F. Для переключения
бит аппаратной блокировки должен быть сброшен.
[Вход ACTION](../Source/Action/DrawBankedProjectedBody.asm).

Глубина достигает 18 временных байтов от входа CEFA и 20 от входа
6C7E при проходе большого круга через корень. В 9 918 сценариях
исполнялись реальные процедуры. Сверены регистры кроме R, банки и
портовые записи. Значения внутренней рамки проекции сверялись по
допустимому диапазону записи, её содержимое перенесено из наблюдения
при сравнении итоговой памяти. После проекции значения и кратность
непиксельных записей проверены независимо.
[Отчёт](../Tools/Disasm/Reports/ProjectedBodyEntryVerification.json).
