# Voxel

Операционные факты ниже получены из исходных инструкций.
Список непосредственных чтений и записей не включает косвенные обращения
через HL, DE, BC, IX/IY и эффекты вызываемых подпрограмм.

## RotateBasisVectors

[Voxel.RotateBasisVectors](../../Source/Voxel/RotateBasisVectors.asm)

Последовательное преобразование трёх векторов ориентации #9B00..#9B11 по углам #9B14, #9B12 и #9B13.

Вход `#E500`, запись 20, смещения `#2500..#28A0`.

- Прямые вызовы: `#E8A1`.
- Непосредственные чтения: `#9B00`, `#9B02`, `#9B04`, `#9B06`, `#9B08`, `#9B0A`, `#9B0C`, `#9B0E`, `#9B10`, `#9B12`, `#9B13`, `#9B14`, `#E67B`, `#E6CD`, `#E71F`, `#E7AF`, `#E7BA`, `#E801`, `#E80C`, `#E853`, `#E85E`.
- Непосредственные записи: `#9B00`, `#9B02`, `#9B04`, `#9B06`, `#9B08`, `#9B0A`, `#9B0C`, `#9B0E`, `#9B10`, `#E67B`, `#E6CD`, `#E71F`, `#E7AF`, `#E7BA`, `#E801`, `#E80C`, `#E853`, `#E85E`.
- Ввод и вывод: нет.
- Косвенное завершение: нет в этом фрагменте.
