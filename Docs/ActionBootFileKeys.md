# Файловые ключи загрузчика полёта

[FileKeys](../Source/ActionBoot/Data/FileKeys.asm) содержит шесть физических
экземпляров FTrDosFileKey. Они занимают исходные файловые смещения
0113..0148 ACTION, после переноса загрузчика их адреса 42D0..4305.
Это адреса загрузочного контекста, к обычному отображению ACTION по
6000 они не приравниваются.

| Ключ | Адрес | Использование в InitializeFlight |
|---|---|---|
| Voxal | 42D0 | Чтение VOXAL в уже выбранный банк 3, начало EC00 |
| Voxal0 | 42D9 | Чтение VOXAL0 в банк 3 по C000 |
| Control | 42E2 | Поиск CONTROL и чтение в банк 1 по DADE |
| Control0 | 42EB | Поиск CONTROL0, сохранение положения файла и чтение в банк 1 по C000 |
| Panel | 42F4 | Чтение PANEL в банк 6 по C000 и распаковка |
| Object3D | 42FD | Чтение OBJECT3D в банк 4 по C000 |

Каждый ключ содержит восемь символов имени, включая исходные пробелы,
и байт C равный 43. Нулевого терминатора нет. Потребитель
[InitializeFlight](../Source/ActionBoot/InitializeFlight.asm) либо копирует
все девять байтов в 5CDD, либо передаёт их
[GetFileLocation](../Source/ActionBoot/GetFileLocation.asm), который делает
такое же копирование перед поиском и чтением заголовка TR-DOS.
Адрес назначения задаёт загрузчик и выбранный им банк, структура ключа
адрес загрузки не содержит.

Разметка повторно использует существующую структуру. Имена полей, размеры,
значения, пробелы в литералах и порядок запросов сохранены. Проверка
[VerifySources](../Tools/Disasm/VerifySources.py) сравнивает все 54 байта
с оригиналом и адреса шести экземпляров с реестром символов.
Исследовательский [сценарий публикации](../Tools/Disasm/Research/PublishActionBootFileKeys.py)
сохраняет отдельный кандидат и основание до замены файлов.

Модель [входа в полёт](ActionFlightCycle.md) рассматривает настоящие Z80
вызовы загрузчика с подставленными успешными дисковыми ответами. Разметка
ключей не расширяет это подтверждение до настоящего TR-DOS, ошибок диска
или нативной игры. Ассемблер при этой работе не запускался.
