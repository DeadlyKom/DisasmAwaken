# Условное создание дочерних записей класса 9

[SpawnLinkedClass9Records](../Source/Action/SpawnLinkedClass9Records.asm)
занимает E86B..E91D ACTION банка 0. IX указывает активного родителя,
A задаёт начальное состояние создаваемых записей. При установленном
бите 2 ReuseByte выполняется ранний RET без изменения A и RAM.
Это тот же разряд, который сбрасывает
[HandleSelectedRecordProximity](ActionSelectedRecordProximity.md).
Общий смысл остальных разрядов ReuseByte из этой связи не выводится.

При сброшенном бите входной A сначала сохраняется в операнд E8F1
инструкции LD (IY+StateCode),n. Затем вызывается поток 11.
Новый младший байт L>=0A завершает вызов, бит запроса ещё не установлен.
При L<0A бит 2 устанавливается **до поиска места**. Младший бит следующего
прочитанного R плюс один задаёт число запросов, 1 либо 2.

Каждый запрос вызывает [FindReusableRecord](ActionRecordSearch.md).
Поиск очищает ReuseByte доступных записей и однократно пропускает FF.
Если достигнут маркер, происходит ранний RET Z. Бит 2 родителя остаётся
установленным, уже созданные дети не отменяются. EXX перед поиском
**не уравновешивается** на этом раннем возврате, основные и альтернативные
пары остаются обменёнными. Это исходная особенность договора.

Для найденного ребёнка сохраняются индекс родителя в Unknown20 и
требуемый полный класс 8 в Unknown21. Одно положительное BC-смещение
создаётся из двух разных чтений R, B=1 либо 2, C=0..127. Оно прибавляется
ко всем трём Components родителя по модулю 65536. Если результирующий
старший байт первой компоненты равен 80, запись может снова попасть в
следующий поиск как свободная, отдельного резервирующего флага нет.
Сочетание полного слова 8080 также может стать маркером этого поиска.

Остальные исходные поля ребёнка:

| Поле | Значение и установленный смысл |
| --- | --- |
| ModelOffset | 88 при бите 7 R=1, иначе 8C, это байтовое смещение таблицы моделей |
| TargetIndex, физический 0F | 5A, в данном контексте управляющий байт, разыменования здесь нет |
| OffsetPhase0 | 0 |
| OffsetPhase1 | отдельное чтение R AND 0F |
| OffsetPhase2 | следующее чтение R AND 07 |
| Unknown11 | 28, десятичное 40 |
| StateCode | входной A через общий изменяемый операнд |
| SavedStateCode | 0D, индекс проверки выбранной записи |
| LinkFlags | 0 |
| ClassCode | 9 |
| Unknown14 | 0 |
| LinkedIndex | текущая связь родителя, отличается от его индекса в Unknown20 |
| Unknown15 | FF, отсутствие прямой подстановки |
| Unknown13 | 32, десятичное 50, общий смысл поля ещё не доказан |
| Unknown10 | 1 |
| TargetCodeStep | 2 |

Счётчик уменьшается только после полного заполнения ребёнка. При полном
создании B=0, C и DE сохраняются от входа, HL равен новому слову потока 11,
A равен связи родителя, F=42. Альтернативные пары содержат последние
рабочие значения заполнения, IY указывает последнюю найденную запись.
При отказе выделения AF=8042, IY указывает маркер, в альтернативном B
остаётся число невыполненных запросов. AF', IX, I, IM, IFF и paging
сохраняются на всех путях, SP после RET увеличен на два.
Максимальная дополнительная рамка CPU-стека равна четырём байтам.

R добавляет 3 M1 при исходно установленном бите и 74 при случайном отказе.
После успешного случайного допуска начальная стоимость равна 81 M1.
Каждый успешно заполненный ребёнок добавляет стоимость поиска плюс
104 M1 и ещё один при сброшенном бите 7 R. Полное завершение добавляет
один M1 заключительного RET. Поиск, завершившийся маркером, добавляет
свою стоимость и 3 M1 EXX, CALL и RET Z без последнего RET процедуры.
Бит 7 R сохраняется, точные T не измерялись.

[Независимая композиционная модель](../Tools/Disasm/Research/CheckActionChildSpawn.py)
проверила 73472 сценария. Исчерпаны все 65536 исходных слов потока 11
при FoldByte=0, все R с шестью профилями места и четырьмя входными
состояниями, все ReuseByte с обоими Carry, все FoldByte с пятью словами.
Реальные поток, поиск и преобразователь адреса исполняются.
Сверены регистры, флаги, R, SP, восемь банков и кратность записей.
Проверены отказы, однократные пропуски и оборачивание компонент.
Полное произведение входов, аппаратные IRQ, сборка и нативный запуск
не выполнялись.
