# Максимум покомпонентных расстояний записей

[MaxRecordDeltaHigh](../Source/Action/MaxRecordDeltaHigh.asm) занимает
EAE9..EB40 ACTION банка 0. IX указывает исходную запись, IY выбранную.
Читаются три слова Components обеих FActionRecord. Координаты в самих
записях не меняются. Четыре байта ниже CPU SP временно сохраняют два
модуля, внешний адрес возврата не меняется.

Для каждого номера i вычисляется `delta[i]=wrap16(IY[i]−IX[i])`.
Если бит 15 сброшен, модуль равен delta, иначе `wrap16(−delta)`.
Отрицательность задаётся знаком обёрнутого слова. JP P после SBC
не является сравнением исходных математических координат без
переполнения. Особое значение 8000 остаётся 8000 и означает здесь
беззнаковый модуль 32768.

Результат A равен максимуму старших байтов трёх модулей. Это
`floor(max(magnitude)/256)` в диапазоне 0..128, а не евклидова длина.
Единицы самих компонент ещё не установлены. HL возвращает полный модуль
третьей разности, DE первой, BC сохраняется. Второй модуль остаётся
в нижнем временном слове CPU-стека, первый в следующем слове.

Флаги возвращаются от сравнения старшего байта первого модуля с уже
выбранным максимумом второго и третьего. Точнее, исполняется
`CP(max(high1, high2), high0)`. При выборе большего high0 последующий
LD A,D флаги не меняет. Поэтому F не следует интерпретировать как
новую проверку возвращаемого A. HL', DE', BC', AF', IX, IY, I, IM, IFF
и paging сохраняются. SP после RET увеличен на два.

Число M1 равно 45 плюс семь на каждую отрицательную разность,
плюс один при high2 меньше high1, плюс два при high0 больше их максимума.
Младшие семь разрядов R увеличиваются с оборачиванием, бит 7 сохраняется.
Точные T и порядок аппаратных шинных циклов этой формулой не доказаны.

[Независимая модель](../Tools/Disasm/Research/CheckActionRecordDistance.py)
проверила 197337 исполнений. Для каждой из трёх разностей перебраны все
65536 значений при фиксированных остальных двух. Ещё 729 троек
покрывают совместные знаки, код 8000, границы старшего байта и равенства
максимумов. Получены все 32 профиля ветвей. Сравниваются точные
регистры, флаги, R, SP и все четыре записи временных слов со значениями.
Другие записи не допускаются. Полное произведение шести входных слов
не исчерпано. IRQ, сборка и нативное исполнение не выполнялись.

Явные CALL находятся, в частности, по F061 и F35E, внутри ещё
разбираемых обработчиков таблицы состояний. Сам тест вычислителя
не выполняет эти игровые вызывающие цепочки.
[Охват обработчиков](ActionObjectStateDispatch.md) учитывается отдельно.
