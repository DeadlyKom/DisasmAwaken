# Хвост станционного контекста в ACTION

[Проверка перехода](MapDistanceAndRenderState.md) исполняет исходное
копирование 512 байтов из станционного состояния по 983B во временный
буфер 4000 и затем в ACTION по 9BBD. Содержимое дискового ACTION до этого
копирования сохраняется буквально.

[Пары настроек](../Source/Action/Data/ContextControlPairs.asm) по 9D82..9D9F
соответствуют смещению +1C5, записям 28..42 исходного ControlOptions.
Первые 14 содержат однобитовые маски клавиш и селекторы строк,
последняя пара равна 00 00. Все 30 байтов исходного ACTION совпадают
с STATIONF и SAVE0..SAVE4. В SAVE5 этот диапазон нулевой.

Обычный [сканер ACTION](ActionKeyDispatchPrefix.md) заканчивает свой
проход с IX=9D82. Эта пара не читается в том же проходе, поэтому
индивидуальные игровые действия следующих пар в ACTION пока неизвестны.
Пары оформлены как существующие FSettingWord по подтверждённому
формату станционного источника.

[Исходный средний диапазон](../Source/Action/Resources/InitialTransferredContextMiddle.bin)
занимает 9C8B..9D4B, то есть +CE..+18E. [Исходный хвост](../Source/Action/Resources/InitialTransferredContextTail.bin)
занимает 9DA0..9DBC, то есть +1E3..+1FF. Модель полного копирования
сверяет все байты назначения с фактическим снимком станции. При обратной
сборке остаются исходные байты ACTION, станционные значения туда не
подставляются. Роли отдельных байтов в этих двух диапазонах пока не
установлены. Хвост 9DBD..9DFF лежит за границей копирования и сохраняется
как отдельный неизвестный диапазон.

[Хвосты STATIONF и SAVE](SavedStateLayout.md) физически соответствуют
9DA0..9DBC в ACTION. Исходные байты и отметка границы обратного
переноса проверены с отдельным 29-байтовым маркером.
