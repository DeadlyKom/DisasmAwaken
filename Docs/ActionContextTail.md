# Хвост станционного контекста в ACTION

[Проверка перехода](MapDistanceAndRenderState.md) исполняет исходное
копирование 512 байтов из станционного состояния по 983B во временный
буфер 4000 и затем в ACTION по 9BBD. Содержимое дискового ACTION до этого
копирования сохраняется буквально.

Индексы корабля и глайдера и сумма игрока находятся в начале этого
контекста, по смещениям `#0E`, `#0F` и `#13`. В обоих направлениях
подтверждены адреса и сохранение значений.
[Перенос полей игрока](ActionTransferredPlayerFields.md)

[Пары настроек](../Source/Action/Data/ContextControlPairs.asm) по 9D82..9D9F
соответствуют смещению +1C5, записям 28..42 исходного ControlOptions.
Первые 14 содержат однобитовые маски клавиш и селекторы строк.
Последние два байта равны 00 00 и соответствуют станционным
[счётчикам выбора ресурса](StationScriptFields.md). Все 30 байтов исходного
ACTION совпадают с STATIONF и SAVE0..SAVE4. В SAVE5 этот диапазон нулевой.

Обычный [сканер ACTION](ActionKeyDispatchPrefix.md) заканчивает свой
проход с IX=9D82. Эта пара не читается в том же проходе, поэтому
индивидуальные игровые действия следующих пар в ACTION пока неизвестны.
Физические пары в исходном ACTION оформлены как FSettingWord. Для двух
последних байтов подтверждён станционный договор, читатель в ACTION
в проверенном полёте не обнаружен.

[Средний диапазон](../Source/Action/Data/ContextMapAndOptions.asm) занимает
9C8B..9D4B, то есть +CE..+18E. По 9C8B сохранён старший байт архивного
DALNO, его современный читатель неизвестен. [Сверка поля](ActionArchivedBodyContext.md)
Далее физические записи оформлены теми же структурами,
что и в станционном [состоянии SAVE](SavedStateLayout.md).

| Адрес в ACTION | Записи |
|---|---|
| 9C8C..9CF1 | Два списка сохранённых точек карты и их ограничители |
| 9CF2..9CFC | Порядок точек |
| 9CFD..9D24 | Дополнительные точки |
| 9D25..9D2F | Коды дополнительных меток |
| 9D30..9D37 | Настройки интерфейса MouseOption, JoyOption, MusicMode и FillMode |
| 9D38..9D43 | Клавиши указателя, четыре направления и два действия |
| 9D44..9D49 | Цвета интерфейса InkBits, PaperRotate и HighRotate |
| 9D4A..9D4B | FlightMouse, первая пара ControlOptions перед активной таблицей клавиш |

Семь групп побайтово совпадают с исходным STATIONF. В кодах дополнительных
меток различаются десять из одиннадцати байтов, все значения ACTION
сохранены. Формат групп и перенос подтверждены, отдельные потребители
ACTION пока не установлены. [Сверка физической разметки](../Tools/Disasm/Reports/ActionContextMapRecordsClassification.json)

В двух исходных полётных профилях все 193 байта совпали с отправленным
станционным контекстом после 64 кадров. В профиле с рабочим возвратом
сверена запись этих байтов обратно по 9909..99C9 на входе свежей станции.
[Проверка перехода и возврата](../Tools/Disasm/Reports/StationFlightCycleVerification.json)

[Исходный хвост](../Source/Action/Resources/InitialTransferredContextTail.bin)
занимает 9DA0..9DBC, то есть +1E3..+1FF. Модель полного копирования
сверяет все байты назначения с фактическим снимком станции. Исходные
нули по `#9DA0..#9DFF` заполняют промежуток до страницы указателей
OBJECT3D. Первые 29 байтов находятся внутри 512-байтового назначения
и перезаписываются при переносе. Оставшиеся 67 байтов находятся после него.
[Авторский макрос и граница](ActionObjectPointers.md#выравнивание-таблицы)

[Хвосты STATIONF и SAVE](SavedStateLayout.md) физически соответствуют
9DA0..9DBC в ACTION. Исходные байты и отметка границы обратного
переноса проверены с отдельным 29-байтовым маркером.

## Перенос тела NEWS и соседних байтов

| Смещение контекста | Станция | Полёт |
| --- | --- | --- |
| `#85..#8A` | `#98C0..#98C5` | `#9C42..#9C47`, [тело NEWS](StationNewsTransfer.md) |
| `#C9..#CA` | `#9904..#9905` | `#9C86..#9C87` |
| `#CC` | `#9907` | `#9C89` |
| `#CE` | `#9909` | `#9C8B` |

Один профиль сохраняет значения исходной станции, второй записывает
десять разных контрольных значений перед вылетом. В обоих профилях
байты сохранились после загрузки ACTION, 64 полётных кадров,
гиперперехода, двух следующих кадров и возврата к `#6300` свежей станции.
Монитор обращений к этим адресам за 64 кадра исходного полёта не
зафиксировал чтений или записей. Переносы контекста происходят за
границами этого окна. Смысл отдельных байтов и обращения в других
сценариях остаются открытыми.
