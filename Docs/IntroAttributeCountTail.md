# Условный обход атрибутов в хвосте вступления

Исходный LDIR из вступления переносит 54 байта AWAKEN.B по файловым смещениям #2C97..#2CCC из RAM #8F97..#8FCC в #7497..#74CC. По #7497 начинается последовательность с замкнутой рамкой из четырёх слов и выходом RET. Прямой вызов этого входа в разобранных путях вступления отсутствует. [Исходник](../Source/IntroUnpack/ScanAttributeCountTail.asm) · [Перенос экранного потока](IntroScreenResources.md)

Первый байт по входному HL получает L. Затем LDIR копирует семь байтов из входного HL во входной DE. Если DE=HL+1, только что записанный байт становится источником следующей итерации, поэтому по всем восьми адресам распространяется один исходный L.

Цикл читает 255 атрибутов #5800..#58FE. Три сдвига и маска 7 извлекают биты PAPER. Каждый результат записывается по #8157 в первоначальный bitmap. При исполнении перенесённой копии смещение INC (IX+0) по #74B3 не меняется. Поэтому все 255 инкрементов приходятся на первый байт счётчиков, независимо от прочитанных PAPER. После последней итерации по #8157 остаётся PAPER из #58FE.

Далее начальный байт по входному HL сравнивается с семью байтами от входного DE. Адрес заменяется только при строго большем значении, поэтому равные максимумы сохраняют первого кандидата. Из выбранного адреса вычитается входной HL по модулю 65536. Результат возвращается в HL. Его младший байт попадает в A, на шину данных и в старшие восемь битов адреса порта, младший байт адреса порта равен #FE.

В 1024 профилях [модель](../Tools/Disasm/Research/CheckIntroAttributeCountTail.py) сверила всю RAM, исходные записи в стеке, все записи PAPER, итоговые регистры и точную операцию OUT. Она исполнила исходный перенос и затем явно задала условный вход по #7497. Прежнее размещение этой последовательности, возможный штатный вызов и намерение автора относительно адреса #8157 остаются открытыми.
