# Исходная синусоида ACTION

[ActionSineTable](../Source/Action/Data/SineTable.asm) содержит 256 физических
экземпляров `FFixedSineValue`. Поле Value занимает один байт по смещению 0.
Оно хранится в дополнительном коде, диапазон фактических значений −127..127,
масштаб 128. Старший бит является частью знакового числа, не независимым флагом.

Байты находятся в записи 17 ACTION по смещениям 3900..39FF. Параметр
адреса этой CODE-записи равен 6000, поэтому таблица соответствует
RAM 9900..99FF. Загрузочный перенос ядра ограничен 6000..7F8E,
копирование контекста идёт в 9BBD..9DBC, построитель пиксельных таблиц
пишет 9400..97FF. Эти операции не заменяют исходную страницу 99.
Загрузочный путь описан в [StationExit.LoadAction](../Source/StationExit/LoadAction.asm)
и [ActionBoot.InitializeFlight](../Source/ActionBoot/InitializeFlight.asm).

| Индекс | Исходный байт | Знаковое значение | Доля полного периода |
| --- | --- | --- | --- |
| 00 | 00 | 0 | 0 |
| 40 | 7F | +127 | 1/4 |
| 80 | 00 | 0 | 1/2 |
| C0 | 81 | −127 | 3/4 |

Для каждого из 256 индексов исходный байт совпал с формулой
`CLAMP(ROUND(128*sin(2*pi*index/256)),-127,127)` в знаковом представлении.
Половина периода строго меняет знак, `table[(i+128) AND FF]=-table[i]`.
Сдвиг индекса на 40 даёт квадратурный коэффициент косинуса.
Совпадение формулы подтверждает значения таблицы и её использование,
но не доказывает способ первоначального создания авторских данных.

Сборка использует буквальные исходные значения, формула не запускается
для генерации новой таблицы. При разборе области ACTION 21CC..482C
выделены ровно 256 байтов. Предшествующие 5940 и последующие 3629 байтов
сохранены в отдельных неизвестных областях. Нули в них не объявлены
мусором или свободной памятью.

[UpdateBufferPoints](../Source/Controls/UpdateBufferPoints.asm) читает страницу 99
по индексу `(-TurnControl) AND FF` и тому же индексу со сдвигом 40.
Страница также читается в трёхмерном коде, например
[Action.UnknownC88C](../Source/Action/UnknownC88C.asm) и
[ThreeD.UnknownC88C](../Source/ThreeD/UnknownC88C.asm).
Полный смысл этих трёхмерных процедур отдельно не объявляется доказанным.

[Проверка и строгий разбор источника](../Tools/Disasm/Research/ActionSineTable.py)
сравнивают все физические значения, симметрию, структуру и адресные метки.
[Классификация](../Tools/Disasm/Reports/ActionSineTableClassification.json)
фиксирует сохранение байтов. В обычной сборке Python не нужен.

В [модели обновления точек](../Tools/Disasm/Research/CheckControlsPointMotion.py)
эта настоящая страница из ACTION дополнительно используется при всех
256 управляющих байтах и двух начальных R. Это проверка оригинальных
инструкций в заданной оснастке, не нативное исполнение всей игры.
