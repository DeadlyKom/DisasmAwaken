# Кодирование отношения двух разностей

[EncodeComponentDeltas](../Source/Action/EncodeComponentDeltas.asm)
занимает #AE15..#AE23. Это 15 исходных байтов перед
[EncodeSignedRatio](../Source/Action/EncodeSignedRatio.asm).
Дополнительного CALL либо JP между ними нет, продолжение
происходит последовательным исполнением по #AE24.

Первое вычитание с очищенным Carry вычисляет `HL−DE` по модулю
65536. EX DE,HL помещает результат в знаменатель. Второе
вычитание с отдельно очищенным Carry получает `HL'−BC` и
помещает результат в числитель HL. Переполнение знакового слова
не проверяется, исходное оборачивание сохраняется.

EXX нужен только для чтения двух байтов исходного HL'. Они
переносятся в основной HL через A и альтернативный AF, поэтому
все альтернативные HL', DE', BC' сохраняются. Последующий
EncodeSignedRatio перезаписывает AF' по собственному договору.
IX, IY, I/IM/IFF и paging сохраняются. BC после общего RET
равен первой разности, остальные основные результаты соответствуют
[точному кодированию](ActionSignedRatioCode.md) второй разности
относительно первой. Это не замена исходного алгоритма на atan2.

Подготовка не пишет память. Все шесть временных байтов стека и
самомодификация принадлежат продолжению и его настоящему делителю.
Возврат снимает внешний адрес входа AE15, отдельная рамка не создаётся.
Приращение R равно приращению дочернего пути плюс пятнадцать M1.

[Модель](../Tools/Disasm/Research/CheckActionDeltaRatio.py)
прошла 8192 сочетания четырёх слов. Исполнены реальное продолжение,
исходный делитель и таблица кодов. Сверены регистры, флаги и R,
все записи памяти и их последовательность в модели. Все совместные
значения четырёх слов, аппаратные шинные циклы, IRQ и нативный
запуск не проверены. Игровой вызывающий путь пока не найден,
поэтому назначение этого входа в игровом процессе не утверждается.
