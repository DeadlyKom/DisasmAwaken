# Обновление левого ребра заливки ACTION

[UpdatePolygonLeftEdge](../Source/Action/UpdatePolygonLeftEdge.asm) занимает D272..D3A7 банка 0. Вход D задаёт текущую строку. LeftCursor указывает исходную First в кольце страницы 90. Код читает её Second один раз, затем ищет назад первую вершину с First строго больше D. Пропущенные равные или меньшие строки не меняют исходную Second. При начале страницы используется последний нечётный индекс кольца.

Высота h равна First конца минус D, dx равен Second конца минус первоначальная Second. Для abs(dx)>=h работает развёрнутый восьмиразрядный делитель, получающий дополненное частное и остаток. Целый горизонтальный шаг равен ceil(dx/h), при dx=0 исходный код использует +1 с компенсирующей дробной поправкой. Альтернативный BC хранит 2000+32×шаг, L' хранит floor(h/2). Для dx<0 вычитаемая ошибка равна abs(dx) MOD h. Для неотрицательного точного длинного наклона она равна нулю, в остальных неотрицательных случаях h−(dx MOD h).

BC и основной D сохраняются. E содержит исходную Second короткой ветви либо дополненное частное длинной. H сохраняет страницу масок, L получает RightEndRow. A содержит D, F получается сравнением D с RightEndRow. Если D меньше правого предела, управление идёт в [SelectPolygonRowLimit](ActionPolygonRowSelection.md). Иначе RowLimit получает правый предел, RowBranch=3B, а продолжение по D229 запрашивает подготовку правого ребра.

Основные AF здесь не сохраняются отдельным PUSH, это существенное отличие от похожего обновления в предпросмотре. Используются только два байта существующего временного стека под FFE0, куда сохраняются исходный H и текущий D. SP восстанавливается, обычного RET нет. Альтернативные H', DE', AF', IX/IY и I/IM/IFF/paging сохраняются.

[Проверка](../Tools/Disasm/Research/CheckActionPolygonEdges.py) содержит 48545 сценариев левой цепочки из общей серии 97090. [Отдельный реестр](../Tools/Disasm/Reports/ActionPolygonLeftEdgeVerification.json) ссылается на полную серию. Проверены все высоты 1..95 и наклоны −255..255, пропуски 0..58 вершин, кольца 3..60 вершин, оборачивание и оба выхода проверки готовности правой цепочки. Сверены регистры кроме R, все физические банки и кратность записей. Все сочетания произвольных колец, строковое ядро целиком, R/T, IRQ, сборка и нативное исполнение не доказаны. [Весь алгоритм заливки](ActionPolygonFill.md) описан отдельно.
