# Переключение режима проецируемого тела

В [фрагменте 6727](../Source/Action/TransitionBodyMode.asm) три входа.

- `#6727` возвращается сразу при `FirstMode = 2`. Иначе выставляет режим 1,
  перезаписывает поток 14 состоянием `#1527/#13`, ставит `Compare06A = #FF`
  и продолжает с `#6742`.
- `#6742` делает один шаг [потока 14](ActionFoldedRandom.md). Только слово
  `#8746` меняет режим на 2 и записывает `#6000` в три старших слова
  рабочего вектора по `#9B70`, `#9B73` и `#9B76`. При любом слове
  управление передаётся по `#688A` в [соседний обработчик](../Source/Action/UpdateBodyMotion.asm).
- `#6765` вычитает `#0030` из каждого из тех же трёх слов по модулю
  65536. Младшие байты 24-битных компонент не затрагиваются. Продолжение
  по `#679B` выполняет отдельное смещение всего вектора.

При последовательном продвижении потока без повторных сбросов первое
слово `#8746` после начальной пары `#1527/#13` получается на 41862-м
вызове. Это число шагов генератора, период кадров из него не выводится.

[Модель](../Tools/Disasm/Research/CheckActionBodyModeTransition.py) в 66816 сценариях сверяет
адрес выхода, SP и всё окно памяти, включая новое состояние генератора
и временные байты стека. Проверка завершается до исполнения `#688A`
или `#679B`. Хвост [688A](ActionWideMotionPrefix.md) проверен отдельной моделью.
Вычитание от `#679B` и последующее обновление панели проверены
отдельными моделями на границах, описанных в документе о хвосте.
