# Выбор страниц в ENGINE

При старте режим из `#5F5E` индексирует три слова по `#5018`.
Выбранное слово становится операндом `JP` по `#4FB6`. Общий вход
по `#4FB1` сохраняет исходный код страницы по `#5012`, кладёт BC
на стек и передаёт управление выбранной ветви. Каждая ветвь снимает
BC перед возвратом. [Общий вход](../Source/ArchiveEngine/SelectPage.asm)
· [Физические поля и таблицы](../Source/ArchiveEngine/Data/Paging.asm)

Для `p` обозначим `lo = #18 OR (p AND #07)` и `ext = p AND #08`.

| Режим | Исходные записи портов в порядке исполнения | A на возврате |
| --- | --- | --- |
| [Pentagon](../Source/ArchiveEngine/SelectPentagonPage.asm) | `#7FFD ← lo OR (ext << 3)` | Значение `#7FFD` |
| [Scorpion](../Source/ArchiveEngine/SelectScorpionPage.asm) | `#1FFD ← ext << 1`, `#7FFD ← lo` | Значение `#7FFD` |
| [ATM-2](../Source/ArchiveEngine/SelectAtmPage.asm) | `#7FFD ← lo`, `#FFF7 ← (NOT p) OR #C0` | Значение `#FFF7` |

Pentagon и Scorpion возвращают флаги последнего `OR`. У ATM-2
после записи `#7FFD` восстанавливается исходный AF, затем `CPL`
формирует флаги. Две команды `SET` их сохраняют. Для последнего
вывода переходник кладёт `#2A53` на стек и переходит к `#3D2F`.
В ROM TR-DOS там исполняются `NOP` и `RET`. Этот `RET` выбирает
подложенный адрес, а `OUT (C), A` и следующий `RET` возвращают
управление в ветвь ATM-2. [Вывод через ROM](../Source/ArchiveEngine/OutputThroughDos.asm)

Индекс файла `BD0`–`BD3` преобразуется через четыре байта по `#5014`
в логический код 8–11. При вызове из IRQ поле `#5013` временно
хранит страницу прерванного кадра на время вывода индикаторов.
[Селектор BD](../Source/ArchiveEngine/SelectSpritePage.asm)
· [Обработчик IRQ](ArchiveEngineStartup.md#прерывание)

В модели проверены 3072 вызова общего входа, все 256 входных байтов
с четырьмя наборами флагов в каждом режиме, и 48 вызовов входа BD.
Сверены записи портов, итоговый AF, сохранение остальных регистров,
стек и содержимое поля `#5012`. Ветка ATM-2 исполняет исходные
инструкции ROM 5.04T. Прогоны Scorpion и ATM-2 фиксируют операции
портов, физическая разводка банков этих машин здесь не проверяется.

## Страницы основного цикла и загрузчика

У общего входа по `#4FB1` 13 прямых вызовов. Одиннадцать загружают
константу 0, 7, 13 или 14. Вызов из `SelectSpritePage` читает код
8..11 по индексу BD. Загрузчик перебирает четыре индекса, а 204
физических шага BAR содержат только индексы 0..3. В исходных
заголовках групп каждый индекс повтора укладывается в число кадров,
каждый номер перехода указывает в таблицу действий.

Последний вызов общего входа восстанавливает код прерванного кадра
из `#5013`. Обработчик IRQ сохраняет туда значение `#5012`,
которое записывает сам селектор. Поэтому восстановление использует
тот же набор кодов 0, 7, 8..11, 13 и 14.

В каждой из трёх моделей выполнены 64 перехода между кодами из этого
набора и первый выбор страницы 7 из каждого из 16 исходных состояний.
Проверено окно после каждой отдельной записи в порт. Scorpion и ATM-2
могут промежуточно показать страницу 15. Страница 12 в этих переходах
не выбирается. Границы результата задают исходный загрузчик и цикл
ENGINE с корректными шагами BAR. Отдельный вход с передачей управления
по `#5C26` остаётся открытым.
