# Возврат от арифметического SP при подготовке тела

Подготовитель 6A6E копирует девять байтов по 9B6F..9B77 в три записи
компонент проекции. Он передаёт старшие слова в операнды AF48, AF56 и
AF69, обнуляет младшие байты компонент и сохраняет настоящий SP по
6AAE. IY получает 6AAD. Передача в AF43 выполняется через JP.
[Подготовитель](../Source/Action/PrepareBodyTransform.asm).

AF43 использует SP как промежуточный арифметический накопитель и
передаёт управление через IY после обычного расчёта либо переполнения.
По 6AAD исходные байты `31 00 00` образуют LD SP,nn. Изменяемый
операнд восстанавливает настоящий CPU-стек без изменения флагов.
Следом исполняется проверка P/V по 6AB0. Порядок двух файлов обязателен.
[Восстановление SP](../Source/Action/RestoreBodyStack.asm).

Модель проверила 8 846 проходов до начала 6AB0, включая все шесть мест
переполнения. Сверены регистры, R, SP, физическая RAM и кратность
записей. До 6AB0 записей по CPU-стеку нет. Проверка заканчивается
перед обработкой выходных компонент и рисованием.
[Отчёт](../Tools/Disasm/Reports/ActionPrepareBodyTransformVerification.json).
