# Оборачивание обратного поиска к последней First кольца

[WrapPolygonLeftEdge](../Source/Action/WrapPolygonLeftEdge.asm) содержит исходные байты D26B..D271 банка 0. Полный регистровый договор и условия временного стека приведены в исходнике. Это переходник [линейной заливки](ActionPolygonFill.md), его назначение ограничено переносом индекса либо восстановлением контекста.

[Проверка](../Tools/Disasm/Research/CheckActionPolygonBridges.py) прошла 65536 сценариев, [отчёт](../Tools/Disasm/Reports/ActionPolygonWrapLeftVerification.json). Сверены регистры кроме R и отсутствие записей RAM. Для оборачивания левого индекса исчерпаны все байты индекса и флагов, для верхней левой обёртки все альтернативные A и основные F. Расширенные байты локальной проверки не объявляются штатными игровыми индексами. Сборка, IRQ и нативное исполнение не выполнялись.
