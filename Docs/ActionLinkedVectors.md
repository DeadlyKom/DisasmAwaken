# Два трёхсловных набора связанной записи

[LoadLinkedRecordVectors](../Source/Action/LoadLinkedRecordVectors.asm)
занимает E794..E803 ACTION банка 0. Начальный LD IY,nn читает адрес,
записанный [PrepareLinkedRecordContext](ActionLinkedContext.md) в E796.
Исходный нулевой операнд сохраняется, прямой обычный вход без
предварительной подготовки адреса не объявляется допустимым.

Связь LinkedIndex=1A игнорирует этот адрес. Input0..2 и Output0
получают ноль, Output1 получает FFB0, Output2 получает FFFF,
IY становится A780. HL=FFB0, DE=FFFF, BC=0000, AF=1A18.
Точные значения сохранены, их физические единицы не выдумываются.

Для остальных связей проверяется полный байт **Unknown1B** выбранного IY.
Это старший байт слова по 1A, а не Component0.High по 01. Значение 80
возвращает AF=8041, не меняя HL, DE, BC и прежние Input0..2/Output0..2.
На обычном успехе Carry очищается через AND A, затем Input0..2 получают
Components выбранной записи, Output0..2 получают слова по 1A, 1C, 1E.
Три слова второго набора участвуют в последующем расчёте, но их полное
игровое назначение пока не установлено, физические имена Unknown сохраняются.

Input0..2 являются существующими операндами
[ComputePatchedVector](ActionPatchedVector.md) в общей RAM банка 2.
По шести писателям, трём нулевым и трём обычным, зарегистрирована
[самомодификация](ModifiedCode.md). Output0..2 по D9B6, D7C4, D7A2
относятся к текущему контексту ACTION банка 0, совпадение числового
адреса с кодом иного банка не делает эту запись изменением того кода.

На обычном успехе HL=Output1, DE=Output2, BC=Output0, A равен Unknown1B,
F соответствует AND A. HL', DE', BC', AF', IX, I, IM, IFF и paging
сохраняются, SP после RET увеличен на два, записей CPU-стека нет.
R добавляет 24 M1 при связи 1A, 11 при отказе и 44 при обычном
копировании. Бит 7 R сохраняется, точные T не измерялись.

[Независимая модель](../Tools/Disasm/Research/CheckActionLinkedVectors.py)
проверила 394240 сценариев, все 65536 значений каждого из шести слов,
все 256 адресных индексов и все 256 кодов текущей связи. Подготовленный
операнд меняется в тестовой RAM явно, за исходным массивом читаются
оригинальные байты. Сверены точные регистры, флаги, R, SP, восемь банков
и кратность всех записей. Последующий преобразователь, полное
произведение входов, IRQ, сборка и нативный запуск не исполнялись.
