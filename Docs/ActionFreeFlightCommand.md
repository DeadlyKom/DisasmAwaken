# Команда свободного полёта

[ToggleFreeFlightMode](../Source/Action/ToggleFreeFlightMode.asm), исходные 754C..7593 переносимого ядра ACTION банка 5, является целью Index10 [таблицы клавиш](../Source/Action/Data/KeyHandlerPointers.asm). Команда меняет один существующий опкод 6E72 в [UpdateMotionFromControls](../Source/Action/UpdateMotionFromControls.asm), исходное размещение не меняется.

Ненулевой CommandDelay даёт немедленный возврат без записей. При нуле задержка получает 20, затем проверяется полный код FreeFlight.Value по 9C28. FF означает отсутствие оборудования и завершает обработку, сохраняя уже установленную задержку. Следующая проверка требует точного равенства LimitWord по 7693 значению 0088. Это изменяемый операнд ограничителя [IncreaseGaugeWord](../Source/Action/IncreaseGaugeWord.asm), не само значение SignedWord шестой шкалы.

При другом ограничителе возвращаются HL=(LimitWord−0088) AND FFFF, BC=0088, A=(FreeFlight.Value+1) AND FF. F соответствует SBC с нулевым входным Carry. DE сохраняется, звуковой поток и опкод не меняются. Проверка равенства не заменена знаковой проверкой или условием неподвижности корабля.

После полного допуска CursorA банка 0 получает исходный поток EDA8. Если MotionOpcode равен 3A, команда передаёт F1E1, сообщение о включении, и записывает C9. Иначе она передаёт F1F0, сообщение о выключении, и записывает 3A. Таким образом, это проверка одного точного опкода, любой иной исходный байт восстанавливается в 3A. Следующие два байта исходной инструкции не меняются. Затем независимо передаётся F200, название свободного полёта.

Опкод 3A означает LD A,(nn) в ScaleMotion по 6E72. C9 означает RET. При таком RET завершается только часть UpdateMotionFromControls начиная с ScaleMotion. Предшествующие вызовы StepNearZeroWord и ScanActionKeys уже выполнены. Весь игровой кадр или вся обработка клавиатуры этой заменой не отключаются. Имена и назначение оборудования отдельно сверены с [авторской раскладкой](ActionEquipmentCodes.md).

На принятом пути HL=EDA8, BC=0088, DE сохранён, A равен записанному опкоду. F остаётся результатом CP исходного опкода с 3A, а не проверкой нового значения. Альтернативные регистры, IX/IY, I, IM и IFF сохраняются. Две обёртки очереди дают OUT 7FFD в порядке 11,10,11,10, итоговая конфигурация 10. Записи могут быть приняты частично, отмены изменения опкода нет. SP после RET равен исходному SP+2, максимальная дополнительная глубина стека восемнадцать байтов.

[Модель команд](../Tools/Disasm/Research/CheckActionTargetCommands.py) с аргументом `--free-flight` исполняет исходную команду, настоящий селектор банков и производитель очереди. [66576 сценариев](../Tools/Disasm/Reports/ActionFreeFlightCommandVerification.json) включают все 65536 значений ограничителя, все 256 задержек, все 256 кодов оборудования, все 256 исходных опкодов и граничные состояния кольцевой очереди. Произвольный опкод здесь только читается командой, его дальнейшее исполнение не проверяется.

Сверены архитектурные регистры кроме R и тактов, вся физическая RAM вне восемнадцати временных байтов стека, точный порядок OUT. Остаточные слова временного стека, IRQ, дальнейшее движение, нативные изображение и звук не проверялись. На входе выбран банк 0, paging разблокирован. Ассемблер не запускался.

[Факты, договоры и оформление](../Tools/Disasm/Research/ActionFreeFlightCommandFacts.py) используются [издателем команд](../Tools/Disasm/Research/PublishActionTargetCommands.py), исследовательский Python для обычной сборки не требуется.
