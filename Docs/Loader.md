# Первый вход загрузчика

[ReadIntroSectors](../Source/Basic/ReadIntroSectors.asm) находится в
первой записи AWAKEN, исходный код занимает файловые байты `#0006..#001D`
и исполняется с `#5CD1`. Его контракт установлен до передачи управления
TR-DOS, без предположений о сохраняемых регистрах конкретного ROM.

DI запрещает прерывания. SP заменяется исходным значением `#5FFF`,
IY получает `#5C3A`. Прежний стек вызывающего BASIC-кода больше не используется.
На новый стек помещается адрес `Intro.InitializeIntro.Entry = #6500`,
а DEC H уменьшает адрес чтения до `#6400`.

Перед JP в TR-DOS `#3D13` регистры имеют следующие значения:

| Значение | Состояние |
| --- | --- |
| HL | #6400, начало чтения вступления |
| DE | слово из LoaderState.NextIntroBlock по #5CF4 |
| BC | #2C05, 44 физических сектора и номер функции чтения |
| AF | входной A, F=#22 плюс входной Carry после DEC H |
| IY | #5C3A |
| SP | #5FFD, на вершине слово #6500 |

Сам загрузчик не меняет IX, альтернативные регистры, I и IM.
Дальнейшие эффекты ROM TR-DOS в этот контракт не включаются.
После чтения ожидается возврат дисковой системы на #6500. Отдельной
проверки ошибки в этих 24 байтах нет.

[CheckBasicLoader.py](../Tools/Disasm/Research/CheckBasicLoader.py)
подтвердил состояние интерфейса на 5120 сочетаниях, включая все входные F.
Проверка останавливается перед первой инструкцией TR-DOS, поэтому она
не подтверждает само дисковое чтение или запуск игры.
Результат — [BasicLoaderVerification.json](../Tools/Disasm/Reports/BasicLoaderVerification.json).
