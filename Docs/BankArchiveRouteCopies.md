# Копии маршрутов кадров внутри BANK

Во внекаталожном блоке по физическому смещению 9406F лежат двенадцать
50-байтовых маршрутов. При подключении этого блока в окно C000 первый
маршрут имеет адрес DE6F. [Исходный потребитель](BankStripArchiveConsumer.md)
копирует целую запись в рабочую RAM. Первый байт выбирает BANK, второй
задаёт число кадров. Следуют два списка по двенадцать слов. Первый
выбирает полосы для вывода через буфер в страницу 7, второй — полосы
прямого вывода в основной экран.

Четыре исходных файла BANK содержат копии начала этой таблицы по
одинаковому файловому смещению 1E12. В каждом случае последовательность
заканчивается перед первой архивной записью маршрута собственного BANK.

| Файл | Копий | Байтов | Конец диапазона, не включён |
|---|---:|---:|---|
| [BANK1](../Source/Resources/34_BANK1/ArchiveRouteCopies.asm) | 2 | 100 | 1E76 |
| [BANK2](../Source/Resources/35_BANK2/ArchiveRouteCopies.asm) | 4 | 200 | 1EDA |
| [BANK4](../Source/Resources/37_BANK4/ArchiveRouteCopies.asm) | 8 | 400 | 1FA2 |
| [BANK5](../Source/Resources/38_BANK5/ArchiveRouteCopies.asm) | 10 | 500 | 2006 |

Во всех 24 экземплярах FArchiveBankStripRoute сверены исходные байты,
позиции полей, число кадров и нули за используемой частью обоих списков.
Метки показывают смещения внутри BANK. Слова указателей сохраняют
исходные значения в окне C000 того файла, на который указывает BankIndex.

Граница установлена по целым записям и точному совпадению с исходным
внекаталожным блоком. Код, который мог бы читать копии из промежутков BANK,
пока не найден. Соседние совпадающие байты остаются отдельными
фрагментами с неизвестным назначением.
[Проверка байтов и размеров](../Tools/Disasm/Reports/BankArchiveRouteCopiesClassification.json).
