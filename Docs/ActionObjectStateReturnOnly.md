# Пустой вход после таблицы состояний

[ReturnFromObjectState](../Source/Action/ReturnFromObjectState.asm)
по `#EF7C` исполняет один `RET`. Он снимает адрес продолжения с
CPU-стека. Флаги и данные объекта сохраняются. R получает один M1.

В `BRAINPRO.a` после 22 слов `ITAB` стоит самостоятельный `RET`
с меткой `NTH`. В архивном `SP.C` из `awk5.trd` он находится по
`#EF8D`, а последнее слово таблицы заканчивается прямо перед ним.
Следующие два обработчика и их указатели совпадают по порядку с ACTION,
адреса и внешние переходы изменились. Это связывает исходный `#C9`
в Awakenv02 с машинной командой из авторского исходника.
[Авторский архив](https://opensourcezx.untergrund.net/a_games-awaken_src.html)

[Диспетчер](ActionObjectStateDispatch.md) читает указатели из `#EF50`
по удвоенному байтовому коду. При подставленных `#16` и `#96`
он читает из `#EF7C` младший `#C9`, из `#EF7D` старший `#DD`
и переходит на `#DDC9`. Штатная передача управления по `#EF7C`
пока не установлена.

В 256 прямых входах исходный `RET` сверялся с адресом продолжения,
SP, остальными регистрами, флагами и отсутствием записей в память.
Ещё два прогона остановлены на цели исходного диспетчера.
