# Символ и обозначение клавиши

[DrawKeyLabel](../Source/Station/DrawKeyLabel.asm), BDF0..BE1A фиксированного банка 2, принимает код в A. При A>=21 вызывает DrawGlyph один раз. При A<21 вычисляет `offset=((A-1E)*4)&FF`, берёт четыре последовательных байта от BE1B+offset и вызывает DrawGlyph для каждого. После отказа одного глифа остальные вызовы всё равно выполняются, итоговый AF принадлежит четвёртому. Это не PrintText, CR/LF и другие коды здесь не обрабатываются как потоковые команды.

[Физические записи KeyAbbreviations](../Source/Station/Data/KeyAbbreviations.asm) занимают ровно BE1B..BE26, исходные 12 байтов представлены тремя экземплярами FKeyAbbreviation с полями Glyph0..Glyph3. Код 1E даёт `ENT `, Enter, код 1F даёт `SS  `, Symbol Shift, код 20 даёт `SP  `, Space. Соответствие кодов проверяется по исходной [таблице матрицы клавиатуры](../Source/Station/Data/KeyboardCodes.asm). Пробелы являются настоящими четвёртыми символами, каждый вызывает DrawGlyph и двигает курсор при принятой ширине.

Для A<1E смещение заворачивается в байте. Код не проверяет принадлежность адреса трём записям и может интерпретировать соседние данные и инструкции как четыре глифа. Эта особенность сохранена, соседние области не объявлены частью таблицы или мусором.

HL, DE, BC, альтернативные и индексные регистры, I, IM и IFF сохраняются. SP после RET равен входному+2. Основной AF содержит статус единственного либо последнего DrawGlyph по его [договору](GlyphRendering.md). CursorX, bitmap и изменяемый GlyphState.DispatchTarget меняются согласно принятым глифам, CursorY не меняется. При нескольких отказах не возвращается агрегированный статус.

[CheckKeyLabel](../Tools/Disasm/Research/CheckKeyLabel.py) проверяет все 256 входных кодов в десяти геометриях, всего 2560 случаев. Независимо рассчитываются байтовый индекс, последовательность вызовов, каждый отказ, курсор и XOR всех пикселей с сохранением атрибутов. Включены строгая граница ширины, переполнение X, малая высота, нижняя физическая граница, положительный старший байт и отрицательные начала X/Y. [Отчёт](../Tools/Disasm/Reports/KeyLabelVerification.json) подтверждает весь регистровый контекст и выполнение всех четырёх вызовов даже после отказа. Сборка, IRQ и нативный запуск не выполнялись.
