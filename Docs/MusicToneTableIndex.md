# Номер частотной таблицы композиции

Поле `FMusicModuleHeader.ToneTableIndex` занимает байт 99 заголовка.
В [исходном Antichrist](../Source/Music/Composition/Header.asm) по `#E763`
сохранено `#02`. В [описании формата PT3](https://groups.google.com/g/fido7.zx.spectrum/c/StZ1c9uHVnc/m/cVQD3SrNZ80J)
этот номер обозначает таблицу ASM/PSC.

Название поля подтверждено также самими байтами. Все 96 слов
[MusicPeriods](../Source/Music/Data/Periods.asm) по `#DD00..#DDBF`
совпадают с константой PT3NoteTable_ASM из
[исходников Vortex Tracker II](https://github.com/oisee/vti/blob/master/trfuncs.pas).
Смещение этой таблицы от входа проигрывателя `#DB00` равно 512,
как для встроенной таблицы скомпилированного PT3.

[InitializeModule](../Source/Music/InitializeModule.asm) начинает
чтение с темпа по смещению 100. Номер таблицы не используется
для её выбора этим входом, уже встроенные периоды сохраняются.
Переименование описывает метаданные формата, новое переключение
таблиц в проигрыватель не добавляется.

[Проверка](../Tools/Disasm/Research/CheckMusicToneTableIndex.py)
сравнивает все 192 байта периодов и изменяет поле по `#E763`
на каждое значение 0..255 при исходном модуле. Результат инициализации
совпадает по всем регистрам, R/T, всей RAM кроме подставленного байта,
последовательности записей и выходам AY.
[Отчёт](../Tools/Disasm/Reports/MusicToneTableIndexVerification.json).

Тест касается инициализации исходного модуля. Произвольные композиции,
аппаратные IRQ и нативный звук этой проверкой не подтверждаются.
