# Загрузка станции с восстановлением состояния

[LoadStationStateRelay](../Source/Controls/LoadStationStateRelay.asm) исполняется по 4200..4230, 49 байтов. Источник находится по DD23..DD53 банка 1, физические смещения CONTROL 0245..0275. Ключ STATIONFC следует по 4231..4239. [PrepareStationReload](../Source/Controls/PrepareStationReload.asm) сохраняет 512 байтов состояния в 4000..41FF, предварительно меняет порядок LowPairs и копирует 256 байтов следующей стадии в 4200. [Факты и договор](../Tools/Disasm/Research/ControlsStateStationRelayFacts.py), [проверка](../Tools/Disasm/Research/CheckControlsStationReloadRelays.py).

OUT 7FFD получает 18, выбирая банк 0 и теневой экран. IY получает 5C3A. Стадия до вызова не устанавливает I, IM и IFF, эти условия обеспечивает родитель. Девятибайтовый ключ из копии переносится в 5CDD, байт диска 5CF9 обнуляется. CALL 3D13 передаёт C=0E и сохраняет локальный адрес 421F на текущем CPU-стеке.

На границе дискового вызова HL=423A, DE=5CE6, BC=000E, AF=0044, SP уменьшен на два, IX, I, IM и IFF сохраняются. Исходный код не проверяет результат TR-DOS. Поэтому AfterLoad по 421F описан при отдельном условии успешной внешней загрузки STATIONF по 6000 с сохранением копии и буфера. Это условие явно задаётся исследовательской моделью, работа дисковой службы не подменяется утверждением об успешном игровом запуске.

После возврата DI сбрасывает IFF. Восстанавливаются ровно 481 байт из 4000..41E0 в 983B..9A1B состояния свежей станции. Последние 31 байт сохранённого родителем 512-байтового блока не копируются. SP получает 5FFF, JP 6300 передаёт управление [StationBoot.RelocateBootstrap](../Source/StationBoot/RelocateBootstrap.asm) свежезагруженного STATIONF.

На конечной границе HL=41E1, DE=9A1C, BC=0. A сохраняет внешний результат TR-DOS. F получает недокументированные биты по последнему LDIR с сохранением S/Z/Carry. IX/IY, I, IM, альтернативные регистры и paging после TR-DOS сохраняют его внешнее значение. Старый адрес возврата не используется.

Общая серия двух стадий содержит 768 проверок. Для этого входа 256 профилей доходят до реальной границы TR-DOS и 256 проверяют условное успешное продолжение с явно подставленным исходным STATIONF. Сопоставлены восемь банков RAM и кратность записей, основные и сохраняемые регистры, I, IM, IFF и SP. Полные R, такты и конечный F в этой серии не сверялись. TR-DOS, его ошибочный возврат, IRQ, сборка и нативная игра не исполнялись.

Ключ оформлен реальным [экземпляром FTrDosFileKey](../Source/Controls/Data/StateStationKey.asm), все девять байтов и рабочий адрес проверены [физическим разбором](../Tools/Disasm/Research/ControlsStationRelayFileKeys.py).
