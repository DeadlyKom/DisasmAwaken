# Умножитель координаты D3D

[MultiplyPreviewCoordinate](../Source/D3D/MultiplyPreviewCoordinate.asm) занимает #EB10..#EB7D банка 4, 110 исходных байтов и 79 инструкций. Функция участвует в преобразовании трёх координат. Договор локального алгоритма установлен отдельно от полного кадра.

## Вход и продолжение

Основной DE содержит адрес продолжения. Знаковая 16-битная координата находится в альтернативном DE', знаковый коэффициент в A. При входе адрес DE записывается в существующий операнд PreviewMultiplyState.ReturnTarget по #EB7C. Затем EXX выбирает координату и одновременно сохраняет основные HL, DE и BC в альтернативном наборе.

Процедура не использует CPU-стек, не кладёт и не снимает адрес возврата. Завершающий JP #0000 исполняется с записанным операндом, SP остаётся входным. Подмена его на RET нарушила бы договор. Повторный вход до завершающего JP не допускается, в том числе из прерывания.

## Алгоритм

Знаковый байт вычисляется как коэффициент XOR старший байт исходной координаты. Он и его логические флаги сохраняются в AF'. Отрицательная координата преобразуется в беззнаковый модуль, включая модуль #8000 для исходного -32768. Отрицательный коэффициент также преобразуется в модуль.

Развёрнутый цикл обрабатывает семь значащих разрядов коэффициента. HL содержит младшую 16-битную часть накопителя, A верхнюю часть. При единичном разряде прибавляется модуль координаты, ADC A,0 переносит переполнение в верхнюю часть. Сдвиг накопителя выполняется ADD HL,HL и ADC A,A. В конце средний и старший байты выбираются как результат деления модуля произведения на 128.

Только после усечения применяется знак. Для штатного коэффициента -127..127 результат равен sign(x·k)·floor(abs(x·k)/128). Это усечение к нулю. Например, -1·1 даёт 0, а -129·1 даёт -1. Математический floor отрицательного произведения дал бы другие значения.

Коэффициент #80 нештатный. NEG оставляет его модуль #80, развёрнутый семибитный цикл возвращает нулевой модуль. Поведение сохранено и проверено. Вход ядра по #EC28 предварительно заменяет #80 на #81 в матричных коэффициентах, сам умножитель этого не делает.

## Выходной контекст

HL содержит знаковый результат. При неотрицательном знаке DE остаётся модулем исходной координаты, при отрицательном DE содержит модуль усечённого произведения. B равен входному B', C=0. A содержит знаковый байт коэффициент XOR исходный старший байт координаты.

При неотрицательном знаке F соответствует XOR знакового байта и не описывает арифметический результат HL. При отрицательном F получается от SBC HL,DE при HL=0 и Carry=0. В частности, Carry=1 только при ненулевом модуле. Это существенно для следующих ADC в вызывающем преобразовании.

HL', DE' и BC' содержат исходные основные HL, DE и BC. A' является старшим байтом модуля результата, F' принадлежит последнему ADC верхнего аккумулятора, для нулевого коэффициента последнему ADD. Если p=abs(x·k), q=p SHR 15, то A'=q. Для штатных коэффициентов S, P/V, N и C в F' равны нулю, Z установлен при q=0, разряды 5 и 3 взяты из q, H соответствует переносу младшей тетрады при удвоении p SHR 16 с добавлением разряда 15 числа p.

IX, IY, I, IFF и IM сохраняются. Единственная собственная запись памяти — два байта ReturnTarget. Аппаратный R меняется при выборках инструкций и не включён в сохраняемый контекст.

## Проверка и физическая разметка

[CheckPreviewCoordinateMultiply](../Tools/Disasm/Research/CheckPreviewCoordinateMultiply.py) проверил 376832 случая. Для коэффициентов -127, -1, 0, 1, 127 охвачены все 65536 координат. Для всех 256 байтов коэффициента дополнительно проверены наборы старших байтов и младших границ. Независимая целочисленная формула сопоставлена с HL, DE, BC, обоими AF, альтернативным и индексным контекстом, SP и точным списком двух записанных байтов. [Отчёт](../Tools/Disasm/Reports/PreviewCoordinateMultiplyVerification.json).

[ClassifyPreviewMultiply](../Tools/Disasm/Research/ClassifyPreviewMultiply.py) выделил исходник только из прежней бинарной области, подготовил отдельный кандидат, сверил текущие файлы и сохранил историю. Диапазоны до и после функции остаются исходными бинарными данными с прежним порядком. Удалена только заменённая бинарная копия после проверки её сохранённой версии и всех активных байтов. [Отчёт выделения](../Tools/Disasm/Reports/PreviewMultiplyClassification.json).

Вызывающее преобразование трёх координат разобрано отдельно в [PreviewTransform](PreviewTransform.md). Это проверка исходных инструкций и локального математического договора без сборки, аппаратных IRQ и нативного игрового запуска. Более широкий контекст приведён в [D3DRuntimeFlow](D3DRuntimeFlow.md).
