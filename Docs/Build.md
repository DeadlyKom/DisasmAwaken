# Сборка и физическое восстановление диска

Основной образец структуры — DisasmElite,
дополнительный образец оформления — HoMM.
Эти проекты только читались.

Главный файл `Builder/Main.asm` собирает все 41 действующие дисковые области.
Каждая собирается с `ORG 0`, это буфер ассемблера для одного файла,
а не новое размещение игры. `DISP` задаёт исходный исполняемый адрес
фрагмента, `ENT` возвращает физический счётчик. Длины проверяются через
`ASSERT` перед фрагментами и в конце каждой области.

`EMPTYTRD` создаёт носитель средствами SjASMPlus. Встроенный Lua третьего
прохода размещает служебные, удалённые и свободные компоненты. Действующие
области сначала сохраняются командами `SAVETRD`, затем Lua читает их из
этого результата текущей сборки. Оригинальный TRD используется исключительно для сравнения
готового результата. Подстановки целых действующих программ из оригинала нет.

Записываются все выделенные сектора, включая хвосты. Каталог сохраняет
исходные логические длины, расширения и физические размещения. Упаковщик
проверяет границы, пересечения, число областей, полное покрытие и каждый
байт результата. Отчёт запуска — `Tools/Disasm/Reports/BuildVerification.json`.
Существующий отчёт относится к предыдущей сборке. После текущих изменений
новая сборка не запускалась, её выполняет пользователь.

Из корня проекта:

```powershell
.\Tools\Sjasmplus\sjasmplus.exe --nologo --fullpath=rel --lst=Tmp/Awaken.lst --sym=Tmp/Awaken.sym --sld=Tmp/Awaken.sld Builder/Main.asm
```

Результат — `Awakenv02.trd`. В `Tmp` сохраняются листинг, символы и SLD.
Python, SkoolKit и исследовательские экспортёры сборкой не запускаются.

`Tools/Disasm/VerifyBuild.py` отдельно сравнивает существующий TRD с оригиналом,
вычисляет SHA-256 и проверяет 44 выделенные области, ассемблер не запускает.
Отчёт — `Tools/Disasm/Reports/ImageVerification.json`. Совпадение существующего
образа отдельно от сборки не доказывает компилируемость изменённых исходников.

Для намеренного изменения игры потребуется отдельно пересмотреть критерий
сравнения. Сейчас любое отличие от исходного образа считается ошибкой.
