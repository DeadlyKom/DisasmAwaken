# Взвешенная байтовая загрузка

[ComputeWeightedLoad](../Source/Text/ComputeWeightedLoad.asm), LANG #C86F..#C8FF, суммирует три набора и необязательное дополнительное поле. Доказана формула исходного кода. Игровые единицы результата и полный смысл второго и третьего наборов пока не установлены, имя отражает взвешенную сумму, а не доказанную физическую массу.

Для первых 30 двухбайтовых строк по #9852 выбирается младший байт без bit7. Если адрес строки равен (#9852+2*входнойHL) AND FFFF, к количеству прибавляется единица до масштабирования. Входной HL не обрезается до байта. Коды по #94FA задают масштаб, код 0 и 81..FF сохраняют количество, код 1 даёт целую шестнадцатую часть, коды 2..80 обнуляют вклад. Это точный эффект DEC B и JP M, а не предположение о допустимых кодах. При выбранном количестве 127 получается 128, до деления это значение не маскируется повторно.

Следующие 30 вкладов используют множители из каждого второго байта начиная с #95F1 и веса из последовательных байтов #988E. Последние 14 вкладов используют множители из каждого второго байта #9633 и последовательные веса #98F6. Для веса w с bit7=0 используется w, иначе w XOR FF. Это дополнение до 255, не модуль отрицательного числа, например FF даёт 0, а 80 даёт 127. Произведение вычисляется повторным ADD и DJNZ. Нулевой множитель выполняет 256 сложений и всё равно даёт ноль по модулю 256.

Накопитель C оборачивается после каждого сложения. Если #984A=FF, дополнительное слагаемое равно нулю. Иначе смещение определяется как (ROL8(код,2)+код) AND FF, затем читается байт по #9829+смещение. Для кодов со старшими разрядами это отличается от умножения на пять. Итог A=(C+дополнительное слагаемое) AND FF, F соответствует этому ADD A,C.

Три исходных операнда изменяются непосредственно в коде, SelectedRow по #C884 содержит адрес выбранной строки, FirstWeight по #C8BF последний преобразованный вес второго набора, SecondWeight по #C8E1 последний вес третьего набора. Повторный вход с изменением этих операндов не допускается. Новая память не выделена.

На возврате B=0, C сумма трёх наборов без дополнительного поля. При коде FF HL=964F и DE=9904, иначе DE является байтовым смещением, HL адресом дополнительного байта. Альтернативные HL, DE, BC, индексные регистры, I и IFF сохраняются, SP восстановлен. Альтернативный A содержит C, альтернативный F относится к последнему ADD A,C третьего набора. Его точный входной аккумулятор — произведение последней пары, второй операнд — предыдущая сумма.

[CheckWeightedLoad.py](../Tools/Disasm/Research/CheckWeightedLoad.py) сравнивает выполнение исходных инструкций с независимой формулой в 512 случаях. Охвачены все 256 кодов масштаба и дополнительной записи, разнообразные строки, индексы, оба набора весов, нулевые и максимальные множители. Проверяются результат, основные регистры, сохранность альтернативных пар и индексных регистров, SP и три операнда. Отчёт [WeightedLoadVerification](../Tools/Disasm/Reports/WeightedLoadVerification.json). Прерывания, сборка и нативный запуск не выполнялись.
