# Разнесённая таблица отсечения KARTA

[DispatchMapClipEdge](../Source/Map/DispatchMapClipEdge.asm) вычисляет
индекс из кодов двух точек. Если первая точка внутри, диспетчер сначала
обменивает записи точек. Затем читает младший байт цели из DE00+индекс
и старший из DF00+индекс. Три слова D4DD образуют общий кадр возврата.
После них выполняется JP (HL). [Договор обработчиков](MapClipHandlers.md)
описывает обычный и специальный выходы.

Таблица содержит 81 исходную пару кодов из набора 0, 1, 2, 4, 5, 6, 8,
9 и A. После обмена остаются 73 достижимых индекса. Остальные восемь
исходных целей сохранены с именами. Например, индекс 00 задаёт DB42,
AppendSecondClipPoint, индекс 05 задаёт D4E6, CaseI_BR. Вторая цель
принадлежит дисковому снимку до обмена.

Младшая страница включает наложенные структуры точек, режима линии
и промежуточных произведений. По DFAB начинается ArcWorkspace,
дальше расположены его рабочие поля и код. Их исходные байты
и оформление сохраняются. В отдельных строках оформлены только
не занятые ими байты:

| Диапазон | Физические исходники |
|---|---|
| DE00..DE0A | [Строка 0](../Source/Map/Data/ClipLowRow0.asm) |
| DE10..DE1A | [Строка 1](../Source/Map/Data/ClipLowRow1.asm) |
| DE20..DE2A | [Строка 2](../Source/Map/Data/ClipLowRow2.asm) |
| DE3E..DE3F | [Хвост строки 3](../Source/Map/Data/ClipLowTail3.asm) |
| DE40..DE5F | [Строки 4 и 5](../Source/Map/Data/ClipLowRows45.asm) |
| DE60..DE6A | [Строка 6](../Source/Map/Data/ClipLowRow6.asm) |
| DE7B..DE7F | [Хвост строки 7](../Source/Map/Data/ClipLowTail7.asm) |
| DE80..DEFF | [Строки 8–F](../Source/Map/Data/ClipLowRows8F.asm) |
| DF00..DF9F | [Старшие байты строк 0–9](../Source/Map/Data/ClipHighRows09.asm) |
| DFA0..DFAA | [Старшие байты строки A](../Source/Map/Data/ClipHighRowA.asm) |

В 27 физических записях сохранены 382 байта. Инициализаторы 162 байтов
используют LOW и HIGH от существующих меток. Вне допустимых пар
сохраняется исходное содержимое, в новых записях это нули.

[Модель](../Tools/Disasm/Research/CheckMapClipTablePages.py) исполняет
исходный диспетчер для 81 пары и отдельно для всех 256 индексов.
Проверяются два фактических чтения, HL на границе JP (HL) и три слова
возврата. При произвольном индексе модель останавливается до перехода.
Исполнение допустимых обработчиков отдельно проверено
[моделью отрезка](../Tools/Disasm/Reports/ClipSegmentVerification.json).
[Результат публикации](../Tools/Disasm/Reports/MapClipTablePagesClassification.json).
