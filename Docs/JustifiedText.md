# Выравнивание текста по ширине

[SkipJustifyRow](../Source/Station/SkipJustifyRow.asm), #AD35,
пропускает одну строку с расчётом курсора без пикселей.
[PrintJustified](../Source/Station/PrintJustified.asm), #ADCD,
выводит последовательность таких строк до остановки либо отказа переноса.
Они используют разные [печататели слова](WordOutput.md).

## Выбор набора слов

Перед работой проверяется Height>=14. При меньшей высоте возвращаются
A=Height и F от CP(Height,14), другие регистры и данные не меняются.
Ширина копируется в отдельный непосредственный операнд LD C,nn.
JustifyState.SkipWidth находится по #AD4E, PrintWidth по #ADDA.
Новой памяти для этих значений не выделяется.

HL начала строки временно сохраняется в CPU-стеке. Просмотр вызывает
MeasureTextRun с B=#20, получает ширину слова, добавляет минимальный
межсловный интервал 2 и переходит за ограничитель. Сумма меньше ширины
окна разрешает просмотр следующего слова. При достижении ширины либо
переполнении суммы обычно выбираются слова перед последним просмотренным.

В D остаётся сумма предыдущего набора с интервалами, E становится числом
выбранных слов. Если первое слово не помещается даже без завершающего
интервала, E=0 и вызывается один печататель слова без распределения ширины.
Особая ветвь сохраняет E=1, когда первое слово без интервала помещается,
а с интервалом уже достигает ширины. Сравнение с шириной строгое,
равенство не считается свободным местом для очередного слова.

Просмотр не заканчивается на CR либо LF. Они останавливают только один
вызов измерителя, затем HL увеличивается, и просмотр продолжается дальше.
Вызывающий код обязан предоставлять читаемые байты после этих ограничителей.
В модели явно предоставлен дополнительный запас, чтение за LF не скрыто.

Прибавление 2 к отдельной ширине выполняется по модулю 256, Carry от него
не проверяется. Проверяется только следующее сложение с накопленной суммой.
Например, результат измерителя #FF после добавления 2 становится 1.
Этот крайний случай сохранён, длинные слова не нормализованы.

## Распределение промежутка

Начало текста восстанавливается из стека. Для непустой группы вычисляется
свободная ширина Width-D по модулю 256. Для группы из N>1 слов дополнительный
интервал равен floor(свободная ширина/(N-1)), деление выполнено вычитаниями.
Для N=1 эта ветвь деления пропускается и дополнительный интервал равен всей
свободной ширине. Дробный остаток между промежутками не распределяется.

После каждого неостановившего печатателя к CursorX добавляются 2 и
дополнительный интервал, затем уменьшается E. CR в печатателе устанавливает
E=1, поэтому завершает группу после текущего слова. После группы вызывается
AdvanceTextRow. Внутри оригинала имеются два физических экземпляра этой
логики, они не заменены общей процедурой.

## Сухой проход

SkipJustifyRow записывает по #AED5 три байта JP ReturnGlyph.Entry.
DrawGlyph продолжает проверять окно и двигать курсор, но пиксели не пишет.
Печать слов выполняется через PrintTextWord, который останавливает проход
при отказе ширины даже после принятого переноса.

При выходе, кроме раннего Height<14, восстанавливаются именно исходные
байты #68,#48,#26, произвольный предыдущий вариант не сохраняется.
DE возвращается равным #2648, A=#68. F остаётся от выхода печатателя,
либо от AND A после завершающей попытки переноса группы. Последний AND
сбрасывает Carry даже при отказе этого переноса.

## Печатающий проход

PrintJustified использует PrintWrapWord. Z завершает весь проход,
успешный перенос без Z позволяет повторить выбор слов следующей строки.
После выведенной группы отказ AdvanceTextRow по Carry также завершает проход.
Другие действия с bitmap выполняет DrawGlyph в его текущем режиме.

HL, DE, BC и AF являются рабочими. D содержит предыдущую ширину либо
дополнительный интервал, E остаток группы с учётом CR. BC содержит разделитель
и кэшированную ширину либо результат попытки нового ряда. Альтернативные
и индексные регистры, I и IFF сохраняются, стек сбалансирован.

Оба прохода сохраняют байтовое переполнение Y. У PrintJustified при Width=0,
Height>248 и остатке Y modulo 8 меньше Height-248 возможен бесконечный повтор
автоматического переноса одного символа. Аналогичная причина разобрана в
[TextStream](TextStream.md). Счётчик строк вне этого алгоритма не добавлен.

## Проверка

[CheckJustifiedText.py](../Tools/Disasm/Research/CheckJustifiedText.py)
сверяет выбор слов и целую долю промежутка с исходным исполнением.
Проверено 11656 случаев, все ширины 0..255 для семи наборов слов,
3072 сочетания высоты и начального Y, 5000 смешанных текстов.
Сверяются AF, HL, DE, BC, курсор, сохранённые регистры, SP и попытки глифов.
Отдельно проверено восстановление префикса глифа сухим проходом.

В печатающем проходе модель заранее включает режим глифа без пикселей.
Сухой проход устанавливает и снимает его сам исходными инструкциями.
Пиксельные ядра проверены отдельно в [GlyphRendering](GlyphRendering.md).
Прерывания отключены, нативный запуск здесь не выполнялся.
Отчёт [JustifiedTextVerification.json](../Tools/Disasm/Reports/JustifiedTextVerification.json).
