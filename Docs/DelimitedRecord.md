# Поиск по двум уровням разделителей

[FindDelimitedRecord](../Source/Text/FindDelimitedRecord.asm), LANG #C849..#C86E, принимает A как число разделителей FF, B как число разделителей FE и DE как смещение. Входной C сохраняется. Исходное начало таблицы #9A49. Сначала выполняется A поисков FF, затем B поисков FE, каждый следующий начинается за предыдущим найденным разделителем. Ноль в любом из внешних счётчиков означает 256 поисков.

Счётчики внешних циклов сохраняются на CPU-стеке. Каждый внутренний CPIR получает BC=0, это предел 65536 сравнений. Если разделитель отсутствует во всём адресном пространстве, CPIR заканчивается с BC=0 и без совпадения, но специальной ошибки функция не обрабатывает, внешний цикл продолжается. Для осмысленного результата требуется существование всех выбранных разделителей. Модель проверяет положительные случаи с присутствующими разделителями и не доказывает корректность некорректной таблицы.

После последнего CPIR выполняется DEC HL, возвращающий указатель на сам FE, затем ADD HL,DE. Итоговый адрес равен (адрес FE+DE) AND FFFF, поэтому нулевое смещение указывает на маркер, а не на следующий байт.

GroupCount по #C856 и RecordCount по #C862 являются непосредственными операндами LD B, записанными при входе. Они сохраняют исходные A и B после возврата. Новой памяти нет. Повторный вход с другими счётчиками до завершения нарушает текущий запрос.

На возврате A=FE, B=0, C и DE сохранены, HL содержит найденный адрес со смещением. Альтернативные регистры, IX, IY, I и IFF сохраняются, SP восстановлен. F после ADD HL,DE сохраняет S/Z/PV от последнего CPIR, задаёт H/C по сложению, N=0, недокументированные X/Y от старшего байта суммы. На успешном поиске S=0 и Z=1, PV показывает ненулевой оставшийся внутренний BC.

[CheckDelimitedRecord.py](../Tools/Disasm/Research/CheckDelimitedRecord.py) проверяет исходные инструкции в 7680 случаях, все значения первого внешнего счётчика, шесть значений второго, включая 0 и 255, пять смещений, включая FFFF. Проверяются итоговый адрес, A/B/C/DE, SP, сохранность альтернативных и индексных регистров, два операнда и часть флагов S/Z/PV. Отчёт [DelimitedRecordVerification](../Tools/Disasm/Reports/DelimitedRecordVerification.json). Сборка, прерывания и нативный запуск не выполнялись. Семантические имена всех групп самой таблицы остаются предметом дальнейшего разбора её потребителей.
