# Запуск, прерывание и таймер ENGINE

На входе `#4000` ENGINE заменяет стек меню на `#6000`. Он вычисляет
`#4842 XOR #4895 = #00D7` и записывает результат по `#503E..#503F`.
Применение этой маски к адресу любой записи бойца даёт адрес другой.
Байт `#5F5E` от меню индексирует три слова по `#5018`. Выбранный адрес
попадает в операнд `JP` по `#4FB6`.
[Вход сцены](../Source/ArchiveEngine/RunCombatScene.asm)
· [Переход между меню и ENGINE](ArchiveMenuHandoff.md)
· [Договоры и операции портов](ArchiveEnginePaging.md)

| Код | Режим меню | Адрес селектора |
| ---: | --- | --- |
| 0 | `256k:Pent` | `#4FB8` |
| 1 | `256k:Scorp` | `#4FCF` |
| 2 | `256k:ATM-2` | `#4FE5` |

Очистка выбирает страницу 7. Первый `LDIR` размножает ноль по всему
растру и первому байту атрибутов. Второй заполняет все 768 атрибутов
значением `#07`. Выбранный код страницы записывается по `#5012`.
При проверке остальной bitmap основной страницы 5 сохранил байты
загруженного кода. [Очистка](../Source/ArchiveEngine/ClearShadowScreen.asm)

Далее загружаются `BD0`–`BD3`, `scene1po` и два экземпляра `BAR`, без
проверок статуса между запросами. Фон читается по `#7700`, после чтения
прерывания запрещаются. Подготовка копирует фон по страницам, строит
таблицу зеркальных битов, инициализирует индикаторы, время и первые кадры.
После установки IM2 начинается основной цикл `#4030`. Он применяет ввод,
продвигает кадры бойцов, согласует положение окна, восстанавливает старый
фон, рисует бойцов и таймер, затем выводит окно сцены.

## Прерывание

257 байтов таблицы по `#5E00..#5F00` получают `#5F`. Любой байт шины
даёт вектор `#5F5F`, по которому установлен `JP #463F`. Подготовка ставит
`I=#5E`, включает IM2 и выполняет `EI` перед `RET`.
[Подготовка IM2](../Source/ArchiveEngine/EnableSceneInterrupts.asm)

Обработчик выполняет `EI`, сохраняет прерванный `SP` в операнде по
`#4669` и ставит `SP=#463F`. Затем сохраняет IX и оба набора основных
регистров. Индикаторы временно выбирают страницу 7 и восстанавливают
логический код страницы. После обновления таймера обработчик опрашивает
клавиши, снимает сохранённые значения и возвращается к прерванному коду.
На пути с истёкшим временем возврат прерывается командой `HALT`.
[Обработчик IRQ](../Source/ArchiveEngine/Interrupt.asm)
· [Индикаторы и раскладка растра](ArchiveEngineMeters.md)

| Адрес слова | Фактическое использование |
| --- | --- |
| `#4621` | Адрес `#2A53`, помещённый по `#5002` и снятый командой `RET` по `#3D30` |
| `#4623` | AF, сохранённый по `#4FE6` и восстановленный по `#4FF0`. Затем адрес возврата из `CALL` по `#4FFF`, снятый по `#2A55` |
| `#4625` | HL, сохранённый по `#4FE5` и восстановленный по `#4FFC` в ATM-2, или AF, сохранённый по `#4FCF` и восстановленный по `#4FD9` в Scorpion |
| `#4627` | `PUSH BC` переходника страниц по `#4FB4` |
| `#4629` | Возврат из вложенного вызова селектора, индикатора или опроса клавиш |
| `#462B` | Возврат из одного из трёх вызовов в обработчике |
| `#462D..#4634` | Альтернативные AF, BC, DE и HL |
| `#4635..#463E` | Основные AF, BC, DE, HL и IX |

В профилях для всех 16 кодов страниц проверены 24 байта этой рамки,
адреса всех записей и восстановление регистров, включая IY. В модели
ATM-2 два переключения на каждом из 32 IRQ используют ещё три слова
по `#4621..#4626`. В Scorpion используется одно дополнительное слово
по `#4625`. Вложенные кадровые IRQ в эти профили не подавались.
Назначение десяти исходных нулей по `#4617..#4620` остаётся открытым.

## Таймер

При старте по `#4C8A` записывается BCD `#99`, а по `#4C8B` число 50.
На каждом IRQ уменьшается второй байт. Когда он достигает нуля,
процедура возвращает ему 50 и уменьшает время. При ненулевой младшей
цифре выполняется обычный `DEC`. Для значений `#10`, `#20` и далее
из старшей цифры вычитается десятка и в младшую записывается 9.

После 4950 вызовов отображаемое время доходит до `00`. Ещё через 50
вызовов выполняются `DI` и `HALT` по `#4A83`. Модель прошла все 5000
комбинаций BCD 00–99 и остатка 1–50 и отдельную полную последовательность
из 5000 вызовов до остановки. Это число прерываний, длительность зависит
от их частоты.
