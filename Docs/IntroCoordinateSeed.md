# Исходные координатные отсчёты вступления

[CoordinateSeed.asm](../Source/Intro/Data/CoordinateSeed.asm) хранит
256 реальных FIntroCoordinateSample. Они читаются с диска по файловому
#0100..#01FF в RAM #6400..#64FF. Это не часть логического BASIC-файла.

Первые 128 значений совпадают с числовым описанием
`round(127.5 × (1 + cos(π × i / 128)))` для i=0..127. Описание
проверено по всем сохранённым значениям, оно не доказывает исходный
язык или инструмент генерации автора. Значения unsigned8, отдельными
битовыми флагами не являются. Все 128 последующих байтов исходно нулевые.

[BuildScreenTables](../Source/Intro/BuildScreenTables.asm) копирует
значения индексов 127..1 в индексы 129..255. Индекс 128 остаётся
нулевым. Эта половина строится при исполнении и не подставляется
в исходный образ. Полученные отсчёты используют
[BuildTextureLookup](../Source/Intro/BuildTextureLookup.asm) и
другие построители фаз вступления.

[Модель](../Tools/Disasm/Research/CheckIntroCoordinateSeed.py) исполняет
оригинальный построитель и сравнивает всю память с независимым
отражением и формулой адресов экранных строк. Проверены три
контекста C, значения за пределами записываемых областей сохранены.
В таблицах #6000 и #6100 записаны указатели для строк y=4×i и
y=4×i+2 при i=0..31, прочие поля страниц не заполняются этим кодом.
Сборка, IRQ и нативный запуск не выполнялись.
