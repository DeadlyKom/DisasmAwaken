# Восстановление временно делимых вычитаемых слов

[RestoreHalvedOffsets](../Source/Action/RestoreHalvedOffsets.asm), вход `E685`,
проверяет полный ClassCode записи IX. Для класса 14 восстанавливаются
три исходных слова, для остальных классов выполняется ранний RET.
Игровая роль самого класса 14 пока не названа.

| Поле | Рабочий операнд | Сохранённый оригинал | Использование |
| --- | --- | --- | --- |
| 0 | Active0, E5B3 | Original0, E68C | Вычитаемое перед обновлением Component0 |
| 1 | Active1, E5D2 | Original1, E692 | Вычитаемое перед обновлением Component1 |
| 2 | Active2, E5ED | Original2, E698 | Вычитаемое перед обновлением Component2 |

Префикс [E55C](../Source/Action/PrepareRecordScale.asm) сначала сохраняет CPU SP
в операнде `E605`. Для класса 14 он читает каждый Active, сохраняет его
в соответствующем Original и временно заменяет арифметической половиной.
SRA H и RR L сохраняют знак, отрицательное нечётное значение округляется
вниз, например FFFF остаётся FFFF. Восстановитель читает именно оригиналы,
арифметическое удвоение половин исходные нечётные значения не восстановило бы.

Original0..2 находятся внутри непосредственных операндов трёх LD HL,nn.
Сохранитель меняет их реальные байты. EQU обозначает эти существующие
байты кода, отдельные данные и новые RAM-адреса не выделяются.
Active0..2 аналогично являются непосредственными операндами LD DE,nn
в [E5A0](../Source/Action/UpdateRecordComponents.asm).

При классе 14 HL после возврата равен Original2, AF=1442.
DE, BC, альтернативные и индексные регистры сохранены.
При другом классе HL сохранён, A содержит ClassCode, F соответствует CP 14.
R получает 11 M1 для восстановления и четыре M1 для раннего выхода.
CPU-стек только читается RET, SP увеличен на два. I/IM/IFF и paging не меняются.

[Проверка](../Tools/Disasm/Research/CheckActionOffsetRestore.py) выполняет
реальный префикс E55C..E58D до входа E58E, затем настоящий восстановитель.
65536 сценариев покрывают все слова каждого поля, два других значения
являются перестановками того же полного домена. Ещё 256 сценариев
проверяют все коды класса и отсутствие записей при раннем выходе.

[Отчёт](../Tools/Disasm/Reports/ActionOffsetRestoreVerification.json)
подтверждает регистры включая R, все восемь банков RAM, точный порядок
и кратность записей, включая самомодификацию. Для префикса получены 27 M1.
Эта проверка останавливается по E58E. Продолжение E55C с чтением заголовка
и изменяемым JR отдельно проверено в [разборе PrepareRecordScale](./ActionRecordScale.md).
Продолжение E5A0 отдельно проверено в [разборе обновления компонент](./ActionRecordUpdate.md).
Все сочетания трёх 16-битных слов, точные T, аппаратные IRQ и нативное
выполнение этой игровой цепочки не проверялись.
