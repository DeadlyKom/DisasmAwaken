# Обратная ссылка поверх кода отсечения

В расширенном профиле [State02](ActionLinkedTargetState.md) с LinkedIndex=A1
обычный расчёт `A100+64*A1` даёт IY=C940. Это адрес в кодовой RAM,
а не одна из 25 обычных записей. Исходные инструкции индекс не ограничивают.
Достижимость такого индекса из штатного игрового процесса не установлена.

[CheckAndToggleLinkedOverlay](../Source/Action/CheckAndToggleLinkedOverlay.asm)
по условию R сначала устанавливает бит 0 по IY+0C, затем записывает
индекс текущей записи по IY+0B. При текущем IX=A700 индекс равен 18,
поэтому запись попадает в C94B, первый байт условного перехода
[ClipSingleEdge](../Source/Action/ClipSingleEdge.asm).

| Адрес | Было | После обратной ссылки |
|---|---|---|
| C94B | 20, JR NZ | 18, JR |
| C94C | 27, относительное смещение | 27, установка младшего бита сохраняет значение |

В результате переход к выбору случая отсечения становится безусловным.
Даже при внутреннем первом конце с кодом F0 обмен точек пропускается.
Старая числовая модель всегда выполняла обмен при F0 и потому выбирала
другие произведения, выходные точки и итоговые регистры. Ошибка находилась
в предположении модели о неизменном коде этого синтетического профиля.
Оригинальные инструкции игры не исправлялись.

[Числовой эталон](../Tools/Disasm/Research/ReferenceActionClipping.py)
теперь читает фактический байт перехода. Он поддерживает исходный JR NZ
и наблюдавшийся JR с исходным смещением 27. Любой иной вариант изменения
этого входа явно отвергается, произвольное повреждение кода не объявляется
разобранным поведением.

[Проверка State02](../Tools/Disasm/Reports/ActionLinkedTargetStateUnrestrictedVerification.json)
прошла 44656 профилей, [проверка State05](../Tools/Disasm/Reports/ActionLinkedPhaseStateUnrestrictedVerification.json)
44032. Принудительный текущий маркер отказа для индексов за массивом
в этих профилях не используется. Сверены регистры кроме R растеризатора,
восемь банков, значения и кратность записей, реальные OUT. Максимальная
наблюдаемая дополнительная глубина стека составляет 28 байтов.

Историческое расхождение и его установленная причина сохранены
[в реестре](../Tools/Disasm/Reports/ActionLinkedTargetOutOfArrayLimitation.json).
Диагностический запуск не заменяет полную проверку и сохраняет отдельный
[отчёт](../Tools/Disasm/Reports/ActionLinkedTargetDiagnostic.json).
Сборка и нативный запуск не выполнялись, ошибка обычной игры не доказана.
