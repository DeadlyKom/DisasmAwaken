# Наведение на элемент миссии

[HandleItem31](../Source/Station/HandleItem31.asm) содержит только JP на [UpdateMissionRowHover](../Source/Station/UpdateMissionRowHover.asm). Это вход наведения, помещённый в EventHandler записи элемента. Нажатие обрабатывается диспетчером через EventHandler+3, то есть по отдельному адресу 6E9C. Его пока неразмеченное тело нельзя подменять доказательством этой короткой обёртки.

UpdateMissionRowHover задаёт DE=0203, то есть ограничение двух строк для ClampRowHeight и верхний пиксельный отступ 3. HL получает DrawItem31.Entry, проверяемый как последний обработчик списка. A получает прежний номер из операнда LD A по MissionHoverState.Row, 6F54. Затем исполняется полный [UpdateRowHover](RowHover.md) с проверками положения и настоящим XOR-ядром карты.

При Z=1 процедура возвращается немедленно и не меняет сохранённый номер. A на таком выходе может быть нулём при отказе либо прежним номером при совпадении. При Z=0 возвращённый A записывается в тот же операнд. Успешный выбор строки 0 тоже имеет A=0, но F=0 и Z=0, его нельзя спутать с отказом. Это назначение условного RET перед записью.

Код FF означает отсутствие прежней полосы. DrawItem31 после перерисовки сбрасывает его в FF, чтобы следующее обновление не пыталось снимать старый XOR с нового изображения. В обычной двухстрочной области выбираются номера 0 и 1. Общий UpdateRowHover читает PointerY дважды. Поздний отказ после снятия прежней полосы не проверяется повторно, возвращённая служебная высота также может сохраниться как Row. Особенность дочернего входа не исправляется в обёртке.

[CheckMissionHover.py](../Tools/Disasm/Research/CheckMissionHover.py) проверяет 1152 случая, все 192 значения PointerY, прежние 0, 1 и FF и оба порядка последнего элемента. Исполняются настоящие банковые вызовы, XOR и указатель, с независимым расчётом bitmap и атрибутов. Проверяются запись операнда, Z, сохранённые регистры, стек и возврат банка 0. [Отчёт](../Tools/Disasm/Reports/MissionHoverVerification.json). Фикстура использует допустимую геометрию и подготовленную карту владельцев, реальный ISR и полный интерфейс игры не исполняются. Сборка и нативный запуск не выполнялись.
