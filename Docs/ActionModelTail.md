# Дополнительные пакеты OBJECT3D

После последней цели исходной таблицы указателей по смещению 2469
остаются семь последовательных пакетов. Последний нулевой ограничитель
лежит по 2953, непосредственно перед секторным суффиксом. Всего 1259
байтов, 207 граней и 19 открытых линий.

| Начало | Конец без включения | Получаемых вершин | Исходник |
|---|---|---:|---|
| 2469 | 251F | 32 | [Model2469](../Source/Action/Data/Model2469.asm) |
| 251F | 25C1 | 24 | [Model251F](../Source/Action/Data/Model251F.asm) |
| 25C1 | 266B | 32 | [Model25C1](../Source/Action/Data/Model25C1.asm) |
| 266B | 2707 | 28 | [Model266B](../Source/Action/Data/Model266B.asm) |
| 2707 | 27AB | 26 | [Model2707](../Source/Action/Data/Model2707.asm) |
| 27AB | 2859 | 28 | [Model27AB](../Source/Action/Data/Model27AB.asm) |
| 2859 | 2954 | 37 | [Model2859](../Source/Action/Data/Model2859.asm) |

Действует тот же [формат](ActionModelPackets.md), включая два независимых
нулевых ограничителя. Число вершин равно сумме числа установленных битов
масок групп. Каждый индекс кратен пяти и выбирает существующую вершину
своего пакета. Материалы граней лежат в пределах 0..4, длины линий
соответствуют исходному формату.

[Сценарий](../Tools/Disasm/Research/CheckActionModelTail.py) заново
разбирает каждый пакет, проверяет границы и собирает его представление
обратно в исходные байты для сравнения. [Отчёт](../Tools/Disasm/Reports/ActionModelTailVerification.json)
сохраняет границы, индексы и объём. Эти пакеты отсутствуют среди 128 слов
по 9E00 и не дублируют один из 95 основных потоков побайтно.

Сразу за этой таблицей, по 9F00..9F1B ACTION, лежат 14 физических
FObjectDataPointer. Каждое начало дополнительного пакета банка 4 записано
дважды подряд. Адрес модели 27AB идёт перед адресом 2707, исходный порядок
сохранён. Обычные читатели таблицы 9E используют оборачивание младшего
байта, поэтому они не доходят до дополнительных слов. Потребитель 9F00
и игровые имена моделей остаются неизвестными.
[Физические указатели](../Source/Action/Data/TailModelPointers.asm),
[сверка адресов](../Tools/Disasm/Reports/ActionTailModelPointersVerification.json).
